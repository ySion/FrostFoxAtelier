# 原生布局历史性能证据

历史记录：下列数字分别对应24、27、29、35项版本，负载和资源持有方式不同，不能直接相除声称提速。当前39项结果与同场景前后比较见[审计](../../modules/ui-layout/audit.md)。原始out材料不随源码提交；缺失时不能声称已在本机重现旧版本。

## 24项版本：全量Inspector与物品格



```powershell
. ./tools/enter-dev.ps1
cmake --preset release
cmake --build --preset release --target ui_layout_acceptance
./out/release/atelier_ui_layout_acceptance.exe --performance
```

实现位于[正式消费者](../../../acceptance/ui_layout/practical.inl)，没有独立benchmark目标。Inspector包含256行、512个真实文字叶，共770个节点；物品格包含256个真实文字叶，共258个节点。文字为Segoe UI/en-US与中文回退，文本内容在源码中固定；中文回退字体未逐文件固定。

动态场景预热8次，再采120次。静态场景1000组，每组100次，表内为每次调用摊销时间；查询场景1000组，每组查询10轮，每轮256个value节点。p95由样本排序取得。冷启动仅记录一次完整场景创建与首次计算，包含DirectWrite初始化，不作为稳定分位数。

### 该版本的采样

单位为微秒。内部缓冲分配列为整个采样期间的次数。

| 场景 | 中位数 | p95 | 内部缓冲分配 | 测量调用总数 |
|---|---:|---:|---:|---:|
| Inspector静态 | 0.007 | 0.007 | 0 | 0 |
| Inspector单项文字更新 | 89.0 | 127.2 | 0 | 120 |
| Inspector宽度280/500交替 | 54619.9 | 63221.8 | 0 | 30720 |
| Inspector折叠/恢复一行 | 66.4 | 93.4 | 0 | 0 |
| Inspector插入并删除一行，两次compute | 236.0 | 360.8 | 120 | 360 |
| 一轮查询256个value | 0.600 | 0.950 | 0 | 0 |
| 复制一份770节点快照 | 0.800 | 1.100 | 0* | 0 |
| 物品格静态 | 0.007 | 0.010 | 0 | 0 |

*快照使用调用方拥有的标准vector进行几何和索引复制，其分配不计入Document内部缓冲计数。该行不能解释为快照零分配。静态纳秒级数值仅为批量摊销结果，环境调度和计时噪声仍存在。

Inspector冷启动一次为71.14ms，内部缓冲分配325次、累计申请1,287,300字节、结束时保留497,332字节，测量768次。预热和结构编辑后保留589,216字节；删除全部行、只剩根与table两个节点后仍保留585,120字节，峰值623,112字节。节点池、发布索引和工作缓冲保留高水位容量，移除释放了每行的孩子数组。Document析构负责释放剩余缓冲；目前没有主动压缩接口。

### 当时成本归因

测量回调单独计时。Inspector resize的回调平均耗时约54.875ms，回调之外平均0.270ms；物品格resize分别约10.536ms和0.105ms。后者包含布局、调用方操作和计时开销，不能冒充纯求解器耗时。回调占总采样时间约99%，测量对象创建数为0，说明复用对象没有消除改变宽度后的排版成本。

消除重复设置DirectWrite换行模式/宽度后，开发中的单因素对照里Inspector增删中位数从474.8μs降至236.0μs；resize没有改善。改动前记录保留于`release-before-provider-setters.jsonl`，没有独立冻结旧二进制，不据此宣称整个引擎获得确定倍数提速。

当前优先保留完整结果、失败回滚和可观察成本。没有增加仅为两种交替宽度服务的特殊缓存，也没有把文字成本误归为几何调度后重写算法。大量文字每帧改变宽度仍是已测出的限制；后续文字排版复用、实际可见集合或更新政策需要结合真实UI负载设计。局部几何调度仍有独立价值，但不能单独消除这次resize成本。

### 计数边界与证据

- `buffer_*`只统计内部节点池、孩子数组、工作/发布/索引缓冲；不含NodeInput列描述复制、provider、快照、拥有者本身及进程其他分配。这里没有全进程内存或字体缓存上限结论。
- `node_visits`仅统计三次可见节点尺寸/定位遍历，不能当全部工作量。单项内容更新仍遍历全树。
- 本机原始输出：[release-performance.jsonl](../../../out/review/ui-layout-practical/release-performance.jsonl)。源码、二进制哈希和环境：[environment.json](../../../out/review/ui-layout-practical/environment.json)。输出不随Git源码交付，复现命令与场景源码随模块交付。

每个操作样本包含实际内容/节点协调、行高索引和完整帧准备。compute内非测量时间用同一批次的compute总耗时减去其内部测量回调总耗时计算；消费协调是整次操作扣除compute，包含捕获帧时准备文字的成本。不能把整次操作扣除测量称为纯布局，也不能用两个中位数相减归因。预览耗时接近计时器分辨率，0.0μs不是零执行成本；确定性证据是没有布局/测量工作。

本次最多实例化22行；最终当前缓存42个段落、可见帧引用42个段落，两者可能指向同一资源，不能相加当作原生对象数。逻辑高度索引1,600,008字节，示例业务key数组800,000字节；两个Document内部缓冲峰值合计87,008字节，均不是整个UI进程内存。正式验收另验证旧帧释放后的段落回收。
