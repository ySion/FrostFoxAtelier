# 菜单栏与 Tab 栏校准

日期：2026-10-02。参照为用户本轮提供的两张局部截图：菜单栏 1087×59 像素、Tab 栏 850×49 像素；Houdini UI Scale 保持用户指定的 1.75。此次实现与比对使用附件和本产品 GPU 读回，没有保存或修改 Houdini 场景。

后续字体调整：用户要求全局字体统一，并移除 Tab 焦点框。当前字体已改为 Sarasa UI SC，Tab 和栏工具的焦点描边已移除；字体、字号与部署依据见[字体说明](../../assets/fonts/README.md)。下文尺寸表和归档截图保留当时使用 Source Sans 3 的校准记录。

后续字形纠正：Sarasa 合成斜体使 Scene View 显得过斜。固定视图名称现统一为正体，移除该标签专用的 `context-view` 类及斜体规则；保留基础 UI 的 font-style 能力。参考截图中的 `/obj` 是路径标题，不作为全部视图名称采用斜体的依据。

## 结构纠正

菜单栏是左侧窄收拢区加主体；Tab 栏直接从标签开始。“＋”紧跟最后一个标签，最大化和 Pane 菜单靠右。原先加在每个 Pane 标签栏前的收起按钮已移除；分隔条的双侧收起、交换、旋转和拖动继续保留。

菜单栏通过现有容器、按钮和 `collapsed` 组成，展开高 32 DIP、左轨宽 12 DIP，收起高 8 DIP。8 DIP 是本产品为保留可点击恢复区所选的尺寸，附件没有给出收起后的高度。F10/Alt 菜单快捷键会展开栏，等待新几何真正呈现后再打开原生菜单。布局重置也展开菜单栏；视图 key、比例、文档和历史不会因此重建。

“＋”使用带图标的普通 combo，走同一 `context_menu → Workspace.menu_items → PopupHost` 链路。当前四个视图各有一份状态：选择已打开的视图将其移入当前组，已关闭的视图重新打开，当前组已有视图则选中。右侧 Pane 菜单的 Show 保持跳转到原组的行为。标签区域按内容占宽并允许压缩，弹性空隙放在“＋”之后；狭窄时保留加号及右端工具的空间。

## 像素依据

屏幕附件是物理像素；本机 Window→Surface 换算为 1.5，Houdini 的 1.75 是应用内部 UI Scale，不能再乘进 Atelier 的 DPI。

| --- | --- | --- |
| 菜单主体 | y=6…52，约 47 px | 32 DIP，48 px |
| 左侧收拢区 | 约 17–18 px | 12 DIP，18 px |
| Tab 栏 | y=6…39，约 34 px | 22 DIP，33 px |
| 普通 Tab 背景 | #2e2e2e | #2e2e2e |
| 当前 Tab 背景 | #494949 | #494949 |
| 标签文字 | #cccccc | #cccccc，13 DIP Source Sans 3 |
| 菜单渐变 | #3a3a3a → #323232 | 同色端点，现有线性渐变 |
| 关闭符号 | 约 9 px | 8 DIP 图标盒内绘制，约 9 px |

采用本项目自带的 Adobe 字体，未复制 Houdini 的字体或图标资源。Scene View 使用 `context-view` 类显示斜体；工具类标签仍用正体。原截图是 `/obj` 路径标题，本项目保留自己的视图名称。抗锯齿、字体字面和非活动标签边缘尚有差异，不称为逐像素相等。

## 样式系统的发现与落实

- `font-style` 原先没有进入字体身份；现在 SS/C++ 都支持 normal/italic，继承、测量、DirectWrite 格式缓存与旧帧快照共用同一值。持久状态可切换，悬停/焦点等临时状态禁止改文字度量。未附带专用斜体字体时由 DirectWrite 合成。
- combo 原先强制画右侧箭头槽；现在允许图标形式，与普通下拉共用菜单请求和键盘行为，不保留多余文字留白。
- 纯图标原先忽略 padding；现在按真实内容区居中并限制尺寸，菜单栏箭头因此可以靠上对齐。最大化的两种颜色分别来自 foreground 与 indicator-background；图标覆盖图继续缓存。
- 标签组使用现有组合容器与 SS，不建立第二套绘制入口。当前边框仍是统一宽度，inset/outset 共用明暗边；附件各边的独立颜色还不能逐边声明。此次未扩展任意边框、路径裁剪或浏览器盒模型。

## 验收范围

沿既有产品端到端入口覆盖：菜单收起/展开及 F10 恢复、恢复前后几何与历史、Tab 起点和加号位置、原生加号菜单、跨组加入已有视图、标签拖动/关闭/重开、最大化、分隔条收起与交换。共享 UI 消费者增加斜体继承、旧帧不变和非法瞬态字体声明检查。没有运行真实搜狗验收。

原生消息验收启动时将系统光标停在编辑器标题栏，避免捕获/显示窗口所补发的移动消息命中其他菜单标题；每次发送手势前同时检查输入焦点与实际前台归属。实际拖动和点击继续通过产品 HWND 的原生消息入口，不跳过菜单或直接修改文档。

最终结果：开发与发布目标均编译通过；共享 UI 消费者两版均 15/15 PASS；完整编辑器窗口验收两版均 PASS，各接受 2660 帧。GPU 截图已检查，包含默认菜单栏、收起状态、多个 Tab 和原生“＋”菜单。归档位于 `out/houdini-chrome-20261002/{dev,release}/`，同目录保留两张用户参考截图。未声称覆盖跨显示器真实 DPI 迁移，也未运行搜狗验收。
