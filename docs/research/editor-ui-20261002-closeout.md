# 编辑器 UI 阶段收口（2026-10-02）

范围：上次提交 `b585353` 之后的菜单、停靠栏、参数组合、字体、细节绘制及单行编辑器与精度阶梯改动。需求来自本阶段用户提供的 Houdini 截图和交互反馈。

## 实际产出与清理

- 菜单栏与可收拢 bar、停靠标签与分隔条使用统一输入链。下拉和上下文菜单由独立 owned HWND 呈现，复用同一 UI、SS、字体和 GPU renderer。
- 路径栏提供对象选择和前后导航；类型＋名称行接入真实文档名称及撤销。参数页签、嵌套内容、整宽折叠标题、颜色通道与滚动条沿普通 row/column/Flex 组合。
- 单行文字和数值编辑共用尺寸入口；标签垂直对齐、部分边框、内沿、水平渐变和指示图形统一由共享样式/绘制表达。停靠标签使用一致正体，hover 不改变底色。
- 精度阶梯采用固定七档、共用绘制/命中几何、逐步增减和原业务事务。旧的字段步长派生档位及整段文字排布已替换，原普通拖动的步长合同保留。
- 全局 UI 使用 Sarasa UI SC，数值使用 Source Code Pro；删除 Source Sans 3 资产和旧部署引用。主窗口与原生菜单使用同一字体集合。名称字段恢复 UI 字体与常规字重。
- 当前合同维护在模块文档，截图测量与各次历史验收保留在研究记录；移除最后的“待窗口验收”状态，修正菜单路径说明。

## Standards

审查发现并修复 1 项输入生命周期问题：数值或阶梯拖动期间按 F10，旧实现仅释放系统 capture，未退役主 Session 的抓取状态。统一菜单开启入口现在先执行 `cancel_interaction()` 及其 effects，回滚业务编辑后再交给菜单。

定点复核确认字段草稿原有提交语义不变，effects 重入期间接受帧引用有效。新增真实窗口回归覆盖拖动中打开菜单、鼠标释放被菜单消费、关闭菜单后继续移动，核对值、历史、捕获和阶梯均无残留。修复后未留存已确认的规范问题。

## Spec

独立需求审查未发现可确认的高价值缺漏或越界实现。最新截图已核对单行高度、中文名称、标签对齐、嵌套缩进、折叠与七档阶梯。

## 当前边界与依据

工作区仍为单宿主停靠；多份同类视图、独立浮动编辑器视图和持久布局未实现。数值阶梯仍为主 Surface 内的覆盖层，菜单已使用独立原生窗口。当前没有完整 Ramp、动画参数、表达式或色轮弹窗。
