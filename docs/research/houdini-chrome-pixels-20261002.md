## 共用设施

- SS 新增 border-edges、border-inner-color、indicator-color、combo-indicator、scrollbar-button-size 和 scrollbar-image；既有 linear-gradient 支持 to right / to bottom。
- 方角细边对齐物理像素；普通完整 solid 圆角继续原单实例路径，部分边和内沿沿原 DrawQuad 合批。不新增 RHI 协议或专用编辑器绘制分支。
- 渐变仅在解析时生成 256 字节纹理，相同声明共用；图标继续按形状/尺寸缓存抗锯齿 Coverage。自动细滚动条不足 8 DIP 时不生成无法辨认的步进图标。
- 路径栏提供 World/Actor 选择与前后导航，沿独立原生菜单和 Session::select 执行；Workspace 保存最多 64 个不保活的选择身份，失效成员清理，不写场景撤销历史。

接口和属性合同分别维护在 [UI 模块](../modules/ui/README.md) 与 [SS](../modules/ui/style-sheets.md)，不在本记录复制解析规范。

## 页签与折叠容器补充校准

后续三张局部截图（`b2b02f57`、`12002617`、`5e7abee8`）进一步明确了容器关系：

- 停靠页签：选中底色 `#494949`，未选中 `#2e2e2e`；共用细分隔边，选中底边与下方区域相连，hover 不改变底色。继续保留整个编辑器一致的正体字。
- 折叠标题：`#333333` 平面底色，常规字重；图中高 42 像素。标题贴满当前内容区，字段的缩进由展开内容的 column 负责。键盘焦点只保留底部细线。
- 内容页签：第一层从其容器左缘开始；截图中内层整体右移 13 像素、上方留 11 像素。编辑器使用父容器的 8 DIP 左缩进及 7.333 DIP 上留白；页签自身不累加内边距。一级内容为 `#3d3d3d`，内层内容为 `#363636`，边界沿页签栏底部细线延伸。

现有 Controls → Appearance 中的 Color/Channels 是实际嵌套消费者，颜色编辑、折叠、组内方向键与独立页签选择继续使用原入口。窗口验收增加父容器缩进、标题全宽及折叠后截图检查；本次证据目录为 `out/tab-nesting-20261002/{dev,release}/`。

## 单行编辑器与精度阶梯

用户后续截图（`b5ab708d`、`3d6e98c5`、`bcfc4954`、`457e89c3`、`b7a5f857`）显示名称、Filter 与数值行存在尺寸和标签对齐差异。修正统一到 `single_line_layout` 的 23 DIP 最低高度；名称采用全局 UI 字体，文本修改状态保留色差，数值修改状态继续加粗。新增 SS `text-vertical-align` 控制文字在内容框中的位置，保留显式首基线布局优先。

阶梯参考图中的七格、细灰边、中央文字和金色选档改为实际共享弹层绘制。交互依据 [SideFX value ladder](https://www.sidefx.com/docs/houdini/basics/ladder.html) 的上下选精度、左右增减和 Alt 乘法语义；本站实现的具体步距、Shift 细调和缓存合同见 [UI 模块](../modules/ui/README.md)。当前阶梯仍由宿主 Surface 内的捕获式覆盖层呈现，未迁移为独立原生窗口。

窗口验收的覆盖与边界见[编辑器验收入口](../modules/editor/README.md#验收入口)，不以固定版本的通过记录代替当前组合验证。
