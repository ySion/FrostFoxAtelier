## 目标与首版边界

MS 是遵守引擎输入输出契约的材质着色程序，定义源码、参数接口、默认值和渲染策略。MI 引用 MS 或 MI，保存显式参数覆盖，不复制计算逻辑。StandardPBR 是一个具体 MS，不是全部材质唯一的字段集合。

- 引擎提供世界位置、几何法线、着色法线、切线框架、UV0 等约定上下文；消费者需要的实际字段、坐标空间与可用阶段在 B0 共同接口中确定。
- 输出为标准金属度/粗糙度表面：线性基础色、粗糙度、金属度、世界空间着色法线、线性 HDR 自发光与遮罩覆盖值。光照积分和合成仍属 Renderer。
- 参数首版覆盖浮点标量、向量、颜色、二维纹理及采样设置。每个 MS 自己声明接口，不强制所有材质拥有同样的贴图数量和参数名。
- Opaque/Masked、双面显示、双面发光先由 MS 决定，不混作逐像素输出。首版 MI 修改普通参数，不开放静态编译参数的任意组合。
- 不同时加入半透明、任意 BRDF、顶点位移、完整节点编辑器、通用 GPU 计算语言、Source 相机或完整资产 Cook 平台。

## 源码、编译与代码寿命

复用现有自有语言前端的纯计算子集，生成 HLSL 并接入现有 DXC/RHI 编译；CPU 查询复用同一语义的纯值执行能力。不新造材质 DSL，不尝试将任意 HLSL 文本在 CPU 上解释。

```diagram
┌──────────────────────────┐
│ MS 源码与参数声明          │
└────────────┬─────────────┘
             ▼
┌──────────────────────────┐
│ 现有类型化前端 + 材质检查  │
└───────┬───────────┬──────┘
        ▼           ▼
┌──────────────┐ ┌─────────────────┐
│ CPU 纯值执行 │ │ HLSL → DXC/RHI  │
│ 覆盖等查询   │ │ 光栅/阴影/射线  │
└──────────────┘ └─────────────────┘
```

首批允许纯值数学、局部变量、条件、无递归函数及引擎提供的纹理采样操作。拒绝对象创建、GC 引用操作、协程、任意宿主调用和无界循环；在类型化计算表示上检查实际可达代码，不用文本黑名单。具体操作集合按两个真实原型所需扩展，不预造注册中心或备用后端接口。

B0 的实际共同值声明为 [`material::Context / Output`](../../../src/material/program.hpp)，由 `atelier_material` 一次注册到现有 Runtime 类型目录；编译器捕获真实 CPU 字段布局并生成 HLSL，不假设两端内存布局相同，也不反向依赖 material 模块。覆盖输出是有符号余量，Masked 保留 `coverage >= 0`，Opaque 忽略；法线均为未 face-forward 的世界方向。

B0 建立普通 `Params` 记录及 `shade(Context, Params)`、`defaults()` 入口，先开放 float/vector2/3/4 参数叶；字段路径是所属 MS 内的稳定键，顺序不是身份。`defaults()` 只求纯值、不采样，材质可达闭包仍拒绝循环。B0 初始的常量数字采样槽已由下述 B1 具名输入替换，不保留旧数字语法；CPU/compute 的 LOD0 验证仍不代表光栅任意 UV 梯度已实现。

当前 [`source::MaterialProgram`](../../../src/source/material_program.hpp) 已验证独立 CPU 入口、具名采样、同名 Params 改版和编译 Runtime 关闭后的代码寿命；两个实际生成模块已组合通过 DXC 及真实 compute。GPU 验收覆盖同次 dispatch 的两个程序、字段反序重绑、索引交换、仅参数修改、独立资源环境和失败候选保留旧内容，采用实际 GBV；不代表光栅/RT 产品路径已迁移。复用前端和代码生成逻辑，不把依赖活 Runtime 的 `source::Program::Entry` 或 `Lease` 直接放入可独立存活的 Surface。执行内容须拥有所需代码和不可变数据，不能保留 Runtime 根、借用地址或设备句柄。

参数声明是唯一权威。编辑器、MI 校验、持久化和 GPU 布局消费同一声明；持久参数键与显示名、Runtime FieldId、GPU 偏移分开。沿用共同值类型语义，不为每个 MS/MI 创建另一套业务类型身份。持久参数声明的具体语法和布局在 B0 产物确定后收敛，不能先以无类型 JSON 属性袋替代。

### B1 具名纹理接口（已实现并通过联合验收）

- 保留数值 `Params/defaults()`；有纹理的程序使用 `shade(Context, Params, Textures)`，无纹理仍用两参数。Textures 是普通嵌套资源记录，叶为 material 一次真实注册的 `TextureInput` plain record。它表示编译器注入的程序本地采样输入，不是 Texture 对象或资产键；按值复制/传参可以，自行构造令牌、整数采样或将它放入数值 defaults 不可以。编译器接收实际 TypeId，不靠类型名字猜测。
- 令牌通过真实注册的 `slot:uint32` 字段投影提供 CPU 布局，偏移来自实际成员的 `offsetof`，编译器沿同一 ValueLayout 捕获并处理每层嵌套偏移，不假定为零或新增裸偏移参数。该字段是编译器布局信息，不是作者参数；材质 AST 拒绝 Source 对其成员的读写和整数转换，原生默认构造只提供存储。
- 数值与资源声明都从源码导出，以字段路径共享稳定键空间，冲突拒绝。资源字段路径映射到该编译版本的槽，重排不按旧槽重绑，不按图片去重。B1 将全部声明输入作为绑定合同，不另建逐输入可达性分析；这不等于声称每项在每次执行都被采样。
- 数值默认值仍只来自 defaults；纹理默认关联、采样默认、颜色解释及空输入值由 MS 的类型化作者数据按声明键保存，不在源码引入资产字符串构造器。MaterialProgram 只持声明和计算内容；宿主冻结实际源码与资源输入，material 捕获精确图片和设置。定义与默认资源同候选发布，不允许混用不同版本的槽映射。
- `TextureInput` 保留给计算输入值；作者/历史中的关联值使用独立的 `TextureBinding` 角色，只保存关联键和采样设置。State 另按作者项一一对齐携带解析根，纯候选解析按同一顺序携带精确 Image；不复制带根/无根两套作者 schema，也不把令牌当作者值。对象内的根转为正式引用，Surface 只拥有精确内容。颜色解释及线性 float4 空输入值属于 MS 输入合同；MI 可以覆盖纹理关联和采样设置，不能偷偷改输入的颜色语义。显式清空采约定空值，绝不回退父纹理；坏的非空键保留并诊断，不能当清空发布。
- 首个增量保持 LOD0 双线性与现有寻址方式；UV 变换、通道选择由普通 Params/Source 计算表达，不再暗加固定六路变换。CPU evaluate、HLSL 外层 ms_shade/environment 与采样桥的调用形状保持，由内部注入资源记录。光栅梯度、射线足迹仍在 B2 解决。

## 对象、继承与发布

- MS/MI 使用现有 Runtime 业务身份、正式引用与事务；编译内容和 Surface 是拥有型不可变值，不是新业务对象世界。实际原生表示由当前接口需要决定，不为名词建立空祖先或透传类。
- B1 采用非空 Material 公共角色承载资产键、正式资源边和发布缓存，MaterialSource/MaterialInstance 分别持定义或父边及作者项；MI 不派生自 MS。注册名为 material.Resource/Source/Instance，避免与待删除的旧 material.Material 重复，不增加兼容别名或 Runtime 抽象类能力。
- 继承是单父、无环关系，支持 MS→MI→MI；不再将“有父”当作场景私有实例，也不按链条层级生成类型。首批用具名与场景实例验证，具体更深链的资源限制不伪装成另一种语义。
- MI 保存本地值和显式覆盖意图。同值覆盖仍成立；继承、显式清空和非空键但缺失的纹理不同。关闭覆盖恢复继承，求值不回写作者值。
- 本地作者值采用同一个稀疏集合：字段路径、类型化本地值及覆盖启用状态。无条目、启用条目、关闭的休眠条目分别表达未作者、显式覆盖和保留本地值；关闭不删除，保存重开仍保留，明确丢弃才删除。声明不匹配是派生诊断，不再存一份可失真的匹配标志。关闭期间父值继续更新有效值，再启用恢复原本地值；预览取消须恢复原条目存在性。
- 稳定捕获复用当前有效内容；父或资源改变时不能仅依据子对象写代号复用旧结果。不在每帧重新读目录、拼源码或构造完整作者状态。
- 参数删除或改类型不得静默丢弃覆盖。启用的失配条目阻止新有效内容发布；休眠失配保留并诊断，但不阻止继续继承。只有完整合法的有效候选可以发布，不用产品旧格式兼容来处理作者冲突。
- 具名资产使用资产文档历史；场景实例使用场景历史。Undo 恢复本地作者值、覆盖与引用意图，不回滚父资产历史；导入内容不作为参数历史的一部分。资产操作与引用撤销的已定/待定边界见[资产现态与参数撤销](asset-system-plan.md#当前范围资产现态与参数撤销)。当前携根/内容的 State 是装配表示，不能直接等同于目标历史记录。

源码及实际依赖先冻结，再校验、准备 CPU 执行内容及所需 GPU 管线。相关程序、参数布局、资源绑定在所有必要内容就绪后协调切换；编译失败或过时结果不替换当前有效内容。草稿与已发布内容明确分开。旧帧、代码租约和实际消费者继续按真实使用期持有原内容，不以“不提供资产历史”为由破坏寿命。

material 的同步更新只保证目标对象在失败时保留原作者态、正式边和有效内容，不伪称 Runtime 已有全图事务。宿主当前使用集合的发布仍必须成组：本次变化影响的必要子 MI 或可恢复的 GPU 准备失败，继续使用上一完整有效组，不能以新祖先搭旧后代冒称成功；编码/上传后的终态错误不在保旧 GPU 可用的保证内。完整视图不意味着每次重建全部材质或强制采用所有最新草稿；受影响闭包与未变内容复用的建议、独立坏草稿的隔离边界见 [Live 重评](live-resource-reassessment.md#一致性保留完整视图缩小真正需要重做的部分)，尚待宿主实施验证。

宿主交接以现有 Session 持有候选与当前完整组，Application/runner 协调所需 GPU 准备；抽取场景前复核并采用，runner 首组须在 start 前就绪。复用 Session revision、presentation identity，以及独立源码缓冲的 CodeDocument 身份/revision，另核对精确内容和关系；这些观察令牌不进入代码构建键。材质解析使用明确的父候选内容，Renderer 就绪结果对应同一候选；单对象 capture 或全局 view.ready 均不能代替整组验证。失败保留旧组，无首个有效组时明确未就绪，不创建第二套业务身份或通用发布 manager。

Session 的请求 serial 每次请求均前进，包含失败、同输入重试和 A→B→A，旧请求不因内容再次相同而恢复采用资格。最终采用只替换已准备内容 owner，不重新调用会捕获活父的 `update_instance`。根留 Session；旧帧、GPU 准备与跨线程内容只持无根 owner。历史恢复本地作者意图后仍与其他文档当前内容组成新候选，不撤销父资产历史。

构建键覆盖实际源码/依赖、参数接口、静态设置、引擎材质契约和编译器信息。普通 MI 参数值、图片像素更新不应触发代码编译。后台不得从活目录重新解析最新 include 混入旧候选；复用现有编译器和缓存，不平行建设第二套通用构建平台。

## Renderer 与 CPU 消费

当前 inline RayQuery 必须按命中的材质执行表面计算，不能只为光栅换一个 shader。首版优先评估按实际使用的 MS 集合生成函数及分派入口，复用现有管线准备机制；多个 MI 共享代码。不立即重写整个 DXR 管线，不按每个 MI 编译，也不每帧重建程序集合。

同一材质定义贯通工作室、GBuffer、阴影、编辑深度、射线命中、DDGI 与 CPU 点拾取。现有固定 emissive 判定、Mask 变化检测、BLAS opaque 聚合和历史兼容也属于迁移范围，不能只替换主颜色函数。

CPU 查询也消费宿主已采用组的精确 Surface，不经 render_items 临时捕获活作者态绕过发布门槛；屏幕拾取继续服从 accepted-frame 合同，渲染 skipped/not_ready 不把命中帧换成未显示组。旧帧及设备资源按实际使用期退休，不因候选采用就立即销毁。

纹理采样是引擎操作。光栅梯度、射线足迹和 CPU 点查询采样政策明确区分；统一语义不承诺不同过滤条件或后端浮点逐位相同。CPU/阴影/射线覆盖及阈值附近需有区分力对照；法线方向、颜色空间和镜像变换沿真实消费者检查。B0 先暴露并解决这些差异，不用白色常量材质的成功替代。

### B2 首增量与就绪合同（已选方向，尚未实施）

- 采用候选专属、owner-thread、move-only 的 `MaterialBatch` 拥有 GPU 准备内容，宿主与 Session 的完整候选配对；Frame 只在调用期间借用，槽索引属于该 batch。不新增 activate 或 manager；具体宿主声明仍须共同对齐。相同 Surface 集合不能代替相同网格槽关系或候选身份。
- `ready` 表示该候选所需的全部材质通道管线和绑定已可在同一 Context 中有序执行，上传排在首次读取之前；不表示 GPU 完成、Present 或扫描显示，不为 ready 调用 `finish`。收取任务结果可以完成 owner-thread 资源准备，不能把它描述为无副作用的只读查询。
- 编译、反射、PSO 的可恢复失败只归对应候选，不污染旧组或后续修正候选。进入资源上传/编码后的失败沿现有 Renderer 终态处理，只允许关闭/析构，不等同于已证明设备丢失。batch 在 Renderer 关闭前释放；存活 batch 的 busy 检查须早于任何破坏性清理，GPU 资源沿既有延迟退休，不逐对象等待 GPU。
- 首增量采用两个不采纹理的真实 Opaque/Masked MS，用 UV/世界位置及运行期参数改变 coverage，并包含离屏发光；目标贯通工作室、GBuffer、阴影、编辑深度、inline RT/DDGI 及整组采用/真实 CPU 点拾取。原生渲染阶段不改 Examples、不造新旧 schema 转换壳，也不算完整 B2；Editor 正式绑定/历史闭环须先满足下述迁移前置，再验证兄弟失配与迟到候选等宿主行为。

上述宿主闭环还受正式引用迁移约束：StaticMeshComponent 目前仍引用旧 `material.Material` 并调用旧 capture。绕开它传入一张测试 Surface 表，只能证明原生渲染链，不能签收 Editor 正式绑定/历史闭环。若切到 B1 公共角色已经迫使唯一 loader 改变，则先完成采样、正式 codec 和必要数据转换，并同候选切换；不能同时承诺首包切产品又绝不改 Examples。尚未满足这一前置时，首增量仅签收实际完成的原生渲染范围。

纹理阶段须按下述合同实施和验证，不以无纹理结果证明采样正确。静态排查尚未找到有界、正确性无缺口的合法 MS→ProgramSurface→DXC/PSO 必拒用例，此公开层失败实测明确保留为覆盖缺口，不阻塞原生无纹理首增量，也不能标成已通过。实现仍须隔离候选错误并审查收尾；前端拒绝、取消及旧 RHI `#error` 都不能替代这一层证据。不为制造测试而新增故障开关、耗尽资源、破坏生成源码或故意保留编译器缺陷。上述合同选择不代表新运行证明，也未分配构建/GPU 时段。

### B2 过滤合同（已定静态方案，尚未实施验证）

保留现有阶段政策：主光栅含覆盖使用过滤；阴影、射线候选遮挡与 CPU 点查询保持 LOD0；已接受射线命中/DDGI 着色使用显式足迹。过滤着色的 coverage 不重新否定先前的 LOD0 命中判定，不承诺阈值附近跨阶段相等。所有阶段均构造完整真实 Context，不能只传 UV、将其他可读字段置零。

采用材质专属 HLSL 局部足迹传播作为待实现方向：保持中心值、分支/短路和已定数值公式，内部传播两个方向的变化量，将最终 UV 足迹交给过滤桥；CPU/JIT 与作者语法不变，不建立通用自动微分框架。原网格 UV 梯度无法替代 `uv*32` 或纹理驱动坐标的实际足迹，在非一致分支内调用隐式采样或 ddx 也不是通用修复。纹理值参与后续 UV 时，以相同中心过滤足迹在两个偏移坐标采样来近似其变化；这是分段局部近似，不是跨分支面积积分，额外采样/寄存器成本须如实验证，不能宣称零成本。

公开生成接口采用 `hlsl(namespace, MaterialSampling::point/footprint)`，默认 point。point 保留现有入口与桥；footprint 的 shade 在现有参数后增加同形 Context 的 d0/d1，grad 桥接收 environment、slot、最终 UV 及其两个方向变化。d0/d1 是从零初始化的变化量，不是邻点 Context，不套用默认法线；不新增 Runtime 类型、全局 valid 位或 CPU/JIT ABI。

局部变化的边界规则沿中心所选路径：有限 min/max 相等取第一参数，clamp 原样组合 `max(lo,min(x,hi))`；abs 在正负零取非负侧变化；floor/ceil/trunc/step 的变化为零；fract 在整数处保留输入变化，在实际封顶区取零。lerp 保留加权中心公式及完整 t 变化，端点不能漏掉 t 的贡献。sqrt/length 中心为零时，仅该方向输入变化全零才取零，否则不可用；不以 epsilon 伪造可用导数。这些是不连续点的约定，不宣称它们数学可微。

Rendering 的种子来自同一实际三角形、实例和重心：像素在派发/作者分支/discard 前取透视重心 ddx/ddy，再以本三角形角点生成位置、UV、法线和切线变化。DDGI 保留现有世界尺度 \(\rho=0.01t\)，以射线在命中平面的投影轴及其正交轴形成 \(\rho/|N\cdot D|\)、\(\rho\) 两方向，再用同一重心变化推导全部连续属性；正入射用最长世界边定轴。不任意封顶有限掠射足迹；足迹 \(\rho=0\) 且几何/中心有效时给合法零方向，世界三角形退化、奇点或溢出则使依赖该计算的变化不可用。归一化着色法线用相同插值的局部变化，切线 XYZ 不偷加归一化；几何法线和手性变化为零。退化 UV chart 不废弃有效世界位置等其他属性。这是局部切平面近似，不是精确射线微分，其他射线消费者须显式提供自身世界足迹。

不可用方向分量用非有限 d 表示，只沿实际所选数据路径传播；无关坏法线不能污染常量 UV。最终 UV 有限而任一最终梯度非有限时，该样本用实际最粗 mip，不向硬件传坏梯度；跳过邻样本，并将两份采样结果变化标为不可用。梯度有限但某一偏移坐标溢出时，保留中心采样，仅该方向变化不可用。仅梯度换算纹素尺度溢出时，由桥内部选最粗 mip；有限偏移仍使用同一梯度调用该桥并作差分，不要求 float4 返回值额外携带降级标志。中心 UV 非有限仍不属于有效作者结果，不由本规则修补。

以上非有限传播不能仅依赖优化器保留普通浮点表达式：生成器须保护需要保留的传播/检查和中心数值公式，并在实际生成的 DXIL 与公开输出中验证，不能把不可用变化重写成零，也不为此全局改变 RHI 编译政策。后续用非对称三角形、镜像/非均匀变换、近远/掠射、退化 chart、无关坏属性和可区分 mip 验证；当前没有 GPU、外观或性能证据。无纹理首增量不依赖这些接口，不据此扩大其签收范围。

## 资产、编辑与单基线迁移

Reader 只读身份、源码与依赖快照，不持 Runtime 根、设备或作者历史。Project 负责创建/保存/导入事务；Session/宿主负责资源装配、文档、历史和发布协调。material 负责参数、继承和消费内容；Renderer/RHI 负责设备表示及退休。

MS 与 MI 的资产种类必须与语言 Source 清楚区分；格式复用 assets 的单一 codec。源码、声明的默认纹理、MI 父链和实际使用资源进入依赖闭包，repro 比较真实快照而非缓存全集。引擎摘要须包含实际程序定义与契约，不以默认参数摘要代替源码一致性。

宿主与资产的接线方向已明确，World 已给出 MS/MI 角色值、拥有型 FrozenMaterialNode/显式父 owner、Reader::source、直接依赖、共享 codec 与显式摘要的声明草案。MaterialReceipt 配对精确输入 owner 与内容摘要，不是编译或采用证明；跨进程接收后仍需重建、重算并比较。声明尚未编译，持久格式字段/版本仍待正式接线冻结；r2 的传输段已转为历史提案，其余作者/摘要交接继续有效，以下合同尚待生产实现与端到端验收：

- Scene 先分配/保留材质 LocalId，再递归归档场景 MI 父，共享父只归档一次；场景父用现有 `$ref` 外壳，具名父保真实资产 key。加载先索引定义再按父依赖准备，环、缺父和错误类型阻止有效候选，未发布资源沿既有 Prepared 回滚。Scene 只编解码身份/父引用，entries 复用 World 唯一 codec；独立 `.material` 保存时父仍只有场景身份则拒绝，不拉平或伪造 project 键。
- Session 在编译前冻结精确 SourceFile，逐节点把源码、作者项、Image、显式父内容凭据及同次 Surface 交给 World 摘要；mesh 另交槽名/顺序、默认 key 与对应节点凭据。原文件字节校验与实际编译文本的 UTF-8/BOM 归一语义分开；不按 key 回读，不只 hash 参数 bytes。MaterialProgram 不负责事后恢复来源，摘要仍由 World 单写。
- strict 的 report/keep 规则不变。只有成功 InstanceResolution 的非阻断 AuthorDiagnostic 经 Scene 窄追加点保留为 warning；启用失配、坏父或必要资源失败不能借此降级。Session 当前问题列表须消费本次作者候选诊断，按作者身份/path 随请求替换；修复后移除当前问题，加载报告仍保留历史事实，不把对象上一次成功发布的诊断当 pending 状态。

作者集合与严格执行依赖分开处理：休眠纹理项保留路径、类型化本地关联、采样值及关闭状态，即使键缺失或声明不再匹配，也只产生非阻断作者诊断，不强制解析 Image/Runtime 根或计入必需纹理集合。恢复声明不会自动启用；重新启用须重新校验。共享 codec 只检查类型化结构，不读目录删值或把坏键改空；严格打开仍拒绝阻断诊断，不能全局放宽 strict 或把休眠诊断伪装为 info。

严格根来自实际 Scene 资源位、全部 World 成员和 mesh 默认关系，沿父链逐节点校验。MS 的全部声明默认绑定和每个被依赖 MI 的有效绑定都必须有效；子 MI 覆盖为 U 不排除 MS 默认 T，后代也不能掩盖祖先的启用失配。显式空是合同允许的绑定，坏非空键不是。关闭作者项不等于剔除 disabled World 对象；宽容复制的文件集合或未用缓存也不能扩大严格根。

作者摘要编码全部稀疏项及父边，包含休眠值和启用状态；MS 内容摘要编码实际源码、数值声明/defaults、资源声明及按稳定键保存的类型化默认关联、采样、颜色解释和空值。必需图片按实际捕获内容编码；不为休眠坏键取图片摘要，不编码匹配诊断、内存 padding 或编译期 slot，同图不同输入的关系分别保留。作者摘要变化不等于有效 Surface 或代码构建键变化。

repro 对每个已加载版本先核对内容与槽关系，再去重，并在旧文档退役前双向核对实际候选与 manifest。冻结源稿可以忠实输出；若外部图片只可复制最新磁盘且已不同于捕获内容，应拒绝 dependency_mismatch，不能拼成混合版本。休眠项不是执行依赖，不免除包内已有文件的完整性检查；保留现有“允许带诊断导出、严格重开拒绝”的合同，不将每次 export 成功等同于可执行包。这些是 B1/B2 的消费约束，当前基线尚无新的统一 material_dependencies 实现。

独立 Play 与 Live 消费同次发布冻结的材质输入，不仅传 key 后重读最新磁盘。具名纹理使用 MS 域内稳定输入名，再映射到本编译版本的采样槽；同图不同采样输入仍是不同关系。World 的单一 codec 编码上述稀疏作者值，不物化从未编辑的继承默认；具体字段编码与资源声明在 B1/B2 统一接入时冻结。

普通 Scene 仍保存作者文档；Play 的私有输入另带精确发布内容与对应绑定，不能将新 Scene 绑定拼到旧组。Live 材质采用仍是不可拆的逻辑操作，成功 ACK 延至子进程完整采用；不扩普通 Live 为全图事务，也不承诺跨进程同时切换。启动确认、顺序屏障与失败处理由 [Live 重评](live-resource-reassessment.md#启动更新撤销与失败)统一定义建议，不把资源可读或进程 running 当作采用成功。

此前 r1 要求传输完整图片，r2 用对端确认的 MaterialBaseline 复用未变图；后者虽避免普通参数编辑重传，却仍让真正的新大图受 16 MiB 命令限额约束。r2 未实施，其声明和反例保留为历史，不再要求 encode/decode 以最后成功材质组作为唯一图片来源，也不在此继续冻结基线字段/版本。

替代方向为同机精确输入供给与编辑命令分离：命令引用已发表的不可变内容清单，资源字节有独立预算与请求保活；复用单一作者 codec，冻结后不读原盘最新版。按用户补充，单机资源服务纳入规划，内部索引按实际查询/缓存需求确定，不引入资产历史仓库、分布式或通用 Cook 前置。具体责任、数据库角色、缓存/请求寿命、受影响闭包及真实大图/撤销/失败验收只维护于 [Live 重评](live-resource-reassessment.md)。这些是设计建议，没有新增运行证据；资产键、内容版本、请求代次、采用 ACK 与 GPU 完成仍不能相互替代。

StandardPBR 和 DefaultWorldGrid 走正常 MS 路径，无绑定采用统一默认，坏关联保留原键与诊断。引擎资产仍由引擎拥有，不给每个工程复制定义，不允许工程冒领引擎身份。

StandardPBR 共享一份计算源码，按实际需求提供策略定义，不预造全部组合。当前 Examples 需要前三组，现有 glTF 导入合同及其真实验收还要求第四组；不能用 Examples 的盘点缩窄已支持的导入行为。这四组也不是通用 MS 策略的枚举限制。

| Coverage / 双面显示 / 双面发光 | 当前迁移需求 |
| --- | --- |
| Opaque / false / false | NewSponza 的 25 份材质，包括单面发光灯泡 |
| Opaque / true / true | 其余 6 份材质、Room/Physic 基本体与不透明 OBJ |

这些是静态作者关系与现有导入规则的盘点，不是运行外观验收。含 alpha 存储的图片仍须在正式转换时沿真实解码结果逐槽分类，不能因存在 alpha 通道就认定透明。组件旧四参数只在无显式绑定且无 mesh 默认绑定时生效，迁移不能再乘到已绑定槽上。

先确定实际声明和消费接口，再定最终作者格式。旧 `.material` 保身份转换为 MI；组件旧字段、导入器、Scene/Live/Control、Examples 与生成工具一起升级。保留显式绑定、共享关系、作者值和原覆盖意图；不能按数值相等合并身份或删除覆盖。

旧 r2 清单可提供身份/来源关系的调查证据，不能直接作为新格式转换脚本的输入合同。无源模型不伪造作者 MI 或持久化默认绑定；真实作者白色材质仍保白；坏关联不转为成功绑定。转换在副本验证后进行，产品只接受新的当前格式；删除被替代的旧字段、读写入口和特殊渲染旁路。

数据转换以唯一新 loader 的实际切换为前置条件，而非机械等待 B3：若 B2 已改变正式引用或作者格式，StandardPBR/DefaultWorldGrid、Scene、Examples、导入器/生成器及受影响夹具必须在同一产品候选对齐。此前可保留尚未迁移的旧生产路径，但不得新增兼容 loader，也不把只通过新原生夹具当作现有工程仍可打开的证据。

## 当前协作边界

- Runtime/语言负责人：纯计算检查、HLSL 生成、CPU 入口及代码寿命，语言/后端直接验收。
- Rendering 负责人：material 内容/对象与 Surface、presentation、Renderer/RHI 消费及 GPU 验收。
- World/资产负责人：assets 值与读取、依赖/摘要、单一 codec 合同及相应读取验证。
- Editor 负责人：Project 写侧、Session/workspace/Control、Scene/Live/拾取、作者格式迁移和 Examples。
- 总负责人：跨模块接口、根构建胶水、分批评估、必要联合验证与本地集成。

共享文件在具体批次明确一个写入者，尤其是 material codec、构建清单及反射归属。B0 已完成两轴复审与定向修复；B1a 保行为归属迁移和 B1 编译/对象/具名 GPU 联合验收均通过，精确受验内容已由总负责人集成。World/Editor 已核对实际对象公共头与消费边界；B2 继续收敛拥有型资产快照/单一 codec、Renderer 候选就绪、Session 整组采用之间的具体交接，不另造全图事务或通用 manager，不提前转换 Examples。构建执行串行安排；此处不要求每项责任都新建库或长期调度设施。

开发复杂度按实际契约控制：验证外部输入、类型、生命周期和真实并发发布条件；不对已证明的内部不变量层层重复检查，不承诺抵御可信原生代码恶意写内存。只有能集中实际复杂度的抽象才保留，不增加一用即弃的接口层或为假设后端配置的空实现。
