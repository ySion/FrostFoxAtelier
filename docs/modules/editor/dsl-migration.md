# 编辑器 DSL 迁移与控件评估

## 目标与边界

阶段目标是让整个编辑器的可见结构、控件选择、布局、样式和组合由 UI DSL + SS 描述。C++ 继续拥有 World、命令、撤销、资源扫描、平台窗口/文件对话框、输入捕获和 GPU 资源。`Viewport`、`DockSpace`、`Table` 可以是有明确合同的原生控件；用一个 `NativePanel` 包住整块旧 C++ 界面构造不算完成迁移。

本次评估基于 2026-10-05 的源码、三项并行审查（区域与控件、手势与生命周期、DSL 结构），以及桌面上的 Houdini Indie 22.0.429。所有后续能力以这里明确的状态为准，不把计划算成实现。DSL 的当前语法与保存更新合同仍以[声明式 UI](declarative-ui.md)为准。

结论：现有 Source/JIT、UI Session、SS、布局和事务发布足以继续增量迁移。最大的不足是控件语义与组合接口，而非缺少另一套 UI 框架。应边迁移真实区域边补共享能力，避免先写一套脱离编辑器的控件大全。

## Houdini 的实际观察

本轮在现有 box1 上进行了以下操作：

- Geometry Spreadsheet 点击 `P[x]` 列头后，点行按该列数值排序，列头显示方向标记；拖动列边界后，列头和单元格同步变宽。点击单元格会区分当前单元格与所在行。这说明表格需要列、行、单元格三个层次，不能用几列文字拼成按钮。
- Spreadsheet 齿轮菜单有独立勾选栏、子菜单箭头和分隔线。点击 `Full Precision` 后菜单关闭，再打开保留勾选；菜单是否展开与设置是否启用是两个不同状态。
- 工具架收起后，下面的窗格立刻回收空间，窄恢复条仍可操作。尺寸应由布局分配，不应在多个区域各自减去一份硬编码高度。
- 参数区有一致的单行输入框、右对齐标签、紧凑的数值元组；标题的类型标签与名称输入框位于同一垂直中心。嵌套内容沿所属容器缩进，不给每种组合强加边框或四周留白。

上述排序、改列宽、勾选和收起均为本轮实际操作；跨应用拖入、节点重挂、多选和任意外部链接行为没有在本轮验证。官方 [Geometry Spreadsheet 文档](https://www.sidefx.com/docs/houdini/ref/panes/geosheet.html)也区分了行过滤、列过滤和排序。[Desktops and panes 文档](https://www.sidefx.com/docs/houdini/basics/panes.html)说明了窗格组合与分隔条操作。借鉴这些可观察的行为，不复制 Houdini 的业务结构或专有图标素材。

## 各区域需求与缺口

| 区域 | 当前能力 | 应补的体验与控件 | 迁移边界与次序 |
| --- | --- | --- | --- |
| 窗口与工程入口 | 工程/场景标题、脏标记、创建/打开/保存、原生文件对话框 | 工程关闭/切换的取消及错误反馈明确；长路径能区分名称和位置 | 原生窗口保留平台所有权；DSL 声明编辑器内部入口，复用同一工程命令 |
| 菜单栏及弹出菜单 | 普通命令、勾选、互斥单选、图标、子菜单、快捷键、独立原生 popup、渲染模式饼菜单 | 打开、焦点、勾选互不冒充；菜单按下即开，关闭即清除 open | 菜单内容由 DSL 声明；列表使用 PopupHost，饼菜单叠在主接受帧；共用菜单模型和命令入口 |
| 工具架 | Create/View、图文工具、收折轨道，完整 DSL 声明 | 普通命令、图标呈现、互斥类别分开；窄窗口应有明确溢出操作；纯图标提供名称和提示 | 保持统一命令表，继续用真实任务补组合 |
| 停靠与分隔条 | 页签移动、分组、分栏、最大化、关闭/恢复、拖动取消 | 活跃窗格与选中页签清楚；拖放预览、最小尺寸；之后布局持久化与重复视图实例 | DSL 声明窗格/内容槽，DockSpace 保留分栏树和手势；统一剩余空间来源 |
| Scene View | 相机环绕/平移/缩放；紧凑 DSL 工具列、真实网格拾取、多选/框选、G/R/S 和变换手柄；显示菜单保留模式单选与 Guides 勾选 | 表面吸附和跨区资源落点预览尚缺 | Viewport 是渲染槽；输入与 overlay 共享接受帧，变换通过 Session 的整组事务进入 World |
| Parameters | 类型图标+名称、连续字段与折叠分组；名称右侧放大镜展开公共查询，筛选所选实例属性 | 欧拉角专用编辑、真实资源引用字段；统一 label/field 中心、窄宽换行策略、禁用原因 | 现有结构已迁移；控件编辑继续走同一事务 |
| Scene Tree | World→Actor、类型图标、过滤、展开、选择和键盘导航；路径栏与树内容均由 DSL 声明 | 空/无匹配区分；行上下文动作和重命名入口；多选需先定义业务选择模型 | 保持只展示 Actor 关系与类型；Component 不塞回树。过滤/展开由共享 Tree 管理 |
| Asset Browser | 工具行、目录树、状态行和 List/Details/Tiles 全部结果由 DSL 声明；共享 Table 支持排序/列宽、网格导航、虚拟绘制及双击/Enter 打开 | 真实缩略图、资产拖放 | 后续按业务补齐缩略图与放置；继续复用数据、选择及资源操作入口 |
| Controls 实验台 | 数值、文本、颜色元组、下拉、勾选、页签、禁用和窄宽案例 | 加入语义不同的 Button/Icon/Toggle/Choice/Menu、表格键盘和长内容；与真实面板共用组合 | 已迁入 DSL，继续与真实面板共用原生控件和参数行 |
| Code | 原生多行文档、保存、文件冲突、跨文件诊断和项目构建/运行，面板由 DSL 声明 | 查找替换、着色、语义服务与调试 | 见[源码工作流](source-editor.md) |
| 状态与诊断 | 状态文字、Actor 数量、Code 编译错误和跨文件定位、Project Output 运行输出 | 多错误列表和调试器 | 结构与文本组合已迁入 DSL，错误来源是实际服务结果 |

目前“没有控件”与“控件存在但 DSL 未开放”必须分别处理：Table、Combo、Checkbox、Tab、Splitter 与菜单节点已开放 DSL；Slider 通过 NumberRow 的 EditBinding 接入，尚无独立节点；对象拾取已沿业务和渲染接受帧接通，跨区资源放置仍需建设。基础输入和参数拖调继续复用共享控件链；CodeEditor 在同一文本核心上增加持久文档和多行视图。

## 按钮与状态模型

行为与呈现正交。图标按钮不是“没有文字的任意矩形”，也不是一种新的业务动作路由。

| 语义 | 输入/输出 | 持久状态 | 典型位置 |
| --- | --- | --- | --- |
| Command Button | 激活一次命令 | 无；pressed 只存在于手势中 | Create、Import、Reset View |
| Icon Button | 同一命令，图标呈现并提供可读名称/提示 | 与 Command Button 相同 | 返回、刷新、关闭 |
| Toggle Button / Checkbox | 请求明确 bool 值 | checked，由实际数据拥有者确认 | Guides、过滤启用 |
| Choice / Radio / 内容页签 | 请求选定的稳定选项 | 一个 selectedValue | List/Details/Tiles、着色模式 |
| Menu Button | 请求打开菜单 | open 由 popup 生命周期拥有 | File、齿轮、Pane 菜单 |
| Combo | 展示当前值并打开选项 | value 与 open 分开 | 变换顺序、资源类型过滤 |

hover、pressed、focus、checked、selected、open、disabled、invalid、modified 不应共用一个 active 标记。键盘焦点仍须可辨认，但无需恢复全局黄色描边；颜色、标记和字重服务各自含义。关闭菜单后清除 open，不能把焦点当菜单仍开着。普通菜单项与勾选/单选项在同一 MenuItem 模型中表达，复用现有输入和绘制链。

DSL 现已开放 `Button`、`ToggleButton`、`ChoiceButton` 和 `Combo`，分别接入命令、布尔请求、互斥组选项和既有弹出菜单入口。`List` 复用共享滚动容器，`Table` 接收有类型的 TableBinding。菜单 check/radio 已在共享控件链实现，菜单内容已经通过 Popup/MenuItem 和组合行开放。

## 表格应达到的最低完整度

第一消费者是 Asset Browser 的 Details；以下能力已在共享原生 Table 和浏览器中实现：

1. Name / Type / Size 共用列定义，表头、行内容、分隔线来自同一列宽；Size 按数字排序和对齐，禁止按格式化字符串排序。
2. 列头单击排序，并显示方向；边界拖动有独立命中区、最小宽度和 resize cursor，不误触排序。拖出表格后可继续已开始的列宽手势，Esc/失焦取消。
3. 稳定资源身份决定行选择，排序不换选中对象；过滤排除所选资源时清空选择，清除过滤不复活隐藏目标。
4. Up/Down/Home/End/Page 导航并滚动显露，整个集合是合理的 Tab 停靠点；Enter/双击 Open，单击只选择，避免选中即创建 Actor。
5. 仅绘制可见行与单元格，不为全量数据建立布局节点。TableData 保存共享的不可变行列数据，选择使用独立轻量值；选行不复制整个目录。过滤、排序、滚动与键盘索引共用数据顺序，选中状态不依赖当前是否绘制了某行。
6. 空目录、无匹配、扫描/导入失败分别反馈；底部操作的可用性与可见选择一致。

首版不提前做可编辑电子表格、冻结列、任意单元格合并或完整多选。真正需要编辑字段时接回 EditBinding 与现有撤销事务。多选必须先定义当前项、锚点、选集和批量动作，而非给每行增加一个 selected bool。

## 手势与作用边界

| 来源/操作 | 当前状态 | 目标合同 |
| --- | --- | --- |
| 按钮点击、Enter/Space | 已有 | 同一目标按下/释放只执行一次；禁用、删除、换绑期间取消 |
| 数值拖调/中键阶梯/滑条 | 已有 | 捕获在手势开始时建立；离开控件仍可继续，松手提交一次，Esc/失焦/目标退休取消；阈值使用一致 DIP 单位 |
| 文本选择、IME、剪贴板 | 已有 | 沿现有文本会话与 token，禁止 DSL 另建编辑缓存；普通窗口验收不替代真实 IME 验收 |
| Dock 页签跨窗格拖动、splitter | 已有单宿主实现 | 专用布局载荷与 drop 预览；内容页签不能获得停靠页签的拖动语义 |
| 表格改列宽与行选择 | 已有 | 控件内部手势；列宽拖动不构成资产拖放；排序/过滤期间按身份保持或取消交互 |
| 资产拖到 Viewport | 待实现 | 开始时冻结资源身份、工程代际、源控件寿命；目标验证类型和可用性；放置预览不创建正式 Actor，drop 时走一次 Create 命令与撤销 |
| 资产拖到资源字段 | 待实现 | 同一资源载荷，字段按类型接收；业务目标冻结为对象/字段身份；禁用字段拒绝 |
| Actor 行拖动 | 尚无业务合同 | 必须先确定是选择、空间父子重挂还是另一个业务操作；不能仅因树上有缩进就允许任意重挂 |
| 外部文件拖入 | 待实现 | Windows drop 适配后进入同一拖放协商；验证扩展名、目录/多文件、工程目标；复用导入服务，不直接在 UI 写资源文件 |
| 外部链接拖入 | 未支持 | 先定义受支持资源类型与明确导入结果；普通链接不自动下载、执行或当成本地文件 |

拖放会话未来应复用 Session 的捕获/取消基础，但不能把当前 `DragPoint{x,y}` 当作资源协议。坐标是几何，载荷是稳定资源或对象身份，两者不同。共同阶段为开始、目标协商/预览、提交、取消；业务在提交时重新验证，任何文档切换、源退役或目标关闭都必须终止旧会话。不要在 drop 时重新读取“当前所选资产”作为原始载荷。

## 视觉与布局准则

- 常驻空间优先用于场景、目录和属性。低频视图设置收进有明确勾选/单选状态的图标菜单；资源来源属于目录层级，不再作为顶部切换按钮。路径与搜索同一行，资源动作复用上下文/更多菜单。
- 搜索属于被筛选内容的父层：参数搜索位于对象标题之后，筛选连续属性区；不预设 Transform／Components 页签。组件组成在 Actor Structure 子页维护。使用空状态表达没有选择或没有匹配，不长期展示操作教程。
- 状态栏背景为 `#191919`；页签栏背景、未选页签和滚动槽为共享 `#2E2E2E`。选中页签、滚动滑块、焦点和菜单勾选各自保持独立表达。
- 保留当前深灰主题、紧凑字体和原有字号标尺；参考截图的物理像素受 DPI/UI Scale 影响，不直接当作 DIP。单行编辑高度继续来自共享 `single_line_height`。
- 参数标签与输入使用同一行高和垂直中心；数字、普通文本、类型标题分别采用既有字体规则。不要用增加字重弥补对齐误差。
- 普通文字按钮按内容与任务决定宽度；工具架图文按钮使用同一紧凑尺寸；纯图标按钮保持足够命中范围，但不放大整个工具区。
- 参数内容页签随所属内容区缩进；折叠条顶格，嵌套只继承对应容器的 padding。组合默认不多插一圈背景/边框。
- 表格头、内容、滚动条在同一裁剪和尺寸来源下布局；无真实溢出时不显示虚假滚动条。
- 长标题、空名称、中英文混合、禁用、窄窗格和 DPI 变化属于同一控件的正常输入，不靠面板逐个打补丁。
- 图标沿现有 ControlIcon/矢量绘制设施扩展，使用项目自身或可明确授权的素材；业务类型图标与操作图标有不同用途。

## 单一执行链与生命周期

```mermaid
flowchart LR
    A[宿主业务快照和动作绑定] --> B[UI DSL / Source JIT]
    B --> C[Control 描述候选]
    C --> D[UI Session 校验与取消旧交互]
    D --> E[提交 DSL 候选]
    E --> F[布局与绘制接受帧]
    F --> G[鼠标和键盘输入]
    G --> H[Action: 控件身份 + 目标路由]
    H --> I[现有 Application 分发]
    I --> J[命令 / 编辑事务 / World]
    J --> A
```

`ControlKey` 标识一个 UI 实例；`ActionBinding.target` 标识宿主动作或已绑定业务目标。同一命令可以呈现在多个不同 key 的按钮上。绑定与 Control 同批准备/拒绝/提交，不能先改外部回调表再等待画面更新。目标改变取消旧按下状态，旧接受帧不能触发新目标。执行前仍检查命令可用性；定向动作不能悄悄改为对新选择执行。

本地 UI 事件只更新实例 state。普通 Button 和 ChoiceButton 事件没有 `event.checked`；Foldout、Checkbox 和 ToggleButton 输出 bool 请求。单个按钮不能同时声明宿主 action 和本地 handler。JIT 不捕获 Actor 指针或直接执行 World 命令。

保持已定稿的保存触发、同步准备、事务提交。性能投入优先放在稳定身份、JIT 复用、依赖失效、可见行虚拟化和避免重复布局；本轮未测量新性能收益，不把这些设计判断写成实测加速。

## 迁移顺序与每步退出条件

| 步骤 | 交付 | 退出条件 |
| --- | --- | --- |
| 1：动作与工具内容 | ActionBinding、Button、Create/View 工具内容由 DSL 声明；清除对应 C++ 按钮构造 | 重复命令、禁用、按下换绑、普通本地事件、源码更新、实际创建/撤销均沿正式链 |
| 2：完整工具架和参数区 | 选择组、收折组合、参数标题/滚动及实例字段、组件结构子页 | 减少 C++ 可见结构；参数输入/撤销/搜索/窄面板不回归；共享组合没有强加 padding |
| 3：视口工具与菜单 | Toggle/Choice/Menu/Combo 语义及 DSL | 勾选/单选可观测；关闭清 open；键盘、禁用、菜单生命周期完整 |
| 4：Asset Browser | 真实 Table、列表/网格、导航/过滤/动作区域 | 可见选择、键盘显露、排序、列宽、虚拟化与实际资源动作一致 |
| 5：完整 Editor 根 | 壳层、DockSpace/Viewport 槽、footer、Controls；重复业务 pane 实例另行建设 | 根布局分配唯一尺寸；删除剩余旧界面构造；不会以类型名代替任意实例身份 |
| 后续操作扩展 | 内部资产拖放，再到外部文件导入 | 渲染拾取/落点、业务载荷、取消、一次撤销有完整合同和端到端结果 |

现有编辑器界面已完成装配迁移：总外壳、菜单栏、工具架、状态栏、路径导航、视口挂载、停靠页签与分隔条、所有现有业务面板、Controls 和独立菜单内容均由 DSL 声明。原生代码保留业务投影、命令执行、停靠模型、窗口/输入/渲染机制。旧菜单、路径、对象标题、内容页签、收折栏及 DockSpace 的 C++ 界面组装路径已移除。

当前参数区展示实例标量与内联记录，Actor Structure 负责组件选择和增删。Class 资产、模板默认值与实例覆盖、多份同类型业务面板以及跨区域资源拖放仍未建设。

## 当前落实与验收

- EditorShell 声明外围区域，DockWorkspace 将原生停靠数据投影为页签、分隔条和业务内容槽；SceneViewport 与 SceneTree 都包含各自路径栏。PopupMenu 与 Controls 已使用同一 Source/JIT 链。
- ToolShelf 根声明收折轨道、类别页签与全部工具内容；共享的轨道尺度由现有 UI 设施提供，展开高度在 DSL 中声明，宿主读取它分配剩余空间。
- Parameters 根组合 PanePath、ObjectHeader、可选搜索和连续 Position/PropertyGroup 滚动区；ActorStructure 独立组合结构树和组成动作；原生 DockSpace 只提供稳定内容槽，拖换窗格保留根实例与编辑身份。
- `ChoiceButton` 使用既有组导航，`ToggleButton` 输出明确 bool 请求。新增内容尺寸、最小宽度、换行与 panel 属性，避免重写布局；命名子组件的点分别名保留现有字段/菜单入口。
- 资源过滤立即清理被排除的选择；清除过滤不复活旧选择。来源使用常驻目录树，视图与类型使用单选菜单，路径和搜索同行；目录失效、Back/Up、上下文动作沿原工程状态和命令链处理。
- ViewportTools 将显示设置收进路径栏末尾的两个图标菜单，释放原整行空间；共享 MenuItem 明确表达普通命令、勾选和互斥组。参数搜索位于对象标题之后，筛选实际字段与类型分组；没有固定业务页签或常驻操作说明。
- 统一相机和 UI 的取消清理，覆盖取消模式、应用失活、失焦及捕获丢失，避免无按键移动继续旋转。
- 源码保存可同时修改工具和参数外壳布局，按原同步事务准备/提交；合法草稿换焦点仍提交，非法草稿切页回滚，不改变既有编辑约定。
- Details 通过 `TableBinding` 接入原生 Table，行/单元格身份、表头、列宽、排序与输入共用接受帧几何。列宽由浏览器保存，拖动预览由 Session 拥有，取消不修改已提交列宽。
- AssetBrowserShell 声明工具行、目录树、内容槽与状态行，AssetResults 的一个 Table 节点声明全部结果视图。浏览器不再构造 Control；旧 VirtualList、可见范围估算、滚动 key 轮换、逐项 Button、逐项菜单选择及旧样式均已删除。目录 Items 按目录、导航和已接受展开状态更新，空闲帧复用。
- TableData 负责共享行列快照，TableLayout 负责视图与密度；切换 List/Details/Tiles 保留同一个控件和数据。绘制、点击、网格键盘移动、重排与末行显露采用同一份当帧几何；呈现变更取消旧按压和旧菜单。DSL 保存可以修改卡片宽高和间距，非法尺寸拒绝整批候选。
- `context` 使用类型化 Key 并保存接受帧路由；换绑取消旧按压和旧菜单。`shrink_width` 复用既有 Flex，目录栏可由 144 DIP 收缩到 96 DIP；布局由 DSL 表达，宿主不再覆盖其尺寸。
