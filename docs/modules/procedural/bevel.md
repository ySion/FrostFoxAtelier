# Bevel · 凸实体倒角

`procedural.Bevel` 的 `surface` 接已经实现化的闭合多边形实体，`output` 给出仍能交给 Volume Scatter、Ray 或下一个建模节点的闭合表面。石柱帽、板材、楔石以及 Boolean 求交得到的凸件可以共用这条路径。一份输入可以包含多个拓扑独立的凸件，每个分量单独计算。凹壳、开口面、未焊接的轮廓和孤立点会返回诊断。需要在具有凹槽的整块网格上选择性倒角，超出本节点当前的拓扑范围。

| Control 属性 | 默认 | 几何含义 |
|---|---:|---|
| `radius` | 0.1 m | 在当前几何坐标中取圆弧半径。两面垂直时，各面退距等于半径。若两面外法线夹角为 θ，退距为 r·tan(θ/2)。零半径原样返回输入。 |
| `angle_degrees` | 30° | 对相邻面外法线取最小夹角，范围 0–180°。共面分区始终跳过。合法输入上无棱入选时保留原几何。 |
| `segments` | 1 | 沿选中棱的法截面将圆弧等角分成 1–8 段。1 段在两处切点间生成平切面。新面的法线随实际切面变化。 |

在空草稿图使用 `graph.apply` 可以得到一块 2 × 0.6 × 2 m 的柱帽。将 `cap.output` 接到 Realize 的原型端口即可沿布点结果重复同一柱帽。

```json
{
  "nodes": {
    "stone": {"type": "procedural.Box", "properties": {"size": {"x": 2, "y": 0.6, "z": 2}}},
    "cap": {
      "type": "procedural.Bevel",
      "inputs": {"surface": "stone.output"},
      "properties": {"radius": 0.1, "angle_degrees": 30, "segments": 3}
    }
  },
  "settings": {"display": "cap"}
}
```

## 轮廓和角部如何生成

1. **建立真实棱。** 先验证原始多边形的平面、面积和凸性，配对反向半边，并验证每个点只有一个闭合面扇。对每个连通件，在局部双精度坐标中检查支撑平面，合并法线与平面一致的相邻面。大型分量沿最长轴划分点的包围盒。若盒子沿平面法线方向的最远角仍在内侧，就跳过整盒的点，否则继续检查。这与逐点验证使用相同的越界判据。一个原始表面可以有多个材质区或 UV 岛。其多边形继续携带各自的来源，同一支撑平面内的对角线不产生倒角。
2. **构造边带。** 将入选棱的两个支撑平面分别内移一个半径，得出圆弧中心轴。沿两面外法线之间的大圆弧取样，两两相邻的站点定义弦。每条弦沿原棱延伸得到一个保留半空间。棱的两端也被同一组平面裁剪，因而楔石仅一条锐棱入选时，两张端面会随动闭合。
3. **填齐交角。** 当一个顶点的所有真实棱均入选时，求它的局部内缩核心。三平面交角有一个中心。多价不对称角的核心可以分成多个中心和短棱。沿每个核心顶点的法线锥构造球面多边形样本，外圈与边带复用同一等角位置，内圈控制多段轮廓。从局部凸包取有支撑作用的割面。只选择部分棱时，相邻条带在保留面上斜接。输出是离散多面体，具体面数取决于交角。
4. **裁剪和发布。** 每次凸壳裁剪以已有边的两个拓扑 ID 为键，同一条边只产生一个交点。沿裁剪面上的反向半边闭合封口，共面细分留下的中间点仍由两侧共享。裁剪后检查原支撑面、各条带与未选棱的相邻关系是否仍存在。写入单精度后再次检验面。若共线分区点舍入到直线一侧，可围绕面内点三角化，并逐片检查方向与可分辨面积。最终验证所有输出半边和顶点扇，随后发布属性。半径吃掉原面或棱、输出精度不足等情况沿 `Result` 返回首错。

保留面的角属性在各自原多边形上求重心权重。新面从确定的一张相邻源面取得材质、组与 UV。多支撑面的新几何采用固定来源，不生成新的 UV 展开。浮点和向量列按权重插值，离散列取权重最大的原元素。输出 `N` 是角法线，保留区域可沿用原法线，切面使用发布坐标的几何法线。零半径和有效输入无匹配棱时，原属性布局与数据一并保留。

几何精度取决于点列存储的 float 坐标。同一源顶点在两片上舍入后，可能在交线附近产生不可分辨的短边。只允许收缩拓扑上已相接、且整个收缩距离都在该分量精度带内的边，然后重新核对特征与闭壳。距离原点 65,536 m 的石块请求 0.001 m 倒角就是一个失败用例。单个非共球角的内移求交上限为 64 个支撑面，单角凸包上限为 2,048 个角向样本，达到上限之外会给出相应诊断。

## 端到端验收

`procedural_acceptance` 将六面盒、带独立 UV 的面、经旋转平移的 48 三角细分盒及真实 Boolean 交集送入同一节点，按解析体积、面积和剖面检查结果。仅削一条锐棱的楔石和偏心四棱锥还要通过下游体积撒点。带凹口的差集与压凹极点的密集球体检查凸性诊断。[程序化几何验收](../../../acceptance/procedural/main.cpp)

`editor_log_smoke_acceptance` 从真实 Control CLI 读取节点和端口说明，在空图建立柱帽，以射线测量单段和三段轮廓。将半径调到无法保留实体时，直接查询与下游 Transform 查询都应传回同一个首错。执行撤销后再次打射线，应得到修改前的命中。[Control 验收](../../../acceptance/editor/control.cpp)

## 实际建模开销

2026-11-25 在 Ryzen 9 3950X 上使用 release 编辑器和真实 Control CLI 测量。用 `graph.apply` 改参数使节点重新求值，从打开 `timings` 的 `graph.inspect` 读取节点的 `cook_ms`。常用配置预热后测 7 次取中位数，时间不含进程启动与管道往返。

| 工作负载 | 输出面数 | 求值时间 |
|---|---:|---:|
| 单个 2 × 0.6 × 2 m 石柱帽，单段 | 26 | 0.106 ms |
| 同一柱帽，三段 | 114 | 0.435 ms |
| 同一柱帽，八段 | 614 | 4.27 ms（一次，闭合、无非流形边和退化面） |
| 32 / 64 / 128 / 256 棱柱，三段，仅选上下沿 | 226 / 450 / 898 / 1,794 | 0.98 / 2.89 / 9.60 / 35.78 ms |
| 8,192 面球体，阈值 180°，无选边 | 8,192 | 11.02 ms（3 次中位数，逐点逐面的旧检查为 55.39 ms） |

在同一图中每次改变原型厚度，交替测量两种顺序。96 件先 Realize 再 Bevel，两节点求值时间之和的中位数为 29.38 ms。先 Bevel 再 Realize 为 1.25 ms。两种顺序都输出 7,680 点、10,944 面、36,864 角，包围盒一致，首、中、末三件的六次轮廓射线命中距离差为零。相同尺寸的重复构件应把倒角放在原型一侧。需要对已缩放或各不相同的构件保持指定几何半径时，应在相应变换之后执行。

## 算法取舍

Blender 的 Bevel 实现分别处理边带、原面和交角，也将偏移模式与几何生成分开。这给了本节点保留一个半径参数、让交角拥有独立几何规则的参照。[Blender Geometry Nodes Bevel 实现说明](https://github.com/blender/blender/commit/c53b03f46a9fd1332dab0d440c72ae510ad10259)

Zhou 与 Qian 的参数曲面研究将交角和相接边带的边界匹配作为独立问题。本实现通过共享圆弧站点保证离散网格接缝闭合，高光的连续程度由分段数和角法线决定。[A vertex-first parametric algorithm for polyhedron blending](https://doi.org/10.1016/j.cad.2009.02.020)

偏移达到临界距离时，可能有一条边收缩为零。凹顶点还可能撞上非邻边，让面分裂。经典直骨架论文讨论了这两种平面偏移事件。这里对保留的凸件采用半空间相交，并在原主要特征消失时返回错误。SideFX 也把防止局部偏移相撞和远处几何相撞分别说明。[Aichholzer 等，《A Novel Type of Skeleton for Polygons》](https://www.jucs.org/jucs_1_12/a_novel_type_of/Aichholzer_O.html) · [SideFX PolyBevel](https://www.sidefx.com/docs/houdini/nodes/sop/polybevel.html)
