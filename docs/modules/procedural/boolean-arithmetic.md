# Boolean 格点算术的适用范围

[格点、换基与分类](../../../modules/engine/procedural/src/boolean.cpp) 使用同一套 [精确谓词](../../../modules/engine/procedural/src/detail/boolean_exact.hpp)。下列界限针对量化后的几何。由浮点输入到格点的舍入，以及输出坐标、插值权重的浮点转换，均在整数推导之外。

## 输入与换基

令 L = 2²⁵。新输入坐标属于 [0,L]，坐标差的绝对值至多 L。三点平面的叉积每个分量至多 2L²，两个乘积和减法在 int64 中均可表示。平面偏置绝对值至多 6L³，小于 2⁷⁸，乘坐标之前已经转换为有符号 128 位 Offset。投影边平面的两个非零法向分量至多 L，偏置至多 2L²。按角点扇累计六倍有向体积时，每项来自一个三角形，整个输入的角点索引为 uint32，因此总幅值小于 2¹¹⁰。

统一记 N=2⁵²、D=2⁸¹、X=2¹⁹⁰、W=2¹⁶⁰。平面满足 |nᵢ|<N、|d|<D。齐次点满足 |xᵢ|<X、0<w<W。以下是绝对值上界，包含相消前的中间结果。有符号 b 位要求正数小于 2^(b−1)。

两个格点单位都是二的幂。取较小单位，旧、新步长的整数倍率分别为 s、t，其中至少一个为 1，两者至多 2²⁵。原点差以该单位表示为整数 Δ，|Δᵢ|≤2⁵⁰。坐标关系是 t·u′=s·u+Δ。故齐次点换为 (s·x+w·Δ,t·w)，平面换为 (t·n,s·d−n·Δ)。把两式代入，新平面作用于新点的结果恰为 st 倍原值。正因子保持半空间方向。分别约去四分量公有的二次幂也保持符号；合法点有 w>0，支撑平面有非零法向，约分循环有终点。

点换基的分子幅值小于 2²¹⁵+2²¹⁰，分母小于 2¹⁸⁵，均在 Wide 内。平面换基的法向幅值小于 2⁷⁷，偏置的任一部分和小于 2¹⁰⁶+3·2¹⁰²，在 Offset 内。约分后还须通过 N、D、X、W 的严格检查才能继续；反复换基不会令下次运算的代数预算不断增长。换基后还逐轴检查 |xᵢ|≤w·2⁵⁰，使包围盒运算和 w=1 快路径的窄化有显式保证。合法切分的交点位于原有线段内，因此坐标区间在后续求交中保持。

## 谓词的逐表达式界限

| 运算 | 中间结果幅值上界 | 实际求值类型 |
|---|---|---|
| 两法向分量的二阶子式 C | 2N² = 2¹⁰⁵ | 首项相乘前转 Offset，另一项同样提升 |
| 三平面交点 | 分子 <3D·2N² <2¹⁸⁸，分母 <3N·2N² <2¹⁵⁹ | C 为 Offset，与 d 或 n 相乘前提升到 Wide。分母变正时逐项取负安全 |
| 平面作用于点 | <3NX+DW <2²⁴⁴ | Wide；w=1 时各分子幅值至多 2⁵⁰，可无损转 int64，Offset 快路径的幅值 <3N·2⁵⁰+D <2¹⁰⁴ |
| 点比较、边插值的有向跨度 | 等分母时 <2X；交叉相乘并相减 <2XW = 2³⁵¹ | 等分母用 Wide，其余在首个乘数处转 Product（384 位） |
| 齐次投影三点行列式 | 内部两类子式 <2XW、<2X² = 2³⁸¹；外部三项累计 <6X²W <2⁵⁴³ | 内部 Product；外部先转 Triple（640 位）再乘 |
| 两平面交线 | 方向 <2N²，矩 <2ND = 2¹³⁴；方向比例比较 <2·(2N²)² = 2²¹¹；矩的比例比较 <2·(2ND)·(2N²) = 2²⁴⁰ | 分别为 Offset、Wide、Wide、Product |
| 沿射线消去坐标后的边平面 | 法向 <2N²，偏置 <2ND；作用于点 <3·2N²·X+2ND·W <2²⁹⁷ | 构造用 Offset、Wide；作用于点时各项在 Product 中计算 |

交点分母非零是调用前提。切分取异号端点之间的交点，端点对应的整段边不会平行于切割面。交线对象同样要求两个平面的法向不平行。以上界限覆盖在此前提下的取负和部分和，并未证明完整网格的拓扑正确性。

## 缝合时的齐次点与支撑线

同一个点的四个齐次坐标、同一条支撑线的六个 Plücker 坐标，都可能从不同面得到成比例的整数表示。缝合用全局哈希表归并这些表示。对每个非零元组，先除去所有分量共有的 2 的幂，再取各分量的低 64 位。首个奇分量在模 2⁶⁴ 下可逆，各分量乘以这个逆元后得到哈希输入。从任一本原整数元组出发，任意非零整数缩放的 2 的幂因子在第一步消去，剩余的奇因子在第二步抵消，负缩放也成立。哈希碰撞通过原坐标的精确交叉乘判等。

点编号按面片的角点首次出现顺序分配。整条支撑线上出现三个及以上不同端点时，沿非零方向轴精确排序，再为每条边插入其覆盖的端点。这样同一条线上的长短边可以共享 T 结点。

## 有限交段与凸单元

只有单元在目标平面两侧都有严格异号角点时，才判定交段是否穿过单元内部。此时两平面交线与单元内部相交于一个非空开区间。单元的每条有向边在这条直线上给出一个半轴约束，最紧的两个约束决定区间的两端。给定一条正长度闭交段，它避开该开区间，当且仅当至少一个约束在两端的值都非正。因此预先取目标面与源平面的交点极值，并对每条边检查两端符号，就可复用同一对精确端点处理后续子单元。共线的不同角点仍保留各自的支撑平面，供端点切分使用。

## 分类与包围盒

凸单元的内部样点可写为顶点按 1,ε,ε²,… 加权的正凸组合。将线性谓词作用到各点，首个非零值决定充分小正 ε 上的符号。齐次分母都为正，逐点取符号仍成立。射线面的法向轴分量为零时不计穿越；其他面先用投影边限制射线，再分别累计严格在上方与同高的有向穿越。每个面在一次累计中贡献 −1、0 或 +1，每个候选射线面在两种计数中至多命中一种。above、at 及两者之和均采用 int64；由 uint32 角点索引限制，输入三角扇的面数小于 2³²。

切分在完整源面包围盒上查候选。分类对每个最终单元用首角的整数包围盒沿正轴查候选：当 ε 趋零，内部样点趋于首角。任意充分小的扰动射线若命中同一个有界目标面，极限射线也必经过该面的闭包围盒。横向两轴使用闭区间相交，射线轴只要求目标盒的上端达到射线起点的下界。整数向外取整允许多收候选。根盒的三轴提前退出另有依据：样点与整个目标闭壳包围盒严格分离时位于外部，有向穿越总和为零，也无同高接触。闭区间相切仍进入查询。首角只用于定位候选，落在投影边或支撑平面上的情况仍按整个单元逐角取首个非零符号。

若目标边两个端点的 w 都为 1，在循环投影轴 (u,v) 中写起点为 (x,y)、有向边为 (dx,dy)。查询角 q 的 w 也为 1 时，计算 dx·(qᵥ−y)−dy·(qᵤ−x)。坐标幅值至多 2⁵⁰，全部坐标差至多 2⁵¹，int64 减法安全；乘前转 Offset，两项之差的幅值至多 2¹⁰³，128 位足够。对 w≠1 的查询角，同式乘正分母得到 dx·qᵥ−dy·qᵤ+(dy·x−dx·y)·w。常数项系数在 Offset 中求值，幅值至多 2¹⁰²；其余乘加在 Product 中完成，总幅值小于 2²⁴²+2²⁶² < 2²⁶³，384 位足够。

这个二维行列式对有向边左侧为正。环顺序与支撑面法向一致，循环投影后将结果乘以法向轴分量的符号，内部统一为正。任一端点 w≠1 时使用原来的平面消元式：在面方程 F=0 上，F 的轴系数乘以内向边平面 E 的值，等于消去轴后的表达式。再乘该轴系数的符号，最终符号与 E 相同。两条路径都按相同角序处理符号扰动。

构造轴向包围盒须分别得到精确 floor(x/w) 和 ceil(x/w)。下面三张整数平面给出浮点近似向下跨过整数的例子。取 m=262149、k=262153，令 y=m(x−k)、z=my、mz+(x−k)=1，则 w=m³+1，x=k+1/w。三张面可分别使用以下三角形，所有顶点都在 25 位格内，交点位于每个三角形的内部。每行的两条边张成所需的原始整数法向量。

| 面 | 三个格点 |
|---|---|
| y=m(x−k) | (k,0,0)，(k+1,m,0)，(k,0,1) |
| z=my | (k,0,0)，(k+1,0,0)，(k,1,m) |
| mz+x−k=1 | (k+1,0,0)，(k+1−m,0,1)，(k+1,1,0) |

用 Python 标准库可重算：

```python
from math import floor

m = 262149
w = m**3 + 1
k = 262153
n = k*w + 1
assert (n, w) == (4722798842865172874351, 18015429321293950)
assert floor(float(n) / float(w)) == k - 1
assert divmod(n, w) == (k, 1)
```

该点的精确边界是 [k,k+1]。仅修正过大的浮点候选会得到 [k−1,k]。若 |x/w|≤2⁵⁰，在 IEEE binary64 舍入至最近值下，分子、分母转换和一次除法各产生至多 2⁻⁵³ 的相对误差。合成相对误差小于 4·2⁻⁵³，绝对误差小于 1，因此对 floor 候选做一次双向整数乘回校正已足够。实现以换基坐标检查保证这一前提，再用 Wide 乘回分别处理两个方向的误差。示例验证了特定算术反例，表中的推导以源码类型与调用前提为依据。

## 可执行算术证书

在仓库根目录运行以下命令，只需 Python 3 标准库。

```powershell
python docs/modules/procedural/boolean-arithmetic-certificate.py
```

[算术证书](boolean-arithmetic-certificate.py) 使用无界整数计算有符号闭区间，对三平面交点的每一类乘法、子式、部分和与正分母规范化检查目标宽度，并检查两个半空间求值分支。实际输出的幅值位数依次为 105、188、159、244、104，对应二阶子式、分子、分母、一般求值及 w=1 求值；此外还需要符号位。

证书验证交点满足三张原平面的方程，且其未规范化分母等于法向行列式。每个方程残差关于十二个平面系数分别至多一次：带坐标 k 的项只乘不含第 k 列的余子式。这样每个变量在取 0、1 时的两个值唯一决定其他取值，逐个展开十二个变量即可覆盖任意整数。实际运行核对了全部 4096 个顶点的三个残差和分母。非零分母经整体取负后为正，任意被测平面的齐次求值等于其仿射求值乘以这个正分母，因此符号相同。脚本也通过同一交点公式重现了前述包围盒舍入反例。

证书核对的是源码所用公式的数学模型以及表中记录的求值宽度。源码强制转换位置、调用前提、编译器对 _BitInt 的实现与整个网格的端到端行为仍分别依赖源码核对、工具链与集成验收。
