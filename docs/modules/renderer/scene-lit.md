# Scene Lit

Scene Lit 是现有 `Renderer::render(Frame)` 的一种视口着色方式。World 持有材质和 LightComponent，Application 从同一 World 生成拥有 CPU 数据的 SceneSnapshot，Renderer 同步借用快照并经唯一 RHI Context 录制、提交、Present。MatCap、Smooth、Flat 保留各自的显示语义，Edit/Play 不选择着色方式。

实现入口为 [scene_lit.cpp](../../../src/renderer/scene_lit.cpp)，它是 Renderer 私有的 GPU 资源与通道拥有者；没有新增业务对象注册表、原生设备、原生队列或第二套提交接口。纯 UI 和空场景不启动 Scene Lit 管线；相关资源在首次非空 Scene Lit 绘制时准备，关闭与尺寸变化沿既有 gfx 退休机制处理。

## 材质和真实灯光

- 不透明金属度/粗糙度材质：基础色、roughness、metallic、线性 HDR RGB 自发光。自发光在曝光前保留大于 1 的值。
- 点光源使用 candela，矩形面光源使用 cd/m²，方向光使用 lux。点光源半径以米表示，方向光角半径以弧度表示；矩形使用米制宽高与单面/双面设置。
- World 唯一负责层级变换与灯的正交方向；Renderer 接收最终位置、传播方向和矩形切向轴。空间缩放不隐式改变灯的物理尺寸、范围或强度。权威数据约束见 [World lighting](../world/lighting.md)。
- 点光和矩形光使用有界距离衰减；方向光覆盖全场景。直接光使用 GGX 表面响应，矩形光对真实发光面积采样。当前没有 LTC 贴图或 RTXDI 依赖。
- 每帧最多 256 盏灯；局部直接光按屏幕分块筛选。阴影预算限制同时追踪可见性的灯数，默认 4，界面可选 4/8/16，单灯样本数 1～64。方向光优先，再按稳定键排序，超额灯仍正常照明。应用显示实际与请求阴影数，如 `Shadows 4/5`；增加第五盏灯不会拒绝整帧。

LightComponent 表示照明源，当前不自动创建可见发光几何。自发光网格是独立材质输入，也可被 DDGI 射线命中；当前没有“这个发光网格属于哪一盏解析灯”的绑定合同。样例中的发光板与解析面光源是独立光源，不用重合的二者重复表示同一个发光面。

## 同一帧的执行链

1. 光栅 GBuffer 写入法线/粗糙度、基础色/金属度、HDR 自发光、运动信息和独立 R32_FLOAT 预期前帧设备深度。当前 D32_FLOAT 深度、前帧 R32_FLOAT 深度与 RG32_FLOAT min/max Hi-Z 都遵循有限 Reversed-Z；方向和背景约定见 [Renderer 合同](contract.md#场景和-ui)。屏幕坐标使用整个窗口，`scene_viewport` 处理物理像素偏移，支持透视与正交投影。
2. 共享不可变网格缓存 BLAS，稳定实例更新 TLAS。内联 RayQuery 完成灯光可见性和 DDGI 探针射线；能力由 RHI 的 `inline_ray_query` 明确报告。
3. 直接光统一估计实际 GGX `f×L×V`：每个灯光样本同时决定表面响应、入射光与真实射线可见性，不把独立平均的光照和可见性再相乘。漫反射与镜面信号分别去除材质调制，使用各自的时间历史、FP32 亮度矩和三个步长的方差引导空间滤波，再恢复材质贡献。法线、切平面、粗糙度和材质约束避免跨 lowpoly 硬边混合。
4. 有限体积 DDGI：规则 XYZ 探针格、八面体方向辐照度与距离矩、可见性加权八探针插值、背面分类、受限位置修正、分帧采样与逐帧照明过渡，以及有界上一轮间接反弹。
5. GTAO 基于深度重建与地平线积分，使用独立历史，只调制间接项。可选 Local GI 提供有界近场漫反射修正；两者使用同一个近场策略选择，保留直接光与自发光。
6. SSSR 使用 GGX 随机反射方向、分层深度遍历、工作列表和间接分派，随后按表面/命中对应关系重投影，使用独立历史计数、FP32 亮度矩与三个步长的方差滤波；空间重建保留材质边界。屏外、遮挡或追踪失败回退到均匀环境辐射。环境控制变量的有符号估计保留至最终 HDR 合成，避免逐样本截零引入额外亮度偏差；SSSR 关闭时环境反射直接通过。
7. 合并 HDR 光照，按抗锯齿设置执行 TAA 或当前帧直通，同时写入下一帧表面深度与法线；随后执行 Bloom、EV 曝光和 SDR 色调映射。
8. SMAA 两种模式在色调映射后的线性 SDR 场景颜色上重建边缘；选择 T2x 时再组合两个独立空间结果。最后沿既有入口合成参考辅助显示与 UI。采用 jitter 的模式在需要辅助显示或 Capture 时，复用深度通道重建公开相机对应的无抖动深度，内部光照历史保留采样深度。

以上通道沿现有显示设置入口控制。低样本直接光的时间与空间重建是有偏工程近似；单灯 1～64 样本沿同一 `f×L×V` 估计路径，64 样本诊断模式关闭直接光时间累积与空间降噪，用于图像对照，不是完整渲染器的无偏参考。当前环境为均匀线性 RGB 辐射场，预积分 GGX BRDF LUT 用于其镜面响应；没有方向 HDR 环境图、场景反射探针资产、透明材质、蒙皮 BLAS、ReSTIR DI、全路径追踪或超分辨率接入。

## DDGI 探针场

默认体积为 `[-6,-1,-6]` 到 `[6,5,6]` 米，`8×4×8` 共 256 个探针，每帧更新 64 个。每次探针更新分开使用 **32 条固定几何射线**和默认 **128 条照明射线**：前者负责背面分类与受限位置修正，后者随机旋转并估计照明，不用随机照明结果驱动探针位移。初始化或没有有效历史的探针一次到达受单元约束的几何目标；已有有效历史的探针缓慢修正。

每轴支持 2～32 个探针，总数不超过 4096；照明射线数支持 1～256，更新预算、体积与密度通过 `ViewSettings::lit` 传入。辐照度使用 gamma 5 空间平滑混合、存储仍为线性 HDR；距离矩为 RG32_FLOAT。静态辐照度/距离历史权重为 .93/.95。已知灯光、环境辐射或材质变化使辐照度进入四轮完整探针覆盖的响应期、权重 .8；几何变化还使距离进入两轮响应期、权重 .85。这里的轮次按真实探针更新预算推进；初始化按实际访问次数预热，不因单次随机样本差异清场。

八探针查询只对朝向与可见性置信度做小权重压缩，随后乘线性的三线性空间权重，避免把每个探针的影响范围锐化成块。累积按实际非零权重和归一化，不把低置信度额外当作遮蔽。查询沿几何法线偏移最小探针间距的 .12，与当前探针几何净空一致，为 8×8 方向距离滤波在墙角提供表面偏移；不依赖相机方向，也没有提高可见性下限或向暗处添加环境光。

分批采样保留独立的辐照度目标历史，已有照明历史在每帧的探针传递中向上一帧目标推进，混合比例为 `min(更新预算, 探针总数) / 探针总数`。因此未在本帧采样的有效探针也会连续响应，不把四帧轮转直接显示成停顿与跳变；采样目标仍按上述 .8/.93 规则稳定。初始化、进入几何或位置修正会同步清除不再有效的目标与显示贡献，下一次有效采样再建立支持。这里增加的是世界空间探针历史，没有增加屏幕颜色模糊、射线或独立提交；默认 256 个探针额外占用 256 KiB 逻辑纹理字节。连续过渡会增加少量收敛延迟。

灯数不超过四盏时，探针命中点逐盏估计解析直接光，避免随机灯选择漏掉小灯。命中点的阴影查询归入 visibility 计数，固定几何与照明的主探针查询归入 probe 计数，所以总射线量不等于“更新探针数×照明射线数”。灯的 `casts_shadow` 也控制命中点直接光阴影；主视图的阴影预算不改变探针接收点的照明合同。

当前仍是有限、低频的漫反射场，有探针插值与更新延迟；不包含相机跟随级联和无限世界流送，也不能单独表达细小几何的全部近场遮蔽。

## 显示菜单与近场策略

Scene Lighting 提供 Shadows、DDGI、GTAO、SSSR、Bloom、Local GI 六个勾选项，以及 Antialiasing、Exposure、Shadow Budget 子菜单。操作仍经 Workspace 的统一 `apply_view` 入口，不改变业务材质或场景撤销历史。

`SceneLitSettings::antialiasing` 为 `Antialiasing::{none,taa,smaa,smaa_t2x}`，菜单显示 Off / TAA / SMAA / SMAA T2x，默认 SMAA。所有模式均使用原生分辨率：

| 模式 | 采样与历史 | 处理位置 |
| --- | --- | --- |
| Off | 无相机 jitter、无最终颜色时间累积；信号自身降噪继续运行 | 当前 HDR 合成后曝光、Bloom 和色调映射 |
| TAA | 八相位 jitter，递归 HDR 颜色历史与局部有效性校验 | HDR resolve，Bloom 和色调映射之前 |
| SMAA | 无相机 jitter，单帧边缘检测、模式面积估计与线性邻域混合 | 色调映射后，UI 之前 |
| SMAA T2x | 两相位四分之一像素 jitter；当前与上一帧的独立 SMAA 空间结果，前帧权重最多 .5 | 与 SMAA 相同，再执行两帧 resolve；最终结果不回灌空间历史 |

SMAA 使用固定版本的上游面积/搜索 LUT；边缘判断读取非线性 sRGB 亮度，颜色混合保持线性。T2x 依据独立 R32 预期前帧深度、前帧表面深度/法线和 motion 校验邻点。它补充亚像素轮廓信息，不替代直接光、反射或 AO 自己的信号降噪，也不承诺恢复单帧完全漏采样的几何细节。原生 SMAA 的 shader、LUT 来源与许可见 [第三方记录](../../../third_party/smaa/README.md)。

Local GI 对应 `ssil`，默认关闭。当前按全分辨率计算半径不超过 1.2 米、强度 .3 的近场修正：以各向同性 `DDGI irradiance/π` 为基线，DDGI 关闭时使用环境漫反射基线；估计有界屏幕空间残差，并保有独立时间历史。它读取已稳定的去材质直接漫反射和 DDGI 间接项，不读取镜面、SSR、最终颜色或自身修正结果，不形成光照反馈环。屏外信息、各向同性基线与残差限幅使它属于受控近似，不能称为无偏完整 GI。

开启 Local GI 会关闭 GTAO，开启 GTAO 会关闭 Local GI；直接调用 Renderer 时即使两者都为 true，也明确由 Local GI 优先。局部近场修正不与 GTAO 重复遮蔽。

## 身份与历史

World/Runtime 仍是业务对象身份与生命期的唯一权威。Application 将完整组件 ObjectId 映射为快照域内的非零稳定键，并在条目离开快照后移除映射；键不保活对象。场景替换改变 `scene_identity`，几何、成员、材质及灯参数编辑改变 `scene_revision`，普通相机移动和连续位姿更新不会每帧清空历史。

Renderer 用前后相机和实例变换生成运动信息，结合深度、法线和局部表面对应关系拒绝错误历史。场景域替换与探针体积重建需要重建相应缓存；尺寸、视口、camera cut 和 AA 采样模式变化清除表面历史，camera cut 保留仍有效的世界空间探针。效果切换经 `lit_history_invalid` 只使依赖变化输入的信号失效，包括受影响的最终颜色历史，不连带清空整个探针场。缺少稳定网格键的旧调用仍可绘制，但不复用该物体的时间对应关系。

运动纹理表达前帧 UV 减当前 UV 与对应有效性；预期前帧设备深度由独立 R32_FLOAT GBuffer 通道提供，不以 FP16 深度或残差恢复。斜面重投影按接收平面的深度梯度校验各邻点；深度容差来自世界空间投影与相对 FP32 误差，避免在反向深度远处用固定设备深度 epsilon 放宽校验。

灯光/材质编辑缩短有关光照历史的响应，DDGI 按上述完整轮转响应；这些编辑不触发全局历史清场。连续几何运动依靠局部对应关系和探针几何响应处理。直接光、SSSR、GTAO、Local GI 与最终 AA 各自拥有历史，照明变化允许短暂平滑响应，不以一帧随机亮度差当作全局重置。探针采样序列属于探针场自身，只在实际更新时推进，随场景域或体积重建重置。

## 诊断与性能边界

`FrameStats::scene_lit_gpu_ms` 为八个阶段的原始 GPU 完成样本：GBuffer、AS/上传、直接光/降噪、DDGI、GTAO/Local GI、HDR/SSSR、HDR resolve/表面历史、Bloom/色调映射/SMAA/显示合成。只有八个 timestamp 与射线读回都对应同一个完成的 RHI 录制序号时，`scene_lit_gpu_timing_valid` 才为 true；`scene_lit_gpu_sample_sequence` 与 `scene_lit_gpu_sample_frame_id` 标识样本。完成结果可能滞后或重复，统计分位数时必须去重；没有用平滑时长计算 p95。

阴影和探针射线数来自 GPU 实际执行计数，与上述完成样本关联。阴影灯数、未获阴影预算的灯数和历史重置数则描述当前编码帧。`scene_lit_resource_bytes` 是资源逻辑字节加 AS 数据量，不包含 GPU 驱动分配开销、scratch 和待退休资源，不能称为显卡实际总显存。

性能入口为 `atelier_renderer_acceptance --scene-lit-benchmark --output <绝对目录>`：原生 2560×1440，预热后收集唯一的原始完成样本，测量阶段关闭验证并且不 Capture。逐项图像入口为 `--scene-lit`，时间响应入口为 `--scene-lit-temporal`，完整质量入口为 `--scene-lit-quality`。`--scene-lit-ddgi` 复用其中的强自发光、整墙接缝、连续运动与薄隔墙场景，使用 debug layer 加快定位；完整质量入口使用 GPU validation 覆盖相同场景。以上入口均可追加 `--output <绝对目录>`，同步图像读回耗时不作为性能结果。菜单与工程入口由 `editor_scene_lit_acceptance` 验证。

这些入口的存在不代表当前候选已经通过。实际通过范围、图片和性能样本由 [验收记录](acceptance.md) 维护；首批版本的 4.25 ms 属于其原采样条件，不能作为新版独立降噪、探针设置与 SMAA/Local GI 的性能结果。

可打开的真实工程见 [Scene Lit Room](../../../examples/scene-lit/README.md)。性能目标基于 RX 6800 XT；目标帧率与最终本机实测应分开陈述。
