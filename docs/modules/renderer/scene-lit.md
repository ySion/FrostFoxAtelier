# Scene Lit

本页维护已实现的光照合同。使用方式与视口合同见 [Renderer](contract.md)，实测结果见[验收记录](acceptance.md)；原生 ReSTIR DI 的理论依据和当前边界见[实现说明](../../research/restir-di-implementation-20261012.md)。自动探针空间分配等尚未实施的方向见[后续演进](../../research/scene-lit-next-evolution-20261010.md)，其中历史参数不覆盖本页。

Scene Lit 是现有 `Renderer::render(Frame)` 的一种视口着色方式。World 持有材质和 LightComponent，Application 从同一 World 生成拥有 CPU 数据的 SceneSnapshot，Renderer 同步借用快照并经唯一 RHI Context 录制、提交、Present。MatCap、Smooth、Flat 保留各自的显示语义，Edit/Play 不选择着色方式。

光照、DDGI 布局和效果参数的作者值为中立共享类型 `rendering::SceneLightingSettings`，由 World 持有，随 Scene v6 的 `world` 字段保存并进入 Session 撤销历史。旧版继续读取；v4 的 `shadow_light_budget` / `shadow_samples` 只在兼容读取边界严格校验后丢弃，新字段采用默认值，v1～v3 使用默认 World 配置。`renderer::SceneLitSettings` 在作者值上附加视口诊断偏好，`Frame::view.lit` 是当帧求值结果。Renderer 不持有或修改 World，Project Run 也从同一 SceneSnapshot 消费场景配置、材质和光源。

实现入口为 [scene_lit.cpp](../../../src/renderer/scene_lit.cpp)，它是 Renderer 私有的 GPU 资源与通道拥有者；没有新增业务对象注册表、原生设备、原生队列或第二套提交接口。纯 UI 和空场景不启动 Scene Lit 管线；相关资源在首次非空 Scene Lit 绘制时准备，关闭与尺寸变化沿既有 gfx 退休机制处理。

接受空场景时，Scene Lit 退休旧 Mesh 所有者、BLAS/TLAS、实例与灯光缓冲及派生发光表；可复用的管线、目标纹理仍保留并计入资源统计。模式退出和清理发生在 CPU 帧准备成功后的编码阶段，被拒绝的候选帧不会清除有效光照历史。同一 Renderer 可以随后重新接收非空场景，关闭保持幂等。

## 材质和真实灯光

- 标准金属度/粗糙度材质支持基础色、roughness、metallic、切线空间法线、线性 HDR RGB 自发光与 Opaque/Mask。六个贴图输入及 UV/采样设置由统一材质表提供，自发光因子在曝光前保留大于 1 的值。
- GBuffer、射线命中、发光采样、辅助深度和选择叠层消费同一表面；Mesh/MTL 默认材质与显式资产绑定走同一解析入口。颜色/发光图使用 sRGB，标量/法线图使用线性数据，详见[材质系统](materials.md)。
- 点光源使用 candela，矩形面光源使用 cd/m²，方向光使用 lux。点光源半径以米表示，方向光角半径以弧度表示；矩形使用米制宽高与单面/双面设置。
- Sky Light 是场景唯一的天光，首版表示均匀入射辐射，颜色乘 cd/m² 强度经 SceneSnapshot 写入 `Frame.environment`。没有启用的 Sky Light 时该值为零；它不进入局部光源候选池，不依据空间变换改变照明，也不自动绘制天空。Scene Lit 背景固定为黑，工作室模式的渐变偏好单独保留。HDRI / 方向性天空尚未实现。
- World 唯一负责层级变换与灯的正交方向；Renderer 接收最终位置、传播方向和矩形切向轴。空间缩放不隐式改变灯的物理尺寸、范围或强度。权威数据约束见 [World lighting](../world/lighting.md)。
- 点光和矩形光使用有界距离衰减；方向光覆盖全场景。直接光使用 GGX 表面响应，矩形光对真实发光面积采样。当前没有 LTC 贴图或 RTXDI 依赖。
- Renderer 的灯光值域与 World 一致：方向光允许零 range，非矩形光允许零 width/height，方向光角半径小于 π/2。局部光源在共享贡献求值入口按真实采样位置检查距离衰减与侧向。
- 默认 A 路径对解析局部灯精确枚举，发光三角形按 `direct_candidates` 个候选做 RIS；ReSTIR 回退路径中点光、矩形光和发光三角形进入同一局部候选池。方向光逐盏独立评估，不进入该池，避免太阳漏选或重复计算。`direct_candidates` 控制每个接收点的初始局部候选数，范围 1～32，默认 8。已移除旧 256 盏截断灯表及四灯阴影槽；下述新精确列表的固定容量只限制快速存储，不截断光源。源数仍受身份表示和实际缓冲大小校验约束。所有选中且 `casts_shadow` 的光源都查询可见性；Shadows 关闭时沿同一求值入口忽略遮挡。

LightComponent 不自动创建可见发光几何。`LightFrame` 沿同一 MeshInstance 快照派生可采样三角形，不创建额外业务对象。世界变换决定实际面积，材质 emission 决定辐射；材质分别控制双面显示与双面发光，相机可见 emission 和采样遵循同一发光侧向。镜像变换后的发光正面沿作者法线的逆转置方向确定，不盲用世界边叉积。静止帧先比较小灯表及发光对象的几何、变换、材质描述和表索引，复用未变化的三角表与 proposal。

局部源的全局 proposal 使用功率估计的统一 alias 表，混合 5% 均匀概率保留支持；发光面权重包含世界面积，贴图用线性平均辐射估计 proposal。CPU 用 double 建表，按实际上传的 float 阈值回算离散 PMF。共享采样域为 `(光源身份, u, v)`，面积 Jacobian、发光余弦、真实重心 UV 的 emission 与 Mask 覆盖在贡献求值中处理，不能把选择 PMF 冒充面积密度。

`LightFrame` 在 CPU 为同一局部源池派生有界近源网格：`16×8×16` 个 cell、每格 8 米，原点随 `Frame::lighting_focus` 按整格移动。点光和矩形光按中心、发光三角形按重心进入一个 cell；每格按全局 proposal 概率保留最多 32 个源，概率相同时以稳定源身份决胜。它不是按灯的 range、发光面边界或真实受光影响范围铺开的 influence grid，也不进行遮挡、SDF 或 room/portal 查询。远源、跨格大光源及 cell 溢出源仍在全局池中，不被剔除。

接收点按相邻八个 cell 的三线性系数乘各 cell 保留源的概率总量（mass）选择 cell，再用该 cell 的 alias 表选择源。每批 `M` 个初始候选采用确定性的技术配额：局部域有效且 `M≥2` 时，`mLocal=floor(3×M/4)`、`mGlobal=M-mLocal≥1`；`M=1` 或局部域无效时全部使用全局 proposal。完整概率为 `q(source | receiver) = (mLocal/M) × q_near + (mGlobal/M) × q_global`，比例按实际整数配额计算，不能固定写成 .75。所有候选统一以 `f/q` 进入 RIS，再以 `sum/M` 归一化，不单独除以所选技术的条件概率。每批保留全局候选，避免随机技术选择使整批都落在局部域；这不保证任一候选具有非零贡献。

空局部域、网格外接收点、空间采样关闭或无法保持 8 米格边精度的极端 focus 退回完整全局 proposal。cell alias 的 PMF 同样由实际 float 阈值回算，八邻选择与概率求值共用舍入后的 CDF 区间。无论候选由哪种技术产生，求值都使用上述完整 `q`；全局技术保留所有局部源的采样支持。

屏幕 DI 的 fresh RIS 与 DDGI 命中处的 fresh RIS 共用上述分布构造、样本域及完整 `q`，DDGI 不借屏幕 reservoir 历史。方向光继续独立逐盏求值，不进入近源网格。网格源版本或整格原点变化时重建并上传，未变化时复用；网格滚动本身不属于辐射变化，不重置光照历史。已归一化 reservoir 权重携带其生成分布的责任，时间复用仍按原有前后源映射和各接收面目标计算 MIS，无需保存或重建旧网格。

解析光的输入计算域沿 [World 灯光合同](../world/lighting.md#灯类型与参数)，由共享检查同时约束 authoring 和低层 Frame；超界帧在编码前拒绝，保留已接受的画面与历史。矩形光先乘已验证的辐射量与面积，再施加有界衰减。MIS 在极大有限 target 下共同缩放 confidence 加权项，并按大小选择乘除顺序，避免中间溢出和过早丢失弱权重；普通范围保留原次序。未夹取 reservoir W。此范围保证的余量只覆盖解析光求值与初始累计，发光三角形的极近 `area/d²`、超出 FP32 的数学 W 及任意历史 target 倍率仍非全域保证，详见[数值审查](../../research/render-pipeline-audit-20261013.md#本轮代码审查与取舍)。

屏幕原生 ReSTIR DI 以初始 RIS 和前帧 reservoir 生成 scratch，再从 scratch 复用最多两个合格空间邻居，写入 current；使用 GRIS generalized balance MIS 在每个输入接收面重新求目标。reservoir 保留样本、贡献权重与受限历史置信度，不保存 visibility；最终着色重新追踪选中源到当前接收点的遮挡。零实现仍代表一个候选分布，不能因本次选中贡献为零就删除其归一化责任。有界近源网格补充全局功率 proposal，尚不是自适应光源树或完整影响域索引；RTXDI SDK 未引入。

共享光源求值先准备与接收面无关的采样端点、发射辐射和侧向参数，再计算各接收面的距离衰减、余弦和 BRDF。ReSTIR 同一候选在当前空间输入之间复用准备结果，避免反复重建端点和读取 emission/Mask；时间输入仍从前帧源快照独立准备，不能拿当前几何或发射量替代前帧。各接收面的 MIS target 和最终可见性继续独立求值，解析面光先乘已验证的辐射量与面积的数值次序保持不变。

屏幕直接光负责发光面到当前表面的漫反射，DDGI 命中着色负责经过另一次表面散射的入射光，探针直接命中的 emission 不再重复注入。屏幕可见 emission 保留；SSIL 读取已稳定的去材质直接漫反射与 DDGI 间接项，不读取 SSR、镜面或表面 emission，避免重复的一跳发光贡献。发光面的镜面路径仍由现有 SSSR 表达，屏幕 mesh NEE 首版不再加一份镜面；离屏发光面镜面缺失仍是限制。没有发光网格与解析灯的绑定合同，样例发光板与解析面光源仍是独立光源，不应重合用于表示同一个发光面。

## 精确局部直接光与缓存阴影候选

`direct_clustered` 经统一 ViewOption/Control 接入，是视口设置，不写 World/Scene。默认 true，使用 A：精确枚举＋端点 RT；false 回退 ReSTIR 路径，仅作诊断对照，回退只需改这一项。同时开启独立的 `direct_shadow_cache`（默认 false）才使用 B：缓存阴影候选。`direct_reference` 优先于两者。实际阴影后端改变时，同时失效阴影驻留及原有 DI/SSIL 等消费者历史；重复提交相同配置不重置。默认切换是[直接光执行计划](../../research/direct-lighting-execution-plan-20261015.md) C 批的第一步（2026-10-18）；A 的发光体复用与 proposal、灯密集场景成本以及 ReSTIR 退役属于第二步。

A 的紧凑光源确定求值，没有随机噪声，平滑的距离衰减在 8 位输出上会显示 1 级量化等照度线；当前显示编码没有抖动。运动帧与静止帧之间有两条路径共有的亚级亮度过渡，会让这些等照度线在放大的差异图里显现为同心环和细线，1× 画面中看不出。这不是 A 的结构误差，见[验收记录](acceptance.md)。DDGI 继续使用既有空间 proposal 与 RT 可见性，不读取屏幕需求驱动的阴影驻留表。

真实地牢的 1440p 对照尚未支持将缓存阴影候选投入默认路径：暖缓存可以零重绘，但 PCSS 着色仍比精确选灯＋RT 更慢，地砖/台阶存在自阴影暗楔。小 ROI 的平面和生命周期通过不覆盖这项质量限制；证据及后续门槛见[验收记录](acceptance.md#精确局部光照与缓存阴影候选2026-10-16)。

`lit_clustered.hlsl` 对实际 GBuffer 接收面构造 16×16 像素 tile、每 tile 四个 view-Z 区间的保守世界 AABB。点光影响域包含有效 range 与球半径，矩形包含面积边界；距离衰减仍在共享贡献求值中处理。每区间最多快速存储 64 个解析局部源，溢出时枚举完整解析前缀并逐接收点检查支持，保留全部贡献。方向光独立；发光三角形使用独立 fresh RIS，暂不引入全屏 reservoir 复用。较大有限点光、范围边缘和矩形保留源内端点 RIS，不能把精确枚举光源身份误称为精确面积积分。

直接光按接收点保守标记随机支持。A 路径只有零半径点光、零角度太阳时，当前 RGB 直接通过重建，历史 count 为零。标记发生在随机抽样与遮挡拒绝之前，不能把一次黑样本当成确定结果。原 ReSTIR 只要存在局部源就保持随机支持；没有局部源且所有太阳为零角度时才直通。B 暂保守保留重建，两者都不做下述分类。零 count 表示没有可复用的随机历史，RGB 仍有效，Compose 与 SSIL 继续读取完整直接光；随机/确定转换不会沿用上一种信号的历史。空间滤波遇严格零方差只跳过本次邻域处理，保留正 count 及后续时间更新，不使用阈值冻结随机信号。

A 路径把接收点距离不小于四倍半径的有限点光和全部太阳当作紧凑光源，辐射确定求值：漫反射取光源中心方向；GGX 镜面取 Karis 2013 的代表点，并以 (α/α′)² 归一化，α′ = saturate(α + sinθ/3)。只有软阴影可见性仍随机，阴影射线终点是光源圆盘上朝向接收点的均匀样本，落到地平线以下时复用中心射线。每条随机可见性射线的结果写入逐像素 R32_UINT 掩码：位 `source%15` 表示可见，位 `16+source%15` 表示被挡。更近的点光、矩形和发光三角形仍使用源内 RIS，并置 `0x80008000` 强制位。resolve 用 12×12 组共享掩码检查 5×5 邻域：同一源同时出现可见与被挡，或出现强制位，即判为半影。半影判定以重投影的 R8_UINT 年龄保持 8 帧迟滞。其余随机接收点直接写当前值（count 1，矩为 (luma, 0)），确定接收点 count 为 0。只有含半影接收点的 8×8 tile 进入列表，三个空间滤波步长按该列表间接派发；未列出的 tile 在 resolve 中同时写入两张 scratch。掩码按 `source%15` 混叠只会把一致误判为分歧，增加重建，不会漏掉半影。几何边缘处的保守外轮廓仍会进入重建。

Shadows 与 `direct_shadow_cache` 均开启时，B 路径使用 `ShadowCache` 派生点光 cube face 与四级方向阴影请求。CPU planner 只持有派生驻留与失效状态；Scene Lit 持有 GPU 管线、两张 4096² D32_FLOAT 静态/动态 atlas（共 128 MiB 逻辑深度）、描述表和实例索引。点光方向按当前保守接收需求分配，包含 normal bias 和过滤支持域；投影者来自完整场景，不能用相机可见集裁掉离屏遮挡。128/256/512 点光层级与最多 1024 的方向级联共享预算，存在迟滞与对齐，图块边界含 guard texel。

方向级联的接收深度由可见 bounds 限定，有限远相机同时保留其 far 裁剪；无限远 Reversed-Z 相机以齐次远方向构造级联角点，不要求把无穷远端点除以零。光源空间的遮挡深度仍包含完整场景投影者。冷分配使用固定占用表快照与实际变更 face 的可复用撤销记录，分配失败原子恢复，不再逐灯复制全部缓存状态；暖驻留路径直接复用。

对象首次出现归入静态层，第一次变换、mesh 或 Mask 覆盖编辑后在当前场景持续归入动态层。旧、新 bounds 都使相交层失效，静转动会移除旧静态遮挡；删除同样清旧层。颜色、粗糙度或光强变化复用深度，光源投影变化重新绘制；源重排通过 LightFrame 的前后身份映射保留正确驻留。空场景退休 atlas 与描述资源，重入重新构建。未被完整编码消费的 plan 不可作为有效缓存，正常编码后才 commit；GPU 退休与依赖由 RHI/gfx 负责。

atlas 压力先调整分辨率，再使用“更新本批 → 着色本批 → 覆盖下一批”的顺序，全部源恰好累加一次，不把缺失页当作无遮挡，也不因压力全量退回逐灯 RT。每个 batch 独立绑定对应描述表。两层先逐 tap 取 reversed-Z 遮挡并集，再过滤，禁止先分别滤波后错误组合可见性。矩形和发光体仍使用原端点 RT 可见性。

每批按实际光类分别派发 cached point、cached directional 与 endpoint visibility；前两者的编译产物不含 RayQuery，后者不读取 shadow atlas。首次实际派发清空 ROI 的直接光信号，之后同帧各光类和驻留批次累加，跨派发 UAV 依赖沿 RHI/gfx 保证。矩形总在 endpoint 入口；有阴影点光的球内接收点由 CPU 保守需求启用该入口，shader 与缓存点光入口互斥求值；发光三角形只在首批计能。沿用同一 BRDF、候选分布和逐源随机种子，分派发仅改变光类求和次序与 RGBA16 写回舍入。未请求缓存时沿同一列表的 RT 求值入口处理。

点光软阴影采用世界/光源锚定的有限 PCSS 样本，cube tap 重新选择面；方向光包含级联过渡。接收平面的设备深度梯度用于实际取样 texel 的中心，四点过滤与 blocker 搜索共用该定义；点光 blocker 距离按该 face 的 texel 射线还原，包含 guard 区。接收平面校正超出投影或深度域时，退回受检的径向／未校正比较并计数，不能把非法深度当作无遮挡。过滤切向上限由 CPU/HLSL 共用常量给出；中心深度图是有限光源的近似，稀薄遮挡、极大半径和近源离轴遮挡仍需要图像对照。接收点位于发光球内时保留原端点 RT 并计数，因此不能用普通小灯暖缓存结果推断大量重叠巨型球光的成本。未以 D16/D24、硬阴影或暗化替代验收。

`direct_cluster_inspect` 只在明确开启时编译/派发接收面支持统计，给出 0～64、>64 的 66 档直方图与最大值。正常入口编译去除该统计工作；不常驻读回逐像素数据。计数是解析局部光保守支持，不含方向光、发光三角形或遮挡判断。普通 cluster 数量/溢出与该接收面分布采用同一完成帧发布。

## 同一帧的执行链

近期管线成本、剔除边界和工业依据见[审计研究](../../research/render-pipeline-audit-20261013.md)。

1. 光栅 GBuffer 写入着色法线/粗糙度、基础色/金属度、HDR 自发光、运动信息、独立 R32_FLOAT 预期前帧设备深度与 RG16_FLOAT 八面体几何法线。法线贴图只改变着色法线；偏移、支持平面和历史深度梯度使用几何法线。当前 D32_FLOAT 深度、前帧 R32_FLOAT 深度与 RG32_FLOAT min/max Hi-Z 都遵循有限 Reversed-Z；方向和背景约定见 [Renderer 合同](contract.md#场景和-ui)。屏幕坐标使用整个窗口，`scene_viewport` 处理物理像素偏移，支持透视与正交投影。
2. 共享不可变网格缓存 BLAS，稳定实例更新 TLAS。内联 RayQuery 完成灯光可见性和 DDGI 探针射线；能力由 RHI 的 `inline_ray_query` 明确报告。
3. 局部 ReSTIR 初始/时间 → 空间 → fresh visibility 着色，另加独立方向光，估计实际 `f×L×V`（解析灯为 GGX 全项，屏幕 mesh NEE 为漫反射项）。不把独立平均的光照和可见性再相乘。随后漫反射与镜面分别去除材质调制，使用各自的时间历史、FP32 亮度矩和三个步长的方差引导空间滤波，再恢复材质贡献；reservoir 与颜色降噪历史分别拥有。重建范围由当前接收点的估计方差决定，亮邻点的高方差不能使稳定暗点获得额外混色支持；法线、切平面、粗糙度和材质约束保留 lowpoly 硬边。
4. 有限体积 DDGI：规则 XYZ 探针格、八面体方向辐照度与距离矩、背面分类、受限位置修正、分帧采样与逐帧照明过渡，以及有界上一轮间接反弹。屏幕接收点用实际射线可见性选择八探针贡献，直接输出间接辐照度。
5. GTAO 基于深度重建与地平线积分，使用独立历史，只调制间接项。一次派发先写出 R32_FLOAT 视空间深度及其四个缩减层级；缩减层级只平均足迹内接近最远表面的深度（XeGTAO 的深度 MIP 思路），空像素不当作遮挡者。地平线 tap 按距离选层：约 14 px 内用全分辨率，之后每倍距离升一级。视空间位置由带 jitter 的投影系数经乘加重建，透视与正交投影通用。积分、切线、偏置和衰减与原世界空间公式一致。resolve 由 8×8 工作组把 12×12 邻域的世界位置、法线和原始 AO 一次性载入组共享内存，5×5 支持和时间重投影算法不变。可选 Local GI 提供有界近场漫反射修正；两者使用同一个近场策略选择，保留直接光与自发光。
6. SSSR 使用 GGX 随机反射方向、分层深度遍历、工作列表和间接分派，随后按表面/命中对应关系重投影，使用独立历史计数、FP32 亮度矩与三个步长的方差滤波；空间重建保留材质边界。屏外、遮挡或追踪失败回退到均匀环境辐射。环境控制变量的有符号估计保留至最终 HDR 合成，避免逐样本截零引入额外亮度偏差；SSSR 关闭时环境反射直接通过。
7. 合并 HDR 光照，按抗锯齿设置执行 TAA 或当前帧直通，同时写入下一帧表面深度与法线；随后执行 Bloom、EV 曝光和 SDR 色调映射。
8. SMAA 两种模式在色调映射后的线性 SDR 场景颜色上重建边缘；选择 T2x 时再组合两个独立空间结果。最后沿既有入口合成参考辅助显示与 UI。采用 jitter 的模式在需要辅助显示或 Capture 时，复用深度通道重建公开相机对应的无抖动深度，内部光照历史保留采样深度。

以上通道沿现有显示设置入口控制。低样本直接光的颜色时间与空间重建仍是有偏工程近似。诊断 `direct_reference` 固定平均 64 次独立局部 RIS 估计，每次使用当前 `direct_candidates`，屏幕参考路径强制使用全局 proposal，不受 `spatial_light_sampling` 开关影响；方向光也增加独立面积/角度采样，关闭 reservoir 时空复用和直接光颜色降噪。参考着色按最多 64×64 像素分派，限制单次 dispatch 的工作量；使用全局像素坐标保持随机序列和每像素采样数，普通路径重置分派原点。分块不减少整帧总成本，也不保证任意光源数和驱动环境下的执行时限。它是同一直接光模型的对照，不是整个渲染器的路径追踪真值。当前环境为均匀线性 RGB 辐射场，预积分 GGX BRDF LUT 用于其镜面响应；没有方向 HDR 环境图、场景反射探针资产、透明材质、蒙皮 BLAS、全路径追踪或超分辨率接入。

直接光的材质恢复与 HDR Compose 在同一通道完成，沿用去除独立 `direct_hdr` 中转后的资源路径与 RGBA16F 舍入行为。参考模式或没有光源时跳过直接光空间滤波，Compose 与 Local GI 共用已解析的直接光历史。候选数、参考模式和 Shadows 变化使受影响的直接光历史失效。

关闭 SSSR 时仍写入环境回退和空来源历史，但跳过 HiZ 构建、工作列表 reset/prepare 与三个反射空间滤波通道；下一次开启重新构建这些输入。关闭 Bloom 时跳过下采样和两次模糊，色调映射沿原开关忽略 Bloom。实例上传比较完整 GPU 数据，包括 previous_world、历史有效位和几何偏移；静止帧复用缓冲，物体停止运动后的前帧矩阵更新仍会上传。法线矩阵按 world 变化计算，统一光源快照按真实 Renderer sequence 推进前后状态，不以可重复的 UI 帧号判定帧生命周期。

直接光、DDGI 屏幕 gather、GTAO 和 Local GI 共用 `lit_screen_dispatch` 的整数原点与独占终点，只派发视口内接收像素；坐标、纹理索引和随机数仍使用原窗口坐标。范围按像素中心与小数视口相交，参考分块也使用独立终点，补齐线程不会写相邻 tile。Compose、公共表面历史和显示后处理仍定义完整窗口；邻域消费者先检查表面和视口，不能读未写的外部区域。这个裁剪不改变光源池、TLAS 或离屏探针更新。

直接光的成对时间 resolve 在一次 3×3 当前邻域和一次 2×2 前帧重投影遍历中共享漫反射/镜面的几何资格读取与重建。两种信号仍独立检查有效样本、粗糙度门槛，保留各自 support、权重、亮度矩和历史响应，按原行优先次序累积；共享几何资格不意味着合并信号或共用历史权重。参考模式与无光帧沿同一 resolve 直接写当前结果，不保留已删除光源。

直接光每轮空间滤波在一次邻域遍历中共享漫反射/镜面的几何引导读取与世界位置重建；两种信号仍保留各自半径、权重、历史和原累积次序。步长 1/2/4 使用同一算法的三个编译入口，只派发 resolve 列出的 8×8 tile。步长 1 的 8×8 工作组协作缓存 12×12 个 FP32 几何引导，占 6912 B 组共享内存；全部线程完成加载和同步后才执行尾组、背景或无效信号的退出。步长 2/4 与时间重建不使用该缓存或组同步；没有降低深度或材质精度。

ReSTIR 的 24 B reservoir 最后一个 DWORD 保存所属接收面的未归一化、排除 visibility 的 target，替代原预留字段。初始 RIS 和 reuse 输出都保存已经计算出的当前接收面 target；同帧空间复用读取候选自身 receiver 的缓存，其他 receiver 仍独立求值。时间复用只允许缓存本帧 fresh 输入，previous-domain 全部按旧表面和旧源重新计算，避免将不同重建浮点路径混同。null realization 的 confidence 仍参与其他候选的完整 MIS 分母；target 不是 proposal PMF，不随 confidence cap 缩放。时间复用最多两个输入，编译入口显式保留此固定上界。

SSSR 逻辑深度第零层直接读取既有 D32_FLOAT，物理 RG32_FLOAT 层从 2×2 min/max 归约开始，删除全尺寸 `(z,z)` 副本；FP32、奇数尺寸尾部和视口外远平面语义不变。首级与后续级使用同一归约算法的独立编译入口，避免单像素层级发生 SRV/UAV 别名。

## DDGI 探针场

权威运输估计使用双缓冲 RGBA32_FLOAT atlas，逐帧呈现使用单份同格式 atlas。`DDGICopy → DDGITrace → DDGIUpdate → DDGIPresent → DDGIResolve` 沿唯一 pass owner 执行：Copy 保留未选探针，Update 读取不可变的上一轮运输场并写当前运输场，Present 在 Update 后按帧时间平滑到呈现缓存，Gather 和空间诊断读取呈现。呈现绝不参与反馈。复用原有三份 atlas，没有新增同尺寸纹理；新增一次有界逐 texel Present dispatch，计入 DDGI update 区间。一个 receiver 的照度八面体编码与四个折叠 texel 偏移仍只计算一次。

`Frame::render_delta_seconds` 是与 Play 解耦的活跃渲染间隔，有限范围 `[0,.1]` 秒，固定步进调用方默认 `1/60`。编辑器与 Project Run 共用 accepted RenderClock：无可绘制视口、停用 DDGI、跳过或拒绝帧时重建基线；恢复首帧为零，连续慢帧限幅推进而不永久冻结。Present 的时间常数为 `.15s`，旧权重 `exp(-delta/.15)`，不再由 `updates / resident` 决定。零时间只保持有效缓存，fresh、inside、重定位与场景替换仍立即撤销旧位置照度。该时间不参与运输统计的访问权重；低更新预算仍受实际观测和多跳传播速度限制。

Mask 模式、alpha 因子/阈值或相关贴图采样描述改变，均属于实际遮挡变化；即使不需要重建 BLAS，也启动距离历史的两轮响应及屏幕可见性响应。阴影 bias 改变会启动探针照度响应。普通 Opaque 基础色编辑只改变辐射响应，不被当成距离变化。

`SceneLitSettings::probe_volumes` 提供四个有稳定身份的槽位，按 0→3 优先查询；固定与跟随体积共用同一描述、采样、资源池和调度。默认只开启 slot 0，范围 `[-6,-1,-6]` 到 `[6,5,6]` 米、`8×4×8` 共 256 个探针，每帧更新 64 个。每次更新分开使用 **32 条固定几何射线**和默认 **128 条照明射线**：前者负责背面分类与受限位置修正，后者随机旋转并估计照明，不用随机照明结果驱动探针位移。初始化或没有有效历史的探针一次到达受单元约束的几何目标；已有有效历史的探针缓慢修正。

固定体积每轴支持 2～32 个探针；`follow_focus` 各轴必须满足 `count ≥ 3 + 2×max(1, blend_cells)`，至少五个，以保留完整接管的内部区域。所有启用体积的**总数不超过 4096**；照明射线数支持 1～256，所有体积共享每帧 1～4096 个更新预算。`probe_settings_error` 校验描述，`probe_focus_error` 连同世界关注点校验实际精度；renderer、UI 与 Control 共用此约束，应用在发布候选状态前完成检查。运输历史与显示辐照度均使用 RGBA32_FLOAT，在照度线性域混合，已移除 gamma EMA 与编码域单侧冲击夹取；距离矩保持 RG32_FLOAT，世界重定位 offset/state 保持 RGBA32_FLOAT。

静态辐照度/距离历史权重为 .93/.95。已知灯光、环境辐射、材质、几何或 shadow bias 变化提升响应代次，各探针的每个方向 texel 独立推进响应：前4次有效观测的旧权重 .6，接下来8次 .8，完成12次后回到 .93；不再用全局四轮覆盖计数代替方向观测。无方向支持与 hold-irradiance 不消耗响应次数，合法零照度会消耗；光源变化保留 RGB、coverage、距离与成熟度，fresh/inside/重定位沿原失效边界清理。代次回绕只清响应状态；单次随机亮峰不触发响应。稳定身份下的灯光重排、材质索引重编号、previous 映射推进及对象纯重排不当作照明变化。几何变化仍使距离进入两轮响应期、权重 .85。初始化按实际观测预热。

每个有效照明批次保留 Fibonacci 球面覆盖，用探针自身实际访问驱动的 R3 整数 Weyl 相位生成均匀旋转；未调度的探针不推进，改变每帧预算不会跳过该探针的旋转序列。32 位访问游标回绕后换独立相位；新空间身份或失效原点清游标，普通光源变化不清。固定几何分类射线保持独立。主方向和软太阳随机域与局部 RIS 候选数分开；这不取消合法高能贡献，也不改变现有 cosine-normalized 卷积的统计性质。额外状态为每方向 RG32_UINT 响应与每探针 RG32_UINT 游标，4096 探针时约 2.03 MiB；没有扩大射线预算或复制运输 atlas。

固定体积的 min/max 是世界坐标；跟随体积的 min/max 是相对 `Frame::lighting_focus` 的范围，关注点由宿主提供，编辑器使用相机 target。间距保持固定，跨整数格点时改变环形地址；亚格移动不会重建场。跟随影响范围在存储边界内缩一格，并随关注点连续移动，避免离散换片直接接管接收面。负坐标采用正模，跨多轴清理进入切片的并集；整跨缓存跨度按整层新区域处理。历史传递同步清理新区的运输/呈现辐照度、距离矩、offset/state 与年龄；反馈始终使用上一轮描述及其不可变纹理快照，不将旧槽位解释为新的世界位置。

缓存范围不限制照明射程。不可变几何缓存保有局部 AABB，场景几何/拓扑/TRS 改变时以八角变换维护共享世界 bounds；每个探针的射线追到足以越过这些场景几何的位置，才能将 miss 解释为 Sky Light。局部 distance 归一尺度仍随 volume 固定，远于该尺度的距离在形成一/二阶矩之前逐射线截断；固定几何射线最近命中搜索使用完整实际距离。小体积不能因忽略远墙而在密闭室内引入天光。

初始化/重定位缺失与有效黑色分开。体积内部照度按合法八邻权重归一化；体积之间依边界与实际观测预热程度分配剩余权重，不累加两份完整 GI。四次有效方向观测完成预热，颜色不参与就绪判定；较优先体积的有效黑色同样占有权重。优先体积覆盖完整时停止查询后续体积，缺失时后续体积也必须通过自身遮挡。`blend_cells` 控制固定区域边界的 0～2 格过渡；跟随区域至少使用一格过渡。体积包围不保证室内有效支持，接收面缺口仍需用 Debug 检查。

调度将新区前两次访问优先安排，同时每帧至少保留四分之一预算（最少一次）给全池分散轮转；离屏、静态表面仍参与高阶传播，不能永久冻结。初始化也计入同一个预算。共享 atlas 尺寸改变时整体资源重建；普通滚动和相同配置重复提交保留交集历史。改变体积尺寸/间距/摆放模式只失效对应身份范围；若物理池布局随启停或计数改变，其受影响范围也失效。

几何变化后的距离两轮响应期按全局轮转游标实际覆盖进度推进；优先反复访问新切片不会提前耗尽远处探针的距离响应机会。辐照度响应使用上述每方向有效观测代次，不消耗全局轮转预算。工作列表仅传入执行探针更新的通道。八邻按原顺序循环，避免在复杂命中着色路径内强制展开八份可见性查询；这些是明确工作裁剪，不代表已测得特定毫秒收益。

探针更新分为 `DDGITrace` 与 `DDGIUpdate` 两个计算通道。前者执行固定几何射线、分类/重定位和主照明射线，保存完整命中材质及 FP32 实际带符号距离；后者执行命中处光照、反馈查询、方向卷积和历史写入。两者共用本帧工作列表、采样序列及前帧反馈快照，不重复射线或增加更新预算。中间记录每条 64 字节，按本轮探针数乘照明射线数保留可复用容量，默认 512 KiB，最大 64 MiB；不活动探针先清除输出再返回，不读取未写记录。缓冲和当前 offset 在阶段之间沿 gfx 的 UAV→SRV 转换建立依赖，扩容及空场/关停沿现有资源退休机制处理。

`probe_bounce` 为 0～0.99 的反馈运输系数，默认 .85；`probe_feedback_visibility` 默认 true，false 仅用于距离缓存遮挡近似的诊断对照。改变它们会使旧运输解失效。`indirect_gain` 为 0～8 的最终间接漫反射增益，默认 1，DDGI 与 Local GI 合成后只应用一次，不回写探针，也不因增益改变而清空探针场。它不创建缺失的空间支持。

照明预算实际执行请求的 1～256 条，不再将小预算暗中提升到 64；固定几何射线仍为独立的 32 条。方向 texel 在本轮没有有效照明观测时保留原运输估计与观测计数，初始化无观测保持无效；距离矩也只在自身方向支持有效时更新。低预算需要更多轮收敛，不承诺与默认预算在任意光场中等价。

DDGI 的 inside 分类只使用闭合组件的几何背面。每份不可变 Mesh 首次进入 Scene Lit 几何缓存时，按精确位置边邻接派生逐三角形信息，跨 UV/normal seam 保留连接；开放、非流形、朝向歧义、退化或零体积组件不作为实体内部证据。几何法线沿作者法线确定正面，并经实例逆转置变换，保留反绕序、镜像及独立内壁壳的朝向。开放背面仍提供正遮挡距离，现有着色侧语义不变。此信息不改变多边形线框掩码，也不宣称完成任意自相交网格的实体判定。

八探针查询只对朝向与可见性置信度做小权重压缩，随后乘线性的三线性空间权重，避免把每个探针的影响范围锐化成块。累积按实际非零权重和归一化，不把低置信度额外当作遮蔽。屏幕接收点经现有 RHI 的 TLAS 查询探针到表面的实际可见性；无效探针、零空间权重和无效辐照度在追踪前排除。该射线的接收点只沿法线偏移 `max(0.1 mm, 最小探针间距 × .0001)` 以处理端点数值误差，不使用方向距离滤波所需的大偏移。距离缓存提供连续方向权重，实际射线则强制剔除被阻挡的贡献，两者共同决定插值。仅用二值射线替代方向权重会暴露探针成员切换的硬轮廓；仅用距离缓存又会让错误贡献污染墙角。组合不增加环境光，也不为被阻挡的探针保留可见性下限。

距离矩方向权重沿用最小探针间距 .12 的法线偏移：先对四个相邻距离 texel 各自计算 Chebyshev 上界并取三次方，再双线性插值可见性，避免先混合距离矩引入额外方差。**反弹反馈默认也执行真实段遮挡**，与屏幕查询使用相同的数值端点、选格、选层和权重语义；统计偏移只影响距离缓存，不再改变反馈的八邻选择。诊断关闭反馈 LOS 时只改变遮挡判定，不同时改变 stencil。距离矩仍为 8×8 RG32_FLOAT，方向锥内混合几何和稀疏支持的近似仍存在；严格遮挡不能保证只有少量可见探针时插值连续，也不是无偏精确光传输的声明。

屏幕 gather 不再执行额外 5×5 表面重建。完整 gather（探针到接收面的实际 LOS、连续距离权重和距离矩）在每个 2×2 块只对一个代表接收点执行：按 (0,0)、(1,1)、(1,0)、(0,1) 的固定次序取第一个表面像素。结果写入四分之一面积的 RGBA16F `indirect_half`，alpha 记录代表点序号。全分辨率上采样只读取四个最近块的代表点，权重为高斯距离 × 平面距离（容差两个像素尺寸）× 几何朝向（点积 > .9）× 着色法线相似度的 8 次方。若总权重低于 1e-4（薄墙、孤立几何、贴边），该像素不借用其他表面的探针，进入回退列表。列表首元素是计数，其余为打包像素，容量为接收像素的四分之一，溢出部分在上采样中内联完整 gather。随后按列表间接派发，每个回退像素在连贯的 wave 中执行精确 gather，避免零散的精确 gather 拖慢几乎所有 wave。去除重建后的墙角、亚像素隔墙、运动与真实柱子场景证据见[验收记录](acceptance.md)。

Local GI 关闭时，若接收材质的 `base_color × (1 − metallic)` 严格为零，上采样直接写零，该像素也不进入回退列表；2×2 块内没有任何接收点需要漫反射时，跳过代表点 gather，省去无贡献的探针可见性查询。代表点仍只按几何选择，材质只决定是否执行，因此材质编辑不会让 LOS 缓存记录对应到另一个接收点。没有亮度阈值，极小非零漫反射仍正常计算。世界空间探针更新不受影响，Local GI 需要的去材质辐照度也不被裁掉。Receiver Coverage 在显示阶段单独查询，不改变此优化或光照射线统计。

非抖动视图的屏幕 gather 缓存代表点的精确 LOS 结果：每个 2×2 代表块使用 32 个可见位和 32 个有效位，对应四个体积各八邻。只有投影/逆投影、视口、体积描述一致且完整场景几何/Mask 未变化时才允许复用；shader 继续精确比较当前与前帧的 FP32 深度、表面身份、几何法线，以及该 probe 的实际 offset。每帧仅保留实际参与查询的有效位；相机移动、物体增删/变换、遮挡材质编辑、滚动布局和重定位均重新判定。照度、距离矩权重、就绪度与反馈传播不缓存，改光不必重查未变的遮挡。feedback、Coverage 和 inspection 仍独立精确查询。缓存按 2×2 代表块存储，块内保持同一代表点才复用，缓冲为每块 8 字节，2560×1440 目标为 7.03 MiB；回退列表的精确 gather 不读写此缓存。它按完整 render target 分配，不能把窗口尺寸与 viewport 混淆。resize/关闭沿已有 gfx 退休，空场/模式退出/失效禁止旧位复用。TAA/SMAA T2x 的 jitter 每帧改变端点，禁用缓存读写；首次启动只绑定一个元素占位，已有容量可保留到目标退休。此优化不降低距离或深度精度、不跳过被挡候选的归一化责任；效果与成本的当前验收状态见[验收记录](acceptance.md#lit-帧率批次2026-10-18)。

默认 256 个探针的两份运输 atlas 加单份呈现 atlas 合计 768 KiB 逻辑字节，与本批前的三份照度 atlas 总量相同。分批更新的运输历史采用上述每方向有效观测响应与静态 .93 权重；呈现每帧向最新运输场推进，时间常数不随更新预算变化。初始化、进入几何或位置修正同步清除无效运输与呈现，下一次有效采样重新建立支持。

探针命中点逐盏显式评估方向光，对统一局部源使用 `direct_candidates` 个候选的独立新 RIS；不复制屏幕 reservoir，不复用屏幕 visibility。这样少量强太阳不会因大量局部灯混入同一个均匀池而漏选。命中点的阴影查询归入 visibility 计数，固定几何与照明的主探针查询归入 probe 计数，所以总射线量不等于“更新探针数×照明射线数”。灯的 `casts_shadow` 保留其命中点直接光遮挡语义；主视图 Shadows 开关不取消探针命中点的遮挡。

命中点材质按完全粗糙（roughness 1）求值，颜色、金属度和 F0 不变。探针原点是一个点，光泽 GGX 波瓣朝向它时，只有极少数射线方向能对准光源的镜面反射方向，单条射线的辐射可达典型值的 30～70 倍；新场前 12 次更新的单次样本权重为 20～50%（成熟后为 7%），吸收这类样本后会出现持续约百帧的亮斑。完全粗糙求值仍计入镜面响应（同一 GGX 模型在粗糙度 1 下求值，单次散射本身在高粗糙度下略有能量损失），只是把它分散到整个半球。这属于路径正则化，与 Lumen 表面缓存的 fully rough 折算、RTXGI 和 Flax 的纯漫反射命中属同类取舍。代价是光泽面朝特定方向的集中反射（例如光泽地面把太阳反射到立柱）在 DDGI 中被摊平；屏幕可见的镜面反射仍由 SSSR 负责。

当前仍是有界、低频的漫反射场，有探针插值与更新延迟；支持有限固定/跟随体积组合，不包含无限世界流送、自动房间拓扑分配或稀疏砖块，也不能单独表达细小几何的全部近场遮蔽。实际场景应在同一预算下选择粗细覆盖或房间/楼层局部密度，不能把“恰好两层”当作普遍足够的结论。

## DDGI 空间与接收面诊断

World Settings → Diagnostics 中的 DDGI 显示与 Control 的 `view.set` / `render.compare` 共用 `ViewOption`。显示诊断默认关闭；设置属于视口，不创建 Entity、TLAS 实例或发光体，不写场景撤销与保存数据。

参数名称、范围和中英文说明来自编辑器的同一 `ViewOptionInfo` 定义，World 属性行与 Control 查询共同使用。悬浮说明解释字段的实际作用；它不参与渲染设置求值、场景序列化或 GPU 诊断数据采样。Scene 作者值与视口诊断的区别继续由 `world_option` 和既有提交链决定。

- `probe_visualization`：`off`、`irradiance`、`state`、`update_age`、`distance`。球心读取本帧完成更新的真实 offset；辐照度读取对应八面体方向，显示 `E / π × exposure` 经 `c / (1 + c)` 映射；它是探针数据预览，不是最终表面光照。距离读取 FP32 距离矩中的方向均值，黑到白对应 0～4 倍最小探针间距。
- `probe_volume` 显示实际滚动后的边界，`probe_relocation` 连接原格点与实际位置；四个槽位用青/黄/紫/绿区分。`probe_debug_volume=-1` 显示全部，0～3 只显示对应槽位。`probe_radius` 为最小格间距的 0.01～0.45 倍，默认 0.12；半径只影响显示，不改变采样。
- `probe_xray` 忽略场景遮挡；探针之间仍有深度遮挡。空间诊断在 AA 完成和无抖动编辑深度重建后执行，使用私有 D32_FLOAT 深度，保留正式 scene depth 给拾取、Capture 和编辑辅助线。未启用时没有诊断绘制或深度副本。
- Update Age 记录距上次**探针评估**经过的 DDGI 更新帧数，包括 inside/relocation 评估，不表示有效照明样本数或墙钟时间。青色表示本轮刚评估，绿到红表示一个预算轮转的年龄，灰色表示尚未评估。每探针 R32_UINT 占 4 字节，随现有 copy/update 维护，无额外 dispatch 或逐帧 GPU 读回；随探针场重建/重置清除，DDGI 关闭时不推进。

`probe_debug=true` 开启 Receiver Coverage；`probe_coverage` 选择 `status`、`volume`、`contributors` 或 `dominance`。查询沿真实多体积 gather，包括段遮挡、偏置、方向权重和历史，不以最近球推断表面质量。Volume 显示主导槽位及覆盖就绪度；Contributors 显示实际参与的邻居数量；Dominance 显示最大归一化贡献占比，接近红色意味着由很少支持主导，需要结合遮挡与密度观察。有效但严格零辐照度仍单独标记。

| 颜色 | 接收面含义 |
| --- | --- |
| 灰 | DDGI 关闭或没有当前场 |
| 蓝 | 超出当前体积 |
| 橙 | 相关探针尚未就绪或正在重定位 |
| 红 | 相关探针处在实体内部 |
| 紫 | 没有非零方向权重 |
| 棕黄 | 探针可用，但所需方向尚无有效照明观测 |
| 粉红 | 有方向观测，但贡献候选被遮挡 |
| 青 | 有有效支持，但辐照度为零 |
| 绿 | 有光照贡献；越亮表示贡献探针越多 |

跨体积全部失败时保留优先槽位的实际失败原因；体积内部待初始化优先于 inside。球体 State 直接显示探针自身分类。关闭 DDGI、空场景或场被失效时，空间设施显示灰色配置位置，不把旧照明当成当前数据。`FrameStats::scene_lit_probe_volumes` 提供每槽实际 bounds、spacing、resident、updated 与 reset_probes；这些是 CPU 本帧布局/调度事实，不是 GPU 完成或有效探针统计。

Coverage 在色调映射/最终 AA 后显示，仅覆盖有表面的像素，和空间球都不进入 DDGI、Local GI、反射、Bloom 或 AA 历史。诊断模式单独查询可见性，开启时有额外 GPU 成本；这部分不混入既有光照阶段时间和射线计数，性能采样应关闭诊断。没有常驻全场探针读回。Control 可按需设置 `probe_inspect` 和物理窗口像素 `probe_inspect_x/y`，由同一 gather 记录至多四层×八邻贡献。完成样本包含源帧/sequence、scene identity、采样像素、当帧布局、实际照度与运输估计、方向观测、年龄、空间/朝向/距离/最终权重及支持拒绝阶段；这些值不假装属于 CPU 当前帧。背景或越界返回无 receiver 的明确样本，空场/关闭检查/DDGI 停用返回 null。32 槽异步读回无空闲槽时跳过，正常渲染不等待，关闭后有界缓存留到 Renderer 退休。此诊断增加独立 gather，包含在 DDGI 父区间但不计入 update/gather 子区间，性能测量应关闭。

`probe_inspect_source` 沿统一 typed ViewOption/Control 入口选择射线检查的全局物理 probe 槽位，范围 `-1…4095`，默认 `-1` 自动选择上一份同场景、同像素完成样本中原始 gather 权重最大的有效邻居；这不等于亮度贡献最大的邻居。显式索引不要求它属于所选像素的八邻，允许检查次贡献探针；索引超出当前驻留池时不回退其他探针。完成样本的 `requested_probe` 保存原请求，`traced_probe` 为实际选择（无选择时为 `UINT32_MAX`），`probe_selection` 区分 `automatic / automatic_pending / explicit / explicit_out_of_range`。选择只改变视口诊断，不写 World/Scene/Undo，不强行调度探针、不清照明历史；显式范围外返回空射线记录，空场或 DDGI 停用仍返回 null。读回有延迟，消费方须同时核对请求、像素、场景和 sequence。

`ProbeInspection::Ray::sampling` 依次记录 reservoir 权重、该命中接收面所选源的完整 proposal PMF `q(source | receiver)`、反馈亮度和主射线命中距离。`sampling.y` 在空间采样开启时包含近源/全局混合，不能再解释为全局源表 PMF；无选中样本时为零。它仍是离散源选择概率，不是面积 PDF。新增 `light_endpoint_distance` 为所选局部源的实际采样端点 XYZ 与 hit→endpoint 距离；没有有效所选端点时 w 为 -1。`source_radius_range_area_min_distance_squared` 依次提供源半径、源范围、面积与解析源衰减使用的最小距离平方，mesh 源最后一项为零。半径/范围/面积按 `identity.y` 的源类型解释，不能把 mesh 的面积衰减当点光半径衰减。`sampling.w` 继续表示 probe→hit 距离，不与新距离混用；方向光贡献仍在 `direct_luminance.zw` 中独立记录，不套用局部源端点。

每条有效射线记录为96字节，仅在 inspection 已开启且所选探针本轮实际更新、命中可着色表面时写入；未记录 ray 不表示零贡献。每帧清理可选记录缓冲，显式越界请求不会留下另一探针的旧记录。端点通过已有 `LitLightSample` 和同一选中 UV 重建，不增加随机抽样或可见性查询；普通路径不增加 pass 或资源。仍未记录完整 RIS 候选、独立 visibility 结果或光源业务身份，源索引只能解释为该完成帧的打包源域。

`probe_history` 的 `live / hold_irradiance / hold_distance` 仅作视口归因对照，不写 Scene/Undo。前者冻结有效运输与呈现 RGB，后者冻结距离矩；几何身份失效始终优先。它们不能作为生产稳定算法。`--scene-lit-stability` 沿已有真实 Renderer 验收入口输出异步 CSV，覆盖通道冻结、运输/显示时钟分离及场景/像素生命周期。

端到端入口：`atelier_renderer_acceptance --scene-lit-restir-suite --output <绝对目录>` 覆盖多体积、共享预算、滚动寿命和运输/增益合同，并在同一 Renderer 上继续执行隔墙传播与空间显示回归，使用真实 GPU validation；`--scene-lit-stability` 另覆盖多体积。`atelier_editor_control_acceptance <editor.exe> <绝对输出目录> --ddgi-debug` 验证正式编辑器、统一选项发现、幂等 patch、非法 patch 原子拒绝、临时对照及场景/撤销隔离。具体已通过的候选和证据仍以[验收记录](acceptance.md)为准。

## 显示菜单与近场策略

World 页统一编辑光照与效果的作者配置，进入同一 World 值和 Session 历史，包括 Shadows、DDGI、GTAO、SSSR、Bloom、Local GI、抗锯齿、曝光和直接光候选预算；不再提供 Shadow Budget / Shadow Samples。诊断仅改变视口偏好。Scene View 显示菜单只切换着色与边线预览。Control 临时渲染对照使用独立求值覆盖，不写入场景或撤销历史。

**Window → World Settings** 打开可停靠的 World 配置页，分为 Lighting、DDGI、Effects、Diagnostics、Performance。Lighting 的 `direct_candidates`、覆盖布局与共享传播作者参数随 Scene v6 保存；`direct_reference`、`spatial_light_sampling`、探针球、接收面指标、体积/重定位叠层以及反馈可见性诊断留在视口。Diagnostics 的 Spatial light sampling 默认开启，关闭后 DI/DDGI fresh RIS 使用完整全局 proposal；此开关由统一 ViewOption/Control 入口读写，不写 World、Scene 或 Session 撤销历史，也不关闭 CPU 网格维护和已有 GPU 缓冲的驻留。本帧 CPU 布局读数仍是瞬时状态。Coverage 提供明确的 Fit Scene 与 Scene + Follow Focus 操作；字段草稿在提交时整体校验，UI 与 Control 不各建一套参数语义。具体页面和交互见[编辑器场景光照](../editor/README.md#场景光照)。

`SceneLitSettings::antialiasing` 为 `Antialiasing::{none,taa,smaa,smaa_t2x}`，菜单显示 Off / TAA / SMAA / SMAA T2x，默认 SMAA。所有模式均使用原生分辨率：

| 模式 | 采样与历史 | 处理位置 |
| --- | --- | --- |
| Off | 无相机 jitter、无最终颜色时间累积；信号自身降噪继续运行 | 当前 HDR 合成后曝光、Bloom 和色调映射 |
| TAA | 八相位 jitter，递归 HDR 颜色历史与局部有效性校验 | HDR resolve，Bloom 和色调映射之前 |
| SMAA | 无相机 jitter，单帧边缘检测、模式面积估计与线性邻域混合 | 色调映射后，UI 之前 |
| SMAA T2x | 两相位四分之一像素 jitter；当前与上一帧的独立 SMAA 空间结果，前帧权重最多 .5 | 与 SMAA 相同，再执行两帧 resolve；最终结果不回灌空间历史 |

SMAA 使用固定版本的上游面积/搜索 LUT；边缘判断读取非线性 sRGB 亮度，颜色混合保持线性。T2x 仅为颜色重投影去除两相位 jitter，复用上游邻域核计算颜色和抗锯齿速度，以原始两帧 point 采样和速度幅值控制最多 .5 的历史权重。GBuffer motion 的 xy 仍含 jitter、z 表示几何覆盖、w 表示对象与着色材质对应有效性；材质编辑不破坏前帧几何矩阵与 FP32 深度。轮廓前景／背景是互补子样本，不能按深度或背景差异一律拒绝。新增、删除或新显露区域可能混合一帧旧空间颜色，下一帧不再包含该颜色；最终结果不递归累积。

T2x 补充亚像素轮廓信息，不替代直接光、反射或 AO 自己的信号降噪，也不承诺恢复单帧完全漏采样的几何细节。原生 SMAA 的 shader、LUT 来源与许可见 [第三方记录](../../../third_party/smaa/README.md)。

Local GI 对应 `ssil`，默认关闭。当前按全分辨率计算半径不超过 1.2 米、强度 .3 的近场修正：以各向同性 `DDGI irradiance/π` 为基线，DDGI 关闭时使用环境漫反射基线；估计有界屏幕空间残差，并保有独立时间历史。它读取已稳定的去材质直接漫反射和 DDGI 间接项，不读取镜面、SSR、最终颜色或自身修正结果，不形成光照反馈环。屏外信息、各向同性基线与残差限幅使它属于受控近似，不能称为无偏完整 GI。

开启 Local GI 会关闭 GTAO，开启 GTAO 会关闭 Local GI；直接调用 Renderer 时即使两者都为 true，也明确由 Local GI 优先。局部近场修正不与 GTAO 重复遮蔽。

## 身份与历史

World/Runtime 仍是业务对象身份与生命期的唯一权威。Application 将完整组件 ObjectId 映射为快照域内的非零稳定键，并在条目离开快照后移除映射；键不保活对象。场景替换改变 `scene_identity`，几何、成员、材质及灯参数编辑改变 `scene_revision`，普通相机移动和连续位姿更新不会每帧清空历史。

Renderer 用前后相机和实例变换生成运动信息，结合深度、法线和局部表面对应关系拒绝错误历史。场景域替换与探针体积重建需要重建相应缓存；尺寸、视口、camera cut 和 AA 采样模式变化清除表面历史，camera cut 保留仍有效的世界空间探针。效果切换经 `lit_history_invalid` 只使依赖变化输入的信号失效，包括受影响的最终颜色历史，不连带清空整个探针场。缺少稳定网格键的旧调用仍可绘制，但不复用该物体的时间对应关系。

ReSTIR 光源身份包含完整稳定键与种类；发光面还包含持有 owner 的不可变 Geometry 和 primitive 身份，防止资源地址复用。前后快照分别保存实际位置、方向、面积参数及双向映射；新增、删除、几何替换和材质 Description 变化断开该源的时间映射，零稳定键不复用历史。材质描述相同时才允许把前帧源重映射到当前材质表。接收面历史另外保留整数表面身份、基础色/金属度、法线与 FP32 深度，用于重建前帧目标；不以当前接收位置代替移动物体的前帧表面。

时间入口将历史样本索引转换到当前局部源域，复用循环统一消费这一域；只有时间输入的旧表面目标使用前帧源参数。失去映射的样本成为空实现，其有效 confidence 仍参与其他候选的 MIS 分母。空间入口全部使用当前域，不绑定前帧源与两张映射表。

基础色、粗糙度、自发光或金属度改变时，只使该对象的着色对应在编辑帧失效，仍保留几何运动；下一帧恢复有效位也纳入实例上传比较。反射的接收面与旧来源都检查这一标记，以响应原位材质编辑。SSSR 分类、历史解析和空间邻点共用粗糙度／视向资格判断，不合资格立即写入环境回退并清除旧来源。反射距离／粗糙度上限、AO 半径、阴影 bias 与探针调试显示的修改沿既有依赖掩码使受影响的历史失效。

运动纹理表达前帧 UV 减当前 UV 与对应有效性；预期前帧设备深度由独立 R32_FLOAT GBuffer 通道提供，不以 FP16 深度或残差恢复。斜面重投影按接收平面的深度梯度校验各邻点；深度容差来自世界空间投影与相对 FP32 误差，避免在反向深度远处用固定设备深度 epsilon 放宽校验。

灯光/材质编辑以及发光几何的移动、增删缩短有关光照历史的响应，DDGI 辐照度按上述每方向有效观测响应；这些编辑不触发全局历史清场。

直接光降噪器的响应取决于距最后一次辐射变化（灯光、材质、发光体或环境）的帧数，而不取决于变化是否恰好落在编辑帧。变化后 48 帧内，漫反射与镜面的历史支持上限分别为 11 帧与 7 帧，旧历史还按当前邻域做颜色夹取；旧辐射每帧保留 11/12，48 帧后低于 1/64，之后支持才逐帧恢复到 47 帧。持续动画的光源（闪烁的火把、移动的发光体）让这个窗口一直打开，半影保持约 11 帧的时间滤波，不会退化为单帧估计。代价是每次编辑后的 48 帧内，随机直接光像素的噪声略高。SSIL 与最终颜色的历史仍只在变化帧缩短响应。

几何变化另有可见性响应提示：即使接收面静止，直接光和 Local GI 也会缩短历史，及时响应移动遮挡物；它不触发直接光针对辐射编辑的颜色夹取。直接光、SSSR、GTAO、Local GI 与最终 AA 各自拥有历史，SMAA 关闭最终颜色时间累积不等于关闭光照降噪历史。探针采样序列属于探针场自身，只在实际更新时推进，随场景域或体积重建重置。

SSSR 不以全局几何变化统一降低历史支持。它比较接收面及反射来源的实际前帧对应与同一世界点的静止投影，排除相机运动和 jitter，再局部缩短运动源的历史。粗糙反射从参与空间估计的样本选择贡献来源见证，按最终新旧贡献权重决定保留或替换；随机 miss 不自动清空见证。旧来源经前帧 R32 深度、法线和投影平面梯度重建，再向当前帧验证几何；确定消失或遮挡时拒绝相应旧历史。连续源锚点不递归吸附像素中心，避免 T2x 相位积累位置漂移。见证不是整个粗糙波瓣的完整身份，离屏信息仍受屏幕空间方法限制。

反射亮度夹取沿当前 RGB 均值收缩，并以同一仿射系数更新一、二阶矩；不对 RGB 三通道加等量亮度偏移，避免纯红旧历史产生互补负色、在最终非负 HDR 合成后形成彩色拖尾。Signed 控制变量估计一直保留。命中 trace 用 RG32_UINT 保存精确 texel 身份和 FP32 距离，两张历史用 RG32_FLOAT 保存连续 UV；三张纹理仍各为每像素 8 字节，来源深度继续读取已有 R32 历史，没有新增纹理、射线或 dispatch。

普通实例新增、移除、几何替换和快照重排保留探针目标、显示历史及轮转进度。新增或替换几何的对象不复用表面对应，存活稳定对象按自身身份保留前帧矩阵；真实几何变化进入探针响应期。连续成员变化不会在目标进入显示照明之前反复清场。

## 诊断与性能边界

ReSTIR、直接光降噪、GTAO、Local GI、最终 TAA 以及 SSSR 接收面/来源见证的表面历史共同检查完整 64 位身份与当前 motion 有效位，再应用各自几何容差；低 32 位相同的不同对象不能共享历史。SMAA T2x 的覆盖样本合成保留自己的轮廓规则，不把这种表面照明身份门槛机械套在互补 AA 样本上。

`FrameStats::scene_lit_gpu_ms` 为八个阶段的原始 GPU 完成样本：GBuffer、AS/上传、直接光/降噪、DDGI、GTAO/Local GI、HDR/SSSR、HDR resolve/表面历史、Bloom/色调映射/SMAA/显示合成。`scene_lit_ddgi_gpu_ms` 再分为 update/transfer 与 receiver gather（包含半分辨率代表点 gather、全分辨率上采样和回退列表的精确 gather），`scene_lit_ddgi_visibility_rays` 分为 probe-hit shading 与 receiver gather；两个数组均长 2，属于既有 DDGI 时间和 visibility 总计数的子集，不重复加总。只有主阶段、细分 timestamp 与射线读回都对应同一个完成的 RHI 录制序号时，`scene_lit_gpu_timing_valid` 才为 true；`scene_lit_gpu_sample_sequence` 与 `scene_lit_gpu_sample_frame_id` 标识样本。完成结果可能滞后或重复，统计分位数时必须去重；没有用平滑时长计算 p95。

`scene_lit_direct_gpu_ms[4]` 细分直接光父阶段：初始/时间 reservoir、空间 reservoir、当前可见性与着色、辐射 resolve/filter。第三项包括显式方向光；第四项在参考模式仍有直通 resolve，因此“关闭降噪”不等于没有该 dispatch。`scene_lit_ddgi_update_gpu_ms[2]` 细分 update/transfer：主射线（含分类/重定位）与命中照明/反馈/卷积；copy/transfer 仍只计入父阶段。细分之和不能替代其父阶段，更不能重复加入八阶段合计。

`scene_lit_direct_reconstruction_gpu_ms[4]` 进一步细分辐射 resolve/filter：temporal resolve、空间 filter step 1、2、4。每个区间包含自己的资源绑定、转换与依赖，不是纯 shader busy time。参考模式与无光源帧仍执行 resolve，三个 filter 区间标记 skipped；这些子项不重复加入 Direct 或八阶段合计。

全部 22 个逻辑时间区间沿既有 timestamp 与异步计数读回共同发布，没有额外 GPU 等待。`scene_lit_gpu_pass_mask` 与完成样本一起保存：bit 0～7 对应主阶段，8～9 对应 DDGI update/gather，10～13 对应直接光细分，14～15 对应 DDGI update 细分，16～19 对应直接光 resolve 与 filter step 1/2/4，20 对应精确灯列表构建，21 对应缓存阴影更新；原有索引保持不变。置位表示进入该工作区间，不保证内部每次都有非零工作；跳过的区间仍配对记录空 timestamp，可能测得微小查询开销，不能只靠浮点零判断启用状态。DDGI 关闭时其所有位不置位；DDGI 开启但没有启用体积时仍执行清零输出的 gather。非 Lit 帧没有有效样本。

编辑器的 **World → Performance** 使用现有 Table 展示当前值、120 个唯一完成样本的均值和 p95，以及均值占八阶段合计的比例。总计先逐样本相加再计算分位数，不相加各行 p95；子项缩进且不重复计入总计。场景、实际渲染尺寸或配置换域后，用新域首个接受帧的 `ui_frame.id` 拒绝迟到旧样本；普通相机运动和选择变化保留窗口。该合计不含 UI、Guides、探针诊断绘制、Capture、CPU Present 或显示扫描，不等于完整 GPU 帧时或 FPS。逻辑资源显示属于当前 CPU 资源账目，与异步 GPU 样本的口径分开。

精确灯列表的时间为 `scene_lit_direct_cluster_gpu_ms`；`scene_lit_shadow_cache_gpu_ms` 为缓存 atlas 更新，均是 Direct 的子项。压力分批的更新和 shading 各自持有独立 timestamp，按该完成帧实际 batch 数求和，未使用 query 的旧样本不会混入；shading 归入原 bit 12。`scene_lit_shadow_cache_*` 同时发布请求/复用面、静态/动态更新、实际 draw、分辨率降级、压力批次、近裁剪面投影者、缺失 tap、过滤截限、球内 RT 回退与平面校正回退。所有这些统计对应同一完成帧，不将当前 CPU 请求混入异步耗时。临时 `direct_cluster_inspect` 的 66 档直方图也按同一身份发布；关闭时归零。

阴影和探针射线数来自 GPU 实际执行计数，与上述完成样本关联。`scene_lit_light_sources`、`scene_lit_shadow_sources`、`scene_lit_di_candidates` 与历史重置数描述当前编码帧，分别为统一源总数、启用 Shadows 时具备投影资格的源数、初始候选预算；投影资格数不是本帧实际射线数，也没有“未获阴影槽”的灯。`scene_lit_resource_bytes` 是资源逻辑字节加 AS 数据量，不包含 GPU 驱动分配开销、AS scratch 和待退休资源，不能称为显卡实际总显存。

空间选灯的当前编码帧统计为 `scene_lit_spatial_sources`（保留源数）、`scene_lit_spatial_cells`（非空 cell 数）、`scene_lit_spatial_bytes`（三个当前 GPU 缓冲的逻辑字节，含空表哨兵）与 `scene_lit_spatial_changed`（本次编码是否上传这些缓冲）。Control 将其发布为 `frame_stats.spatial_light_sampling` 的 `retained_sources / nonempty_cells / resource_bytes / uploaded`。这些值不表示裁掉的源数、实际选中数、GPU 完成状态或时间收益；三个缓冲已包含在总资源字节中，不能重复相加。未编码 Scene Lit（例如无几何且不绘制探针诊断）的帧，这四项为零，不代表所有 Scene Lit 缓存均已释放；仍保留的逻辑资源以 `scene_lit_resource_bytes` 总账为准。

Renderer 的常规验收是 `renderer_acceptance` 目标。它在各自的进程和窗口中依次运行下列入口，任一入口失败即整体失败；证据写入构建目录的 `renderer-evidence/<入口>`，日志为 `renderer-acceptance-<入口>.log`：

| 入口 | 覆盖 |
|---|---|
| 默认（无参数） | cavity、材质与材质光输运、UI、变换、网格、可见性、选中、视口显示与参考辅助、关闭 |
| `--scene-lit` | 环境、逐项图像、时间稳定、Edit/Play 收敛、删灯、正交、模式独立性、resize |
| `--scene-lit-benchmark` | 原生 2560×1440 完成样本与 GPU 分段计时合同；测量阶段关闭验证且不 Capture |
| `--scene-lit-temporal` | 信号编辑、移动历史、时间隔离、刚体运动响应 |
| `--scene-lit-quality` | 四种 AA、灯光编辑与收敛、direct64、DI 辐射响应、SSIL、深度、DDGI 质量、contracts |
| `--scene-lit-stability` | 稳定性、DDGI 质量、多体积 |
| `--scene-lit-restir-suite` | 材质/传输、ReSTIR、多体积、DDGI 质量/调试、audit、contracts（同一 Renderer） |
| `--scene-lit-clustered`、`--scene-lit-shadows`、`--scene-lit-cost` | A 路径、缓存阴影 B、DI 成本与等价 |

各入口也可单独运行并追加 `--output <绝对目录>`；同步图像读回耗时不作为性能结果。菜单与工程入口由 `editor_scene_lit_acceptance` 验证。

`--scene-lit-restir-suite` 在同一个 Renderer 中组合材质/传输、ReSTIR、多体积、DDGI 质量/调试、audit 与最后关闭的 contracts。实际通过范围、图片和性能样本由 [验收记录](acceptance.md) 维护；首批版本的 4.25 ms 属于其原采样条件，不能作为新版独立降噪、探针设置与 SMAA/Local GI 的性能结果。

contracts 通过同一真实 Renderer 覆盖灯光值域、混合开放与闭合几何、反绕序/镜像、连续成员变化、无效帧隔离、小预算能量与实际射线计数、空场景退休/重入和重复关闭，包含在 `--scene-lit-quality` 与 `--scene-lit-restir-suite` 中。旧确定性灯循环的查询复用判据不再代表当前统一采样工作量，新候选以 `--scene-lit-restir-suite` 和当前验收记录为准。零／极小漫反射及 Local GI／调试消费者仍须保留其行为。`--scene-lit-temporal` 另覆盖原位关闭 emission、等亮度换色、材质粗糙度与反射上限编辑，和移动光照历史响应。

资源账目必须包含新采样状态：每像素 24 字节 reservoir 的 previous / scratch / current 三份共 `72P` 逻辑字节，另有当前/前帧表面身份、前帧材质及光源快照/映射；FP32 探针照度另按实际 atlas 计数。旧版移除直接光中转的 `8P` 节省不能单独代表本批净资源变化。参考模式跳过直接光滤波，关闭 SSSR 或 Bloom 仍按前述裁剪工作；保留的可复用纹理继续计入统计。P 为窗口像素数，逻辑字节、dispatch 数均不是实际外部带宽或帧时测量。

静态 DDGI 闪亮、更新预算与响应时间、多灯采样及 SDF 配套的演进建议见 [稳定性与光照管线研究](../../research/ddgi-stability-and-lighting-roadmap-20261015.md)。其中已落地部分以本文当前合同为准；本批固定近源网格不代表已实现 SDF、room/portal、自动探针布点或真正的光源影响域索引。验收与性能结论仍以[验收记录](acceptance.md)为准。

可打开的真实工程见 [Scene Lit Room](../../../assets/examples/Examples/Scene%20Lit%20Room/README.md) 和 [Sponza](../../../assets/examples/Examples/Sponza/README.md)。体积配置来自当前 Scene 的 World 设置，切换场景不继承上一个场景的布局；重新拟合由 World Settings 页的明确操作完成。渲染通过统一材质表消费原有贴图及 Mask。`editor_sponza_acceptance` 在完整建筑上验证 DDGI 开关、移动光源与关灯后的收敛。性能目标基于 RX 6800 XT；目标帧率与最终本机实测应分开陈述。
