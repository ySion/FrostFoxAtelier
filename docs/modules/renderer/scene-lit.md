# Scene Lit

本页维护已实现的光照合同。使用方式与视口合同见 [Renderer](contract.md)，实测结果见[验收记录](acceptance.md)。尚未实施的方向见[后续方向](../../research/scene-lit-next-evolution.md)。

Scene Lit 是现有 `Renderer::render(Frame)` 的一种视口着色方式。World 持有材质和 LightComponent，Application 从同一 World 生成拥有 CPU 数据的 SceneSnapshot，Renderer 同步借用快照并经唯一 RHI Context 录制、提交、Present。MatCap、Smooth、Flat 保留各自的显示语义，Edit/Play 不选择着色方式。

光照、DDGI 布局和效果参数的作者值为中立共享类型 `rendering::SceneLightingSettings`，由 World 的 EnvironmentComponent 提供（没有时为默认值），随 Scene v8 保存并进入 Session 撤销历史。旧版继续读取；v4 的 `shadow_light_budget` / `shadow_samples` 只在兼容读取边界严格校验后丢弃，新字段采用默认值，v1～v3 使用默认 World 配置。`renderer::SceneLitSettings` 在作者值上附加视口诊断偏好，`Frame::view.lit` 是当帧求值结果。Renderer 不持有或修改 World，Project Run 也从同一 SceneSnapshot 消费场景配置、材质和光源。

实现入口为 [scene_lit.cpp](../../../src/renderer/scene_lit.cpp)，它是 Renderer 私有的 GPU 资源与通道拥有者；没有新增业务对象注册表、原生设备、原生队列或第二套提交接口。纯 UI 和空场景不启动 Scene Lit 管线。管线按视图设置分组，在 RHI 工作线程上准备，未就绪的帧返回 not_ready（见 [Renderer 合同](contract.md#场景和-ui)）；采样器、查询、读回与查找表在第一个编码的 Lit 帧创建。关闭与尺寸变化沿既有 gfx 退休机制处理。

接受空场景时，Scene Lit 退休旧 Mesh 所有者、BLAS/TLAS、实例与灯光缓冲；可复用的管线、目标纹理仍保留并计入资源统计。模式退出和清理发生在 CPU 帧准备成功后的编码阶段，被拒绝的候选帧不会清除有效光照历史。同一 Renderer 可以随后重新接收非空场景，关闭保持幂等。

## 材质和真实灯光

- 标准金属度/粗糙度材质支持基础色、roughness、metallic、切线空间法线、线性 HDR RGB 自发光与 Opaque/Mask。六个贴图输入及 UV/采样设置由统一材质表提供，自发光因子在曝光前保留大于 1 的值。
- GBuffer、射线命中、辅助深度和选择叠层消费同一表面；Mesh/MTL 默认材质与显式资产绑定走同一解析入口。颜色/发光图使用 sRGB，标量/法线图使用线性数据，详见[材质系统](materials.md)。
- 点光源使用 candela，矩形面光源使用 cd/m²，方向光使用 lux。点光源半径以米表示，方向光角半径以弧度表示；矩形使用米制宽高与单面/双面设置。
- 天光是同一作者值中的 `sky_enabled`、`sky_color`、`sky_intensity`（cd/m²），以及方向性贴图 `sky_map`（`rendering::SkyMapRef`，空表示 map = 1）和 `sky_rotation`（度）。入射辐亮度为 L(ω) = sky_color × sky_intensity × map(R·ω)。宿主用 `rendering::sky_radiance` 求颜色乘强度写入 `Frame.environment`；天光关闭或没有 Environment 时该值为零。天光不进入局部光源候选池。Renderer 从 `Frame::view.lit` 读取 `sky_map` 与 `sky_rotation`：
  - DDGI 探针射线 miss 读贴图的低分辨率 radiance cube。
  - 背景像素只在设了贴图时显示天空，按相邻像素方向的跨度选 mip，u 接缝处按环绕计算跨度；没有贴图时 Scene Lit 背景仍为黑，工作室模式的渐变偏好单独保留。背景在未抖动的像素网格上采样：贴图已经按 mip 预滤波，抖动只会让它闪烁。
  - 设了贴图时，compose 给背景像素写运动向量：天空在无穷远，取同一方向在上一帧 view-projection 下的位置（w = 0，自然去掉相机平移），按未抖动网格计（jitter coverage z = 0）。上一帧是正交相机时，所有像素看到同一方向，背景运动为零；方向在上一帧相机背后时，前帧位置记在窗口外，远离窗口的位置也夹在窗口外的有限范围内，FP16 不会溢出。SMAA T2x 据此重投影背景，窗口外的位置不取历史；TAA 对背景不取历史。没有贴图时背景为黑，compose 不写 motion，GBuffer 的清除值（零运动）保持不变。
  - 其余读均匀天光的地方（DDGI 关闭时的合成、SSSR 的环境回退）改读贴图按立体角的平均辐亮度，即 `Frame.environment` 乘贴图均值。
  - 换贴图、改旋转角或改颜色强度都会增加探针纪元；旋转角逐帧变化时探针历史逐帧重置。
  - GPU 缓存项持有 `SkyMapRef`，不拿地址当键，旧贴图释放后新贴图即使分配在同一地址也不会命中过期资源。换贴图时旧纹理经 gfx 按在途帧退休；4K 贴图约 85 MiB（RGBA16F 加 mip），cube 1.5 KiB，都计入 `scene_lit_resource_bytes`。上传与 mip 生成计入 AS/uploads 时段，在一帧内完成：4K 贴图的上传帧 CPU 约 34 ms（主要是 64 MiB 上传缓冲 14–17 ms 和建纹理约 5 ms），GPU 约 3.4–3.7 ms。背景纹理创建时就带 UAV 标志，mip 生成只是一次录制（约 0.03 ms）；不带这个标志时 gfx 会在第一次生成 mip 前重建并整张拷贝纹理，多花 12–25 ms。1440p benchmark room 里设了贴图后 compose 中位数从 0.498 ms 变为 0.576 ms（其中背景 motion 约 0.012 ms），DDGI 主追踪不变。
  - 天空里的太阳不提取：它只经 DDGI 和反射照亮场景，没有清晰阴影。需要清晰阴影时，用不带太阳的 HDRI 加一盏 Directional 光，用 `sky_rotation` 对齐。
- `rendering::SkyMap`（[sky_map.hpp](../../../src/rendering/sky_map.hpp)）是不可变的等距柱状天空资源：
  - 贴图空间：第 0 行是 +Y，行向 −Y 推进；u = 0.5 朝 +Z，u = 0.75 朝 +X，从球心看贴图不镜像。
  - `sky_rotation` 让贴图绕 +Y 转动，方向与 Transform 绕 +Y 的正旋转相同：+X 转向 −Z，在本引擎的左手系里从 +Y 往下看是顺时针。所以方向光和天空转同一角度时，HDRI 里的太阳仍与光对齐。范围 [−180, 180]，±180 是同一方向。
  - 输入：宽高 2:1，宽不超过 8192；辐亮度有限、非负，每通道不超过 2^32。宽于 4096 时按 2×2 平均降一次（高必须为偶数），所以 GPU 背景图最大 4096×2048。
  - 存储为 RGBA16F。源峰值超过 65504 时整图乘 2^-k（k 记在资源里，着色时乘回），不裁掉能量；代价是很暗的纹素会落进 FP16 次正规数，精度下降。
  - 以下派生量由完整的 float32 源图计算：按立体角加权的平均辐亮度、通道峰值、最亮纹素方向，以及 4²×6 按立体角盒滤的 radiance cube（RGBA float，未缩放，D3D 面序 +X −X +Y −Y +Z −Z，纹素约 22°）。cube 按不大于 0.5° 的子纹素累加，再除以落进每个纹素的采样面积，所以常量贴图逐纹素精确复原，也不受 2^-k 次正规数的影响；采样面积与纹素的几何立体角最多差 0.9%，4K 源图上 0.13%。
  - cube 取 4² 是为了 DDGI 稳定。kloppenheim_05 里最亮的 0.1% 纹素（太阳）占全图辐射通量的 64%，而 64 条探针射线的间距约 25°，比 16² 的纹素大得多，太阳纹素时中时不中。room 场景里时间偏差的 p95 与同均值均匀天空（0.50 级）相比：16² 为 3.87 级，8² 为 1.53 级，4² 为 0.55 级。代价是辐照度的精度：在这张 HDRI 上，相对最大辐照度的误差平均 1.6%、最大 7%，集中在法线与太阳方向接近垂直处；16² 分别为 0.9% 和 3.5%（离线按最近纹素估计）。
  - `rendering::decode_radiance_hdr` 读取 Radiance `.hdr`：只接受 `32-bit_rle_rgbe` 和 `-Y H +X W` 方向，支持新式 RLE、旧式 RLE 和平铺扫描线，来源上限 256 MiB。像素按 R × 2^(e−136) 还原，不加半步偏移（与 OIIO、stb_image 一致）；其他头部行（含 EXPOSURE）忽略。4K 源图解码并计算派生量在 Release 下约 0.46 s，每个资产只做一次。
- World 唯一负责层级变换与灯的正交方向；Renderer 接收最终位置、传播方向和矩形切向轴。空间缩放不隐式改变灯的物理尺寸、范围或强度。权威数据约束见 [Presentation](../presentation/README.md)。
- 点光和矩形光使用有界距离衰减；方向光覆盖全场景。直接光使用 GGX 表面响应。屏幕直接光用 LTC 对矩形光的立体角做确定积分；DDGI 探针命中点仍对矩形的真实发光面积采样。
- Renderer 的灯光值域与 World 一致：方向光允许零 range，非矩形光允许零 width/height，方向光角半径小于 π/2。局部光源在共享贡献求值入口按真实采样位置检查距离衰减与侧向。
- 屏幕直接光对 cluster 列表中的解析局部灯逐盏确定求值，方向光逐盏独立评估；发光网格不进入直接光，只经 DDGI 照亮场景（见下）。`direct_candidates`（1～32，默认 8）只控制 DDGI 探针命中点每次挑选的局部光候选数，不影响屏幕直接光。cluster 列表的固定容量只限制快速存储，不截断光源；源数仍受身份表示和实际缓冲大小校验约束。Shadows 开启时，所有 `casts_shadow` 的光源都从阴影 atlas 取可见性；Shadows 关闭时忽略遮挡。

LightComponent 不自动创建可见发光几何。网格自发光由材质 emission 决定，只经两条途径到达画面：相机直接看到的 emission，以及 DDGI 探针射线命中发光面时记录的 emission。后者与相机看到的一致：单面材质的背面不发光，双面材质按材质的双面发光设置。因此 DDGI 关闭时发光网格不照亮其他表面；开启时它的照明随探针更新收敛，空间分辨率受探针间距限制，小发光体附近的照度会被探针插值抹平。静止帧先比较小灯表，内容未变时复用光源表与 proposal。

DDGI 命中点的局部光选择使用功率估计的统一 alias 全局 proposal，混合 5% 均匀概率保留支持。CPU 用 double 建表，按实际上传的 float 阈值回算离散 PMF。共享采样域为 `(光源身份, u, v)`，面积 Jacobian 与侧向在贡献求值中处理，不能把选择 PMF 冒充面积密度。

`LightFrame` 在 CPU 为同一局部源池派生有界近源网格：`16×8×16` 个 cell、每格 8 米，原点随 `Frame::lighting_focus` 按整格移动。点光和矩形光按中心进入一个 cell；每格按全局 proposal 概率保留最多 32 个源，概率相同时以稳定源身份决胜。它不是按灯的 range 或真实受光影响范围铺开的 influence grid，也不进行遮挡、SDF 或 room/portal 查询。远源、跨格大光源及 cell 溢出源仍在全局池中，不被剔除。

接收点按相邻八个 cell 的三线性系数乘各 cell 保留源的概率总量（mass）选择 cell，再用该 cell 的 alias 表选择源。每批 `M` 个初始候选采用确定性的技术配额：局部域有效且 `M≥2` 时，`mLocal=floor(3×M/4)`、`mGlobal=M-mLocal≥1`；`M=1` 或局部域无效时全部使用全局 proposal。完整概率为 `q(source | receiver) = (mLocal/M) × q_near + (mGlobal/M) × q_global`，比例按实际整数配额计算，不能固定写成 .75。所有候选统一以 `f/q` 进入 RIS，再以 `sum/M` 归一化，不单独除以所选技术的条件概率。每批保留全局候选，避免随机技术选择使整批都落在局部域；这不保证任一候选具有非零贡献。

空局部域、网格外接收点、空间采样关闭或无法保持 8 米格边精度的极端 focus 退回完整全局 proposal。cell alias 的 PMF 同样由实际 float 阈值回算，八邻选择与概率求值共用舍入后的 CDF 区间。无论候选由哪种技术产生，求值都使用上述完整 `q`；全局技术保留所有局部源的采样支持。

DDGI 命中处的 fresh RIS 使用上述分布构造、样本域及完整 `q`，每次更新独立抽样，不保留跨帧 reservoir。方向光继续独立逐盏求值，不进入近源网格。网格源版本或整格原点变化时重建并上传，未变化时复用；网格滚动本身不属于辐射变化，不重置光照历史。

解析光的输入计算域沿 [灯光合同](../presentation/README.md#灯类型与参数)，由共享检查同时约束 authoring 和低层 Frame；超界帧在编码前拒绝，保留已接受的画面与历史。矩形光先乘已验证的辐射量与面积，再施加有界衰减。共享检查要求每通道 color × intensity ≤ 2^32，矩形光的该乘积再乘面积也不超过 2^32；结合衰减、BRDF、均匀 proposal 下限和至多 32 个初始候选，这为解析光求值与 RIS 初始累计保留 FP32 余量，普通日光不受 65504 限制。

共享光源求值先准备与接收面无关的采样端点、发射辐射和侧向参数，再计算各接收面的距离衰减、余弦和 BRDF；解析面光先乘已验证的辐射量与面积的数值次序保持不变。

屏幕直接光只计解析灯。发光网格的照明全部由 DDGI 承担：探针射线命中发光面时记录其 emission，命中点 NEE 另计解析灯在该点的反射，二者不重复。屏幕可见 emission 保留。发光面的镜面路径仍由现有 SSSR 表达；离屏发光面的镜面缺失仍是限制。没有发光网格与解析灯的绑定合同，样例发光板与解析面光源仍是独立光源，不应重合用于表示同一个发光面。

## 直接光与阴影 atlas

屏幕直接光只有一条路径，没有视口开关：`lit_cluster_build_cs` 先构建保守灯列表，阴影 atlas 重绘需要更新的面，`lit_compose_cs` 再在一个通道里对每个接收像素逐盏确定求值列表中的解析局部灯与全部方向光，乘阴影可见性，加上 DDGI（或环境）漫反射、AO 与自发光，直接写 HDR。没有随机采样、reservoir、时间历史或空间滤波，也没有直接光专用的中间纹理；相同输入逐帧得到相同结果，灯光、材质和遮挡物的编辑当帧生效。

点光（球光）与太阳的漫反射取光源中心方向；GGX 镜面取 Karis 2013 的代表点，并以 (α/α′)² 归一化，α′ = saturate(α + sinθ/3)。球光的距离窗口从球面起算，衰减的最小距离平方为 max(.0025, r²)。矩形光按立体角积分（Heitz 2016 的线性变换余弦，LTC）：漫反射是裁到接收面地平线的余弦多边形积分，在点光极限下精确，其 (1−F) 取多边形平均入射方向的半角向量；镜面用拟合到本项目 BRDF（GGX、可分离 Smith、Schlick）的 64×64 LTC 表，不是 Heitz 按 height-correlated Smith 拟合的原表；表由 `tools/ltc/fit.py`（Python + NumPy）离线生成为 `src/renderer/ltc_lut.hpp`，改动 `lit_brdf_components` 后要重新生成。LTC 镜面逐方向近似，GGX 长尾在 LTC 支持之外为零。视线与法线夹角在约 65° 以内时，面光照亮平面的逐像素误差在峰值的 2% 以内；更掠射时 LTC 这一族分布表达不了 GGX 波瓣（多起点重新拟合都收敛到同一最优），粗糙度 0.3 的金属在 78° 和 83° 视角下，镜面最多低估约 35% 和 50%。单面矩形只照亮朝向一侧；接收面几何平面把四个角都挡在背后时不受光。距离窗口从矩形的支持半径起算，与 cluster 的支持边界一致，没有最小距离钳制；阴影仍从矩形中心投影。确定求值的平滑衰减在 8 位输出上会显示 1 级量化等照度线，显示编码的静态抖动（见下文第 8 步）把它打散。

阴影是硬阴影：点光与矩形光从光源中心、太阳沿传播方向各取一张深度图，球半径与太阳角半径只影响着色，不产生半影。

`lit_clustered.hlsl` 对实际 GBuffer 接收面构造 16×16 像素 tile、每 tile 四个 view-Z 区间的保守世界 AABB。点光的支持半径为有效 range 加球半径，矩形为有效 range 加两条边长之和的一半（不小于半对角线）；距离衰减在共享求值中处理。每区间最多快速存储 64 个解析局部源，溢出时枚举全部局部源并逐接收点检查支持，保留全部贡献。方向光不进列表，逐盏求值。

Shadows 开启且场景有投影光源时，`ShadowCache` 为每盏投影点光和矩形光派生 cube face 请求（矩形从中心投影），为方向光派生四级级联。CPU planner 只持有派生驻留与失效状态；Scene Lit 持有 GPU 管线、两张 4096² D32_FLOAT 静态/动态 atlas（共 128 MiB 逻辑深度）、描述表和实例索引。点光方向按当前保守接收需求分配，包含接收点一个纹素的法线偏移；投影者来自完整场景，不能用相机可见集裁掉离屏遮挡。点光和矩形光按投影直径选 128/256/512 层级（带迟滞），但只有重要性排前 16 的保留该层级，其余一律 128²；已在高层级的光按 1.25 倍重要性排序，相近的光不会因小幅移动来回换层级并重新分配。这些层级与最多 1024 的方向级联共享 atlas，图块边界含 guard texel。

方向级联的保守接收深度由可见 bounds 限定，有限远相机同时保留其 far 裁剪；无限远 Reversed-Z 相机以齐次远方向构造级联角点，不要求把无穷远端点除以零。光源空间的遮挡深度仍包含完整场景投影者。

级联拟合实际可见接收面的相机 view Z 范围。light-list pass 在每个 16×16 tile 已经算出 GBuffer 接收面的最小、最大 view Z，再对整帧做原子最小、最大，随 ray 计数一起异步回读。规划时取已完成的最新一帧：gfx 录制第 N 帧时第 N − frames_in_flight 帧已完成，当前为 3 帧，所以读数晚 3 帧。每个回读槽记一个相机纪元，换场景、camera_cut 或 Scene Lit 重新启用时纪元加一，纪元不符的读数不用。拟合范围的规则如下：

- 近端取 0.8 × 最小值，向下取整到 1/4 倍频程；远端取 1.25 × 最大值，向上取整到 1/4 倍频程；再夹到保守范围 [相机 near, 保守 far] 之内。0.8 和 1.25 在对数上对称，各约 1/3 倍频程。远端的余量吸收读数滞后的 3 帧里相机后退或转向带来的变化，例如最远 10 m 时可容纳 2.5 m 的变化。近端只影响分辨率，不影响覆盖（见下），所以不再另加余量。
- 1/4 倍频程的量化：范围变化不到约 19% 时分段不变，所以动态物体的小幅移动、或最近像素的亚像素变化不会让级联投影改变、静态层重画。代价是纹素密度最多损失 19%。
- 范围变大（新读数越出当前范围）立即生效，保证覆盖。变小时按两端分别判断：某一端在连续 32 次规划内的每个读数都比当前值往里至少半个倍频程（2 个量化级），才收缩到这段时间读数的包络。只差 1 个量化级的来回变化永远不收缩；离开不到 32 帧（60 fps 约 0.5 s）又回来，也不收缩。相机移动时级联本来就随相机重画，所以推迟收缩的代价只是这段时间内分辨率偏低，不会多画。
- 分段按对数：n、f 是拟合后的近端和远端，级联 0 的终点取 n·(f/n)^(1/4)，其余三级从这一点到 f 按对数均分。拟合后的 n 不再是相机 near，对数分段接近透视下的最优分配。级联 0 的终点不晚于保守分段的第一个点；被截短时，其余三级在余下的范围里按对数分配。每个分段点最后再与保守分段取较近者，所以拟合只会收紧级联，任何一级都不比不拟合时更粗。例如拟合范围 [0.105, 8]、保守范围 [0.1, 8]：级联 0 的对数终点 0.31 晚于保守的 0.22，截到 0.22；余下三级按对数是 0.74、2.43，仍晚于保守的 0.59、2.07，结果与不拟合相同。拟合范围 [2, 4] 而保守范围到 1024 时，分段是 2.38、2.83、3.36，保守分段则是 16.1、64.1、256。
- 级联 0 仍从相机 near 起算，所以比拟合近端更近的接收面仍在级联 0 内，近处没有空档。
- 没有可用读数时（新场景、camera_cut 或重新启用后的头 3 帧、画面没有接收面、相机 near ≤ 0 的正交相机），沿用保守分段：[相机 near, 保守 far] 的固定比例 1/64、1/16、1/4、1。

读数滞后期间，新露出的接收面（移走遮挡物、相机快速转向）可能落在所有级联之外。这样的接收点朝太阳追一条射线求可见性，不按无遮挡或全黑处理；射线长度取 float 最大值，与级联深度覆盖全部投影者一致。射线不在合成里追：合成只把有太阳取不到级联的像素写进一个紧凑列表（每像素至多一项），紧随其后的 `lit_sun_trace_cs` 按列表长度间接派发，对每盏取不到级联的投影太阳追射线，把结果加到 HDR 上。合成不含 RayQuery：含 RayQuery 的合成即使一条射线不追，每帧也慢约 0.3 ms（2560×1440，约 28%）。列表为空时间接派发零个线程组。这类射线计入 direct 阴影射线；有了新读数后范围立即变大，射线随之消失。

级联投影不变而分段变了时，face 复用，但重新发布这一级的起点，让着色时的级联过渡带按当前分段计算。冷分配使用固定占用表快照与实际变更 face 的可复用撤销记录，分配失败原子恢复；暖驻留路径直接复用。

对象首次出现归入静态层，第一次变换、mesh 或 Mask 覆盖编辑后在当前场景持续归入动态层。旧、新 bounds 都使相交层失效，静转动会移除旧静态遮挡；删除同样清旧层。颜色、粗糙度或光强变化复用深度，光源投影变化重新绘制；源重排通过 LightFrame 的前后身份映射保留正确驻留。空场景退休 atlas 与描述资源，重入重新构建。未被完整编码消费的 plan 不可作为有效缓存，正常编码后才 commit；GPU 退休与依赖由 RHI/gfx 负责。

全部投影光源在同一帧同时驻留，不分批。需求超过 atlas 时先逐级降低点光面、再降低级联的分辨率；仍放不下时按重要性预留：方向光优先，点光和矩形光按亮度×功率×相机所见支持球立体角从大到小。最低分辨率仍放不下的光整盏放弃：本帧它不贡献直接光（计入 `dropped_lights`），不把缺失页当作无遮挡，也不只画一部分面。两层先逐 tap 取 reversed-Z 遮挡并集，再过滤，禁止先分别滤波后错误组合可见性。

方向级联需要时总是当帧重绘，不占预算；其余 face 每帧最多重绘 24 个。一盏点光或矩形光需要重绘的 face 整盏一起画，所以一盏光已画的 face 总来自同一个原点；GPU 光源记录带上这个原点，取样按它选 face、做投影，不按光源当前位置，否则光源移动而重绘被延后时 cube 接缝附近会落到旧 face 外。有无内容 face（新分配、换尺寸）的光排在前面，只有过期 face（光源移动、投影者变化）的光在后，各自按连续等待帧数从长到短、再按重要性排队；整盏放不进本帧剩余预算就整盏延后，继续尝试后面的光。光源移动后还没重绘时，按绘制原点为当前接收面需要的 face 也一并请求，保证延后期间取样选中的 face 都在；光在新原点重绘时，没有一起重绘的旧 face 作废。`stable_key` 为 0 的光没有跨帧身份、不保留缓存，face 和级联一样每帧重绘，不受预算限制；编辑器和 Project Run 的光都有非零键。辐亮度为零的投影光不请求 face。被延后的光沿用上一次的原点、投影、深度范围和内容（其 face 计入 `deferred_faces`），所以这类阴影会滞后一到几帧；`deferral_frames` 是被延后的光连续等待的最长帧数。只要有光被延后，本帧至少已画 25 − k 个 face（k ≤ 6 是那盏光需要的 face 数），因此 N 个待画 face 在 ⌈N/19⌉ 帧内画完。一盏光只要还有需要的 face 没有内容，就整盏不贡献直接光（计入 `pending_lights`），不会在没有阴影时照亮被挡住的接收面；画齐后，等待过的光用 8 帧线性淡入，当帧就画齐的光直接全亮。DDGI 命中用光线追踪可见性，不读 atlas，照常计入这类光。加载、开关 Shadows 或切回 Scene Lit 时所有 face 都要重画，光按重要性逐盏亮起（例如 5 或 6 个 face 的光每帧 4 盏）。同重要性的光优先保留已有 face 的那盏，调整光源顺序不会换一批光驻留。

取样先把接收点沿几何法线移动所用 face 的一个内部纹素（点光按到光源的距离，太阳按级联半径）。World 的 `shadow_bias` 仍可编辑，但 Renderer 只校验它的值域，不读取它；DDGI 与反射等次级射线的起点偏移固定为 2 mm。过滤是 3×3 帐篷：四个相隔半纹素的双线性 tap，用 4 次 GatherCmp 取 2×2 比较块，静态、动态两层逐纹素取遮挡并集后再加权，滤波足迹留在 guard 纹素内。每块的比较深度是偏移点的设备深度，按接收面自身（未偏移）平面的斜率外推到块中心；偏移平面在掠射时会越过点光源、使斜率反号，接收面平面只要朝向光源就不会。一个纹素的法线偏移在任何入射角下都大于块内纹素相对块中心的半纹素平面斜率，所以平面接收面不会自遮挡；接收面所在平面经过或背向光源中心时不外推，按投影点深度比较并计入 `plane_fallbacks`（只有球光或矩形光会这样照到它，零半径点光照不到）；N·L 小于偏移比例时偏移点越过接收面的地平线，外推的比较深度可能低于 0，此时按 0（远平面）比较，只有空纹素算受光。深度梯度溢出（掠射）时同样退回投影点深度并计入 `plane_fallbacks`。方向光包含级联过渡，选中级联取不到时依次用更大的级联，所有级联都取不到时朝太阳追一条射线（见上文级联拟合）。接收点位于发光球内时仍从球心 cube 取阴影。

`direct_cluster_inspect` 只在明确开启时编译/派发接收面支持统计，给出 0～64、>64 的 66 档直方图与最大值。正常入口编译去除该统计工作；不常驻读回逐像素数据。计数是解析局部光保守支持，不含方向光或遮挡判断。普通 cluster 数量/溢出与该接收面分布采用同一完成帧发布。

## 同一帧的执行链

1. 光栅 GBuffer 写入着色法线/粗糙度、基础色/金属度、HDR 自发光、运动信息、独立 R32_FLOAT 预期前帧设备深度与 RG16_FLOAT 八面体几何法线。法线贴图只改变着色法线；偏移、支持平面和历史深度梯度使用几何法线。当前 D32_FLOAT 深度、前帧 R32_FLOAT 深度与 RG32_FLOAT min/max Hi-Z 都遵循有限 Reversed-Z；方向和背景约定见 [Renderer 合同](contract.md#场景和-ui)。屏幕坐标使用整个窗口，`scene_viewport` 处理物理像素偏移，支持透视与正交投影。
2. 共享不可变网格缓存 BLAS，稳定实例更新 TLAS。每个快照索引记住上一次完整编码时对应的对象和网格；对象和网格不变时不查哈希表。材质表修订号不变、对象仍在原索引上时，不逐槽比较材质。成员、网格和材质都没变的帧跳过覆盖扫描与退休扫描，未变且已稳定的对象只重新登记阴影投射者。内联 RayQuery 完成灯光可见性和 DDGI 探针射线；RHI 只在支持 DXR 1.1 的硬件上打开 Context，Renderer 不另做能力判断。
3. 有限体积 DDGI：规则 XYZ 探针格、八面体方向辐照度与距离矩、背面分类、受限位置修正、分帧采样与逐帧照明过渡，以及有界上一轮间接反弹。屏幕接收点用实际射线可见性选择八探针贡献，直接输出间接辐照度。
4. GTAO 基于深度重建与地平线积分，使用独立历史，只调制间接项。一次派发先写出 R32_FLOAT 视空间深度及其四个缩减层级；缩减层级只平均足迹内接近最远表面的深度（XeGTAO 的深度 MIP 思路），空像素不当作遮挡者。地平线 tap 按距离选层：约 14 px 内用全分辨率，之后每倍距离升一级。视空间位置由带 jitter 的投影系数经乘加重建，透视与正交投影通用。积分、切线、偏置和衰减按世界空间公式计算。resolve 由 8×8 工作组把 12×12 邻域的世界位置、法线和原始 AO 一次性载入组共享内存，再做 5×5 空间支持和时间重投影。
5. 直接光：保守灯列表 → 阴影 atlas 更新 → 融合 compose，逐盏确定求值解析局部灯与方向光（GGX 全项），乘 atlas 可见性，与 DDGI/环境漫反射、AO 和自发光一起写 HDR。
6. SSSR 使用 GGX 随机反射方向、分层深度遍历、工作列表和间接分派，随后按表面/命中对应关系重投影，使用独立历史计数、FP32 亮度矩与三个步长的方差滤波；空间重建保留材质边界。屏外、遮挡或追踪失败回退到均匀环境辐射。环境控制变量的有符号估计保留至最终 HDR 合成，避免逐样本截零引入额外亮度偏差；SSSR 关闭时环境反射直接通过。
7. 合并 HDR 光照，按抗锯齿设置执行 TAA 或当前帧直通，同时写入下一帧表面深度与法线；随后执行 Bloom、EV 曝光和 SDR 色调映射。
8. SMAA 两种模式在色调映射后的线性 SDR 场景颜色上重建边缘；选择 T2x 时再组合两个独立空间结果。显示 pass 把线性 SDR 颜色按 sRGB 分段曲线编码到 8 位，加一个宽 0.99 级、RGB 共用的静态屏幕空间 IGN 抖动后取整，再用同一条曲线解码交给 sRGB RTV；RTV 重新编码时得到的正是所选的码值。图案只取决于像素坐标，不随帧变化，所以相同输入得到逐字节相同的输出，恰好落在码值上的颜色（包括 0 和 255）不变。最后沿既有入口合成参考辅助显示与 UI。采用 jitter 的模式在需要辅助显示或 Capture 时，复用深度通道重建公开相机对应的无抖动深度，内部光照历史保留采样深度。

以上通道沿现有显示设置入口控制。环境是均匀天光乘可选的方向天空贴图：DDGI 探针 miss 读贴图的 radiance cube，背景显示贴图；DDGI 关闭时的合成与 SSSR 的环境回退读贴图的立体角均值，即均匀辐射场，预积分 GGX BRDF LUT 用于其镜面响应。没有场景反射探针资产、透明材质、蒙皮 BLAS、全路径追踪或超分辨率接入。

关闭 SSSR 时仍写入环境回退和空来源历史，但跳过 HiZ 构建、工作列表 reset/prepare 与三个反射空间滤波通道；下一次开启重新构建这些输入。关闭 Bloom 时跳过下采样和两次模糊，色调映射沿原开关忽略 Bloom。实例表、光源表与阴影批次表都常驻默认堆（`DeviceTable`），变化的内容先写入本帧槽再拷入，内容未变的帧不拷贝；这些表被直接光、DDGI 与阴影光栅逐像素或逐顶点反复读取，所以放在默认堆。实例表逐项比较完整 GPU 数据（包括 previous_world、历史有效位和几何偏移），只拷变化的连续区间，物体停止运动后的前帧矩阵更新仍会上传。阴影作业内的投射者按几何组排序，同一网格的投射者合成一次实例化绘制。法线矩阵按 world 变化计算，统一光源快照按真实 Renderer sequence 推进前后状态，不以可重复的 UI 帧号判定帧生命周期。

直接光、DDGI 屏幕 gather 和 GTAO 共用 `lit_screen_dispatch` 的整数原点与独占终点，只派发视口内接收像素；坐标、纹理索引和随机数仍使用原窗口坐标。终点按像素中心与小数视口相交；原点向下取整到 16 的倍数（cluster tile 尺寸），8×8 线程组与纹理分块对齐，多出的左上边距由 `lit_inside` 和表面检查早退或写中性值（compose 在这里写零 HDR）。未对齐时线程组会跨越纹理分块边界（编辑器最大化视口的原点是 (57,255)）；覆盖整窗的游戏视口原点为 (0,0)。Compose、SSR 分类与反射 resolve/filter、TAA 与表面历史、色调映射和 SMAA 同样只派发视口；每次历史复位（含视口变化、AA 切换与目标重建）后的两帧仍覆盖完整窗口，使两组 parity 的视口外纹素保持零或远深度，SMAA 搜索等越界邻域读取得到与此前相同的值。Bloom 与深度金字塔仍按完整目标派发；邻域消费者先检查表面和视口。这个裁剪不改变光源池、TLAS 或离屏探针更新。

SSSR 逻辑深度第零层直接读取既有 D32_FLOAT，物理 RG32_FLOAT 层从 2×2 min/max 归约开始，删除全尺寸 `(z,z)` 副本；FP32、奇数尺寸尾部和视口外远平面语义不变。首级与后续级使用同一归约算法的独立编译入口，避免单像素层级发生 SRV/UAV 别名。

## DDGI 探针场

权威运输估计使用双缓冲 RGBA32_FLOAT atlas，逐帧呈现使用单份同格式 atlas。`DDGICopy → DDGITrace → DDGIUpdate → DDGIPresent → DDGIResolve` 沿唯一 pass owner 执行：Copy 保留未选探针，Update 读取不可变的上一轮运输场并写当前运输场，Present 在 Update 后按帧时间平滑到呈现缓存，Gather 和空间诊断读取呈现。呈现绝不参与反馈。Present 是一次有界的逐 texel dispatch，计入 DDGI update 区间。一个 receiver 的照度八面体编码与四个折叠 texel 偏移仍只计算一次。

`Frame::render_delta_seconds` 是与 Play 解耦的活跃渲染间隔，有限范围 `[0,.1]` 秒，固定步进调用方默认 `1/60`。编辑器与 Project Run 共用 accepted RenderClock：无可绘制视口、停用 DDGI、跳过或拒绝帧时重建基线；恢复首帧为零，连续慢帧限幅推进而不永久冻结。Present 的时间常数为 `.15s`，旧权重 `exp(-delta/.15)`。零时间只保持有效缓存，fresh、inside、重定位与场景替换仍立即撤销旧位置照度。该时间不参与运输统计的访问权重；低更新预算仍受实际观测和多跳传播速度限制。

Mask 模式、alpha 因子/阈值或相关贴图采样描述改变，均属于实际遮挡变化；即使不需要重建 BLAS，也启动距离历史的两轮响应及屏幕可见性响应。普通 Opaque 基础色编辑只改变辐射响应，不被当成距离变化。

`SceneLitSettings::probe_volumes` 提供四个有稳定身份的槽位，按 0→3 优先查询；固定与跟随体积共用同一描述、采样、资源池和调度。默认只开启 slot 0，范围 `[-6,-1,-6]` 到 `[6,5,6]` 米、`8×4×8` 共 256 个探针，每帧更新 64 个。每次更新分开使用 **32 条固定几何射线**和默认 **128 条照明射线**：前者负责背面分类与受限位置修正，后者随机旋转并估计照明，不用随机照明结果驱动探针位移。初始化或没有有效历史的探针一次到达受单元约束的几何目标；已有有效历史的探针缓慢修正。

固定体积每轴支持 2～32 个探针；`follow_focus` 各轴必须满足 `count ≥ 3 + 2×max(1, blend_cells)`，至少五个，以保留完整接管的内部区域。所有启用体积的**总数不超过 4096**；照明射线数支持 1～256，所有体积共享每帧 1～4096 个更新预算。`probe_settings_error` 校验描述，`probe_focus_error` 连同世界关注点校验实际精度；renderer、UI 与 Control 共用此约束，应用在发布候选状态前完成检查。运输历史与显示辐照度均使用 RGBA32_FLOAT，在照度线性域混合；距离矩保持 RG32_FLOAT，世界重定位 offset/state 保持 RGBA32_FLOAT。

静态辐照度/距离历史权重为 .93/.95。灯光、环境辐射、天空、材质、发光体或物体变换的变化提升响应代次，各探针的每个方向 texel 独立推进响应：前4次有效观测的旧权重 .6，接下来8次 .8，完成12次后回到 .93。无方向支持与 hold-irradiance 不消耗响应次数，合法零照度会消耗；光源变化保留 RGB、coverage、距离与成熟度，fresh/inside/重定位沿原失效边界清理。代次回绕只清响应状态；单次随机亮峰不触发响应。稳定身份下的灯光重排、材质索引重编号、previous 映射推进及对象纯重排不当作照明变化。几何变化仍使距离进入两轮响应期、权重 .85。初始化按实际观测预热。

每个有效照明批次保留 Fibonacci 球面覆盖，用探针自身实际访问驱动的 R3 整数 Weyl 相位生成均匀旋转；未调度的探针不推进，改变每帧预算不会跳过该探针的旋转序列。32 位访问游标回绕后换独立相位；新空间身份或失效原点清游标，普通光源变化不清。固定几何分类射线保持独立。主方向和软太阳随机域与局部 RIS 候选数分开；这不取消合法高能贡献，也不改变现有 cosine-normalized 卷积的统计性质。额外状态为每方向 RG32_UINT 响应与每探针 RG32_UINT 游标，4096 探针时约 2.03 MiB；没有扩大射线预算或复制运输 atlas。

固定体积的 min/max 是世界坐标；跟随体积的 min/max 是相对 `Frame::lighting_focus` 的范围，关注点由宿主提供，编辑器使用相机 target。间距保持固定，跨整数格点时改变环形地址；亚格移动不会重建场。跟随影响范围在存储边界内缩一格，并随关注点连续移动，避免离散换片直接接管接收面。负坐标采用正模，跨多轴清理进入切片的并集；整跨缓存跨度按整层新区域处理。历史传递同步清理新区的运输/呈现辐照度、距离矩、offset/state 与年龄；反馈始终使用上一轮描述及其不可变纹理快照，不将旧槽位解释为新的世界位置。

缓存范围不限制照明射程。不可变几何缓存保有局部 AABB，场景几何/拓扑/TRS 改变时以八角变换维护共享世界 bounds；每个探针的射线追到足以越过这些场景几何的位置，才能将 miss 解释为天光。局部 distance 归一尺度仍随 volume 固定，远于该尺度的距离在形成一/二阶矩之前逐射线截断；固定几何射线最近命中搜索使用完整实际距离。小体积不能因忽略远墙而在密闭室内引入天光。

初始化/重定位缺失与有效黑色分开。体积内部照度按合法八邻权重归一化；体积之间依边界与实际观测预热程度分配剩余权重，不累加两份完整 GI。四次有效方向观测完成预热，颜色不参与就绪判定；较优先体积的有效黑色同样占有权重。优先体积覆盖完整时停止查询后续体积，缺失时后续体积也必须通过自身遮挡。`blend_cells` 控制固定区域边界的 0～2 格过渡；跟随区域至少使用一格过渡。体积包围不保证室内有效支持，接收面缺口仍需用 Debug 检查。

调度将新区前两次访问优先安排，同时每帧至少保留四分之一预算（最少一次）给全池分散轮转；离屏、静态表面仍参与高阶传播，不能永久冻结。初始化也计入同一个预算。共享 atlas 尺寸改变时整体资源重建；普通滚动和相同配置重复提交保留交集历史。改变体积尺寸/间距/摆放模式只失效对应身份范围；若物理池布局随启停或计数改变，其受影响范围也失效。

几何变化后的距离两轮响应期按全局轮转游标实际覆盖进度推进；优先反复访问新切片不会提前耗尽远处探针的距离响应机会。辐照度响应使用上述每方向有效观测代次，不消耗全局轮转预算。工作列表仅传入执行探针更新的通道。八邻按原顺序循环，避免在复杂命中着色路径内强制展开八份可见性查询；这些是明确工作裁剪，不代表已测得特定毫秒收益。

探针更新分为 `DDGITrace` 与 `DDGIUpdate` 两个计算通道。前者执行固定几何射线、分类/重定位和主照明射线，保存完整命中材质及 FP32 实际带符号距离；后者执行命中处光照、反馈查询、方向卷积和历史写入。两者共用本帧工作列表、采样序列及前帧反馈快照，不重复射线或增加更新预算。中间记录每条 64 字节，按本轮探针数乘照明射线数保留可复用容量，默认 512 KiB，最大 64 MiB；不活动探针先清除输出再返回，不读取未写记录。缓冲和当前 offset 在阶段之间沿 gfx 的 UAV→SRV 转换建立依赖，扩容及空场/关停沿现有资源退休机制处理。

`probe_bounce` 为 0～0.99 的反馈运输系数，默认 .85；`probe_feedback_visibility` 默认 true，false 仅用于距离缓存遮挡近似的诊断对照。改变它们会使旧运输解失效。`indirect_gain` 为 0～8 的最终间接漫反射增益，默认 1，在 DDGI 合成时只应用一次，不回写探针，也不因增益改变而清空探针场。它不创建缺失的空间支持。

照明预算实际执行请求的 1～256 条；固定几何射线仍为独立的 32 条。方向 texel 在本轮没有有效照明观测时保留原运输估计与观测计数，初始化无观测保持无效；距离矩也只在自身方向支持有效时更新。低预算需要更多轮收敛，不承诺与默认预算在任意光场中等价。

DDGI 的 inside 分类只使用闭合组件的几何背面。每份不可变 Mesh 首次进入 Scene Lit 几何缓存时，按精确位置边邻接派生逐三角形信息，跨 UV/normal seam 保留连接；开放、非流形、朝向歧义、退化或零体积组件不作为实体内部证据。几何法线沿作者法线确定正面，并经实例逆转置变换，保留反绕序、镜像及独立内壁壳的朝向。开放背面仍提供正遮挡距离，现有着色侧语义不变。此信息不改变多边形线框掩码，也不宣称完成任意自相交网格的实体判定。

八探针查询只对朝向与可见性置信度做小权重压缩，随后乘线性的三线性空间权重，避免把每个探针的影响范围锐化成块。累积按实际非零权重和归一化，不把低置信度额外当作遮蔽。屏幕接收点经现有 RHI 的 TLAS 查询探针到表面的实际可见性；无效探针、零空间权重和无效辐照度在追踪前排除。该射线的接收点只沿法线偏移 `max(0.1 mm, 最小探针间距 × .0001)` 以处理端点数值误差，不使用方向距离滤波所需的大偏移。距离缓存提供连续方向权重，实际射线则强制剔除被阻挡的贡献，两者共同决定插值。仅用二值射线替代方向权重会暴露探针成员切换的硬轮廓；仅用距离缓存又会让错误贡献污染墙角。组合不增加环境光，也不为被阻挡的探针保留可见性下限。

距离矩方向权重沿用最小探针间距 .12 的法线偏移：先对四个相邻距离 texel 各自计算 Chebyshev 上界并取三次方，再双线性插值可见性，避免先混合距离矩引入额外方差。**反弹反馈默认也执行真实段遮挡**，与屏幕查询使用相同的数值端点、选格、选层和权重语义；统计偏移只影响距离缓存，不改变反馈的八邻选择。诊断关闭反馈 LOS 时只改变遮挡判定，不同时改变 stencil。距离矩仍为 8×8 RG32_FLOAT，方向锥内混合几何和稀疏支持的近似仍存在；严格遮挡不能保证只有少量可见探针时插值连续，也不是无偏精确光传输的声明。

完整 gather（探针到接收面的实际 LOS、连续距离权重和距离矩）在每个 2×2 块只对一个代表接收点执行：按 (0,0)、(1,1)、(1,0)、(0,1) 的固定次序取第一个表面像素。结果写入四分之一面积的 RGBA16F `indirect_half`，alpha 记录代表点序号。全分辨率上采样只读取四个最近块的代表点，权重为高斯距离 × 平面距离（容差两个像素尺寸）× 几何朝向（点积 > .9）× 着色法线相似度的 8 次方。若总权重低于 1e-4（薄墙、孤立几何、贴边），该像素不借用其他表面的探针，进入回退列表。列表首元素是计数，其余为打包像素，容量为接收像素的四分之一，溢出部分在上采样中内联完整 gather。随后按列表间接派发，每个回退像素在连贯的 wave 中执行精确 gather，避免零散的精确 gather 拖慢几乎所有 wave。墙角、亚像素隔墙与运动的验收见[验收记录](acceptance.md#--scene-lit-quality)。

若接收材质的 `base_color × (1 − metallic)` 严格为零，上采样直接写零，该像素也不进入回退列表；2×2 块内没有任何接收点需要漫反射时，跳过代表点 gather，省去无贡献的探针可见性查询。代表点仍只按几何选择，材质只决定是否执行，因此材质编辑不会让 LOS 缓存记录对应到另一个接收点。没有亮度阈值，极小非零漫反射仍正常计算。世界空间探针更新不受影响。Receiver Coverage 在显示阶段单独查询，不改变此优化或光照射线统计。

非抖动视图的屏幕 gather 缓存代表点的精确 LOS 结果：每个 2×2 代表块使用 32 个可见位和 32 个有效位，对应四个体积各八邻。只有投影/逆投影、视口、体积描述一致且完整场景几何/Mask 未变化时才允许复用；shader 继续精确比较当前与前帧的 FP32 深度、表面身份、几何法线，以及该 probe 的实际 offset。每帧仅保留实际参与查询的有效位；相机移动、物体增删/变换、遮挡材质编辑、滚动布局和重定位均重新判定。照度、距离矩权重、就绪度与反馈传播不缓存，改光不必重查未变的遮挡。feedback、Coverage 和 inspection 仍独立精确查询。缓存按 2×2 代表块存储，块内保持同一代表点才复用，缓冲为每块 8 字节，2560×1440 目标为 7.03 MiB；回退列表的精确 gather 不读写此缓存。它按完整 render target 分配，不能把窗口尺寸与 viewport 混淆。resize/关闭沿已有 gfx 退休，空场/模式退出/失效禁止旧位复用。TAA/SMAA T2x 的 jitter 每帧改变端点，禁用缓存读写；首次启动只绑定一个元素占位，已有容量可保留到目标退休。此优化不降低距离或深度精度、不跳过被挡候选的归一化责任；缓存与每帧重新追踪的一致性见[验收记录](acceptance.md#--scene-lit-cost)。

默认 256 个探针的两份运输 atlas 加单份呈现 atlas 合计 768 KiB 逻辑字节。分批更新的运输历史采用上述每方向有效观测响应与静态 .93 权重；呈现每帧向最新运输场推进，时间常数不随更新预算变化。初始化、进入几何或位置修正同步清除无效运输与呈现，下一次有效采样重新建立支持。

探针命中点逐盏显式评估方向光，对统一局部源使用 `direct_candidates` 个候选的新 RIS，每次更新独立抽样，不保留跨帧 reservoir。这样少量强太阳不会因大量局部灯混入同一个均匀池而漏选。命中点的阴影查询归入 visibility 计数，固定几何与照明的主探针查询归入 probe 计数，所以总射线量不等于“更新探针数×照明射线数”。灯的 `casts_shadow` 保留其命中点直接光遮挡语义；主视图 Shadows 开关不取消探针命中点的遮挡。

命中点材质按完全粗糙（roughness 1）求值，颜色、金属度和 F0 不变。探针原点是一个点，光泽 GGX 波瓣朝向它时，只有极少数射线方向能对准光源的镜面反射方向，单条射线的辐射可达典型值的 30～70 倍；新场前 12 次更新的单次样本权重为 20～50%（成熟后为 7%），吸收这类样本后会出现持续约百帧的亮斑。完全粗糙求值仍计入镜面响应（同一 GGX 模型在粗糙度 1 下求值，单次散射本身在高粗糙度下略有能量损失），只是把它分散到整个半球。这属于路径正则化，与 Lumen 表面缓存的 fully rough 折算、RTXGI 和 Flax 的纯漫反射命中属同类取舍。代价是光泽面朝特定方向的集中反射（例如光泽地面把太阳反射到立柱）在 DDGI 中被摊平；屏幕可见的镜面反射仍由 SSSR 负责。

当前仍是有界、低频的漫反射场，有探针插值与更新延迟；支持有限固定/跟随体积组合，不包含无限世界流送、自动房间拓扑分配或稀疏砖块，也不能单独表达细小几何的全部近场遮蔽。实际场景应在同一预算下选择粗细覆盖或房间/楼层局部密度，不能把“恰好两层”当作普遍足够的结论。

## DDGI 空间与接收面诊断

World Settings → Diagnostics 中的 DDGI 显示与 Control 的 `view.set` / `render.compare` 共用 `ViewOption`。显示诊断默认关闭；设置属于视口，不创建 Entity、TLAS 实例或发光体，不写场景撤销与保存数据。

参数名称、范围和中英文说明来自编辑器的同一 `ViewOptionInfo` 定义，World 属性行与 Control 查询共同使用。悬浮说明解释字段的实际作用；它不参与渲染设置求值、场景序列化或 GPU 诊断数据采样。Scene 作者值与视口诊断的区别继续由 `world_option` 和既有提交链决定。

- `probe_visualization`：`off`、`irradiance`、`state`、`update_age`、`distance`。球心读取本帧完成更新的真实 offset；辐照度读取对应八面体方向，显示 `E / π × exposure` 经 `c / (1 + c)` 映射；它是探针数据预览，不是最终表面光照。距离读取 FP32 距离矩中的方向均值，黑到白对应 0～4 倍最小探针间距。
- `probe_volume` 显示实际滚动后的边界，`probe_relocation` 连接原格点与实际位置；四个槽位用青/黄/紫/绿区分。`probe_debug_volume=-1` 显示全部，0～3 只显示对应槽位。`probe_radius` 为最小格间距的 0.01～0.45 倍，默认 0.12；半径只影响显示，不改变采样。
- `probe_xray` 忽略场景遮挡；探针之间仍有深度遮挡。空间诊断在 AA 完成和无抖动编辑深度重建后执行，使用私有 D32_FLOAT 深度，保留正式 scene depth 给拾取、Capture 和编辑辅助线。未启用时没有诊断绘制或深度副本。
- Update Age 记录距上次**探针评估**经过的 DDGI 更新帧数，包括 inside/relocation 评估，不表示有效照明样本数或墙钟时间。青色表示本轮刚评估，绿到红表示一个预算轮转的年龄，灰色表示尚未评估。每探针 R32_UINT 占 4 字节，随现有 copy/update 维护，无额外 dispatch 或逐帧 GPU 读回；随探针场重建/重置清除，DDGI 关闭时不推进。

`probe_debug=true` 开启 Receiver Coverage；`probe_coverage` 选择 `status`、`volume`、`contributors` 或 `dominance`。查询沿真实多体积 gather，包括段遮挡、偏置、方向权重和历史，不以最近球推断表面质量。Volume 显示主导槽位及覆盖就绪度；Contributors 显示实际参与的邻居数量；Dominance 显示最大归一化贡献占比，接近红色意味着由很少支持主导，需要结合遮挡与密度观察。有效但严格零辐照度仍单独标记。

| 颜色 | 接收面含义 |
| --- | --- |
| 灰 | DDGI 关闭或没有当前场 |
| 蓝 | 超出当前体积 |
| 橙 | 相关探针尚未就绪或正在重定位 |
| 红 | 相关探针处在实体内部 |
| 紫 | 没有非零方向权重 |
| 棕黄 | 探针可用，但所需方向尚无有效照明观测 |
| 粉红 | 有方向观测，但贡献候选被遮挡 |
| 青 | 有有效支持，但辐照度为零 |
| 绿 | 有光照贡献；越亮表示贡献探针越多 |

跨体积全部失败时保留优先槽位的实际失败原因；体积内部待初始化优先于 inside。球体 State 直接显示探针自身分类。关闭 DDGI、空场景或场被失效时，空间设施显示灰色配置位置，不把旧照明当成当前数据。`FrameStats::scene_lit_probe_volumes` 提供每槽实际 bounds、spacing、resident、updated 与 reset_probes；这些是 CPU 本帧布局/调度事实，不是 GPU 完成或有效探针统计。

Coverage 在色调映射/最终 AA 后显示，仅覆盖有表面的像素，和空间球都不进入 DDGI、反射、Bloom 或 AA 历史。诊断模式单独查询可见性，开启时有额外 GPU 成本；这部分不混入既有光照阶段时间和射线计数，性能采样应关闭诊断。没有常驻全场探针读回。Control 可按需设置 `probe_inspect` 和物理窗口像素 `probe_inspect_x/y`，由同一 gather 记录至多四层×八邻贡献。完成样本包含源帧/sequence、scene identity、采样像素、当帧布局、实际照度与运输估计、方向观测、年龄、空间/朝向/距离/最终权重及支持拒绝阶段；这些值不假装属于 CPU 当前帧。背景或越界返回无 receiver 的明确样本，空场/关闭检查/DDGI 停用返回 null。32 槽异步读回无空闲槽时跳过，正常渲染不等待，关闭后有界缓存留到 Renderer 退休。此诊断增加独立 gather，包含在 DDGI 父区间但不计入 update/gather 子区间，性能测量应关闭。

`probe_inspect_source` 沿统一 typed ViewOption/Control 入口选择射线检查的全局物理 probe 槽位，范围 `-1…4095`，默认 `-1` 自动选择上一份同场景、同像素完成样本中原始 gather 权重最大的有效邻居；这不等于亮度贡献最大的邻居。显式索引不要求它属于所选像素的八邻，允许检查次贡献探针；索引超出当前驻留池时不回退其他探针。完成样本的 `requested_probe` 保存原请求，`traced_probe` 为实际选择（无选择时为 `UINT32_MAX`），`probe_selection` 区分 `automatic / automatic_pending / explicit / explicit_out_of_range`。选择只改变视口诊断，不写 World/Scene/Undo，不强行调度探针、不清照明历史；显式范围外返回空射线记录，空场或 DDGI 停用仍返回 null。读回有延迟，消费方须同时核对请求、像素、场景和 sequence。

`ProbeInspection::Ray::sampling` 依次记录 reservoir 权重、该命中接收面所选源的完整 proposal PMF `q(source | receiver)`、反馈亮度和主射线命中距离。`sampling.y` 在空间采样开启时包含近源/全局混合，不能再解释为全局源表 PMF；无选中样本时为零。它仍是离散源选择概率，不是面积 PDF。新增 `light_endpoint_distance` 为所选局部源的实际采样端点 XYZ 与 hit→endpoint 距离；没有有效所选端点时 w 为 -1。`source_radius_range_area_min_distance_squared` 依次提供源半径、源范围、面积与衰减使用的最小距离平方。半径/范围/面积按 `identity.y` 的源类型解释。`sampling.w` 继续表示 probe→hit 距离，不与新距离混用；方向光贡献仍在 `direct_luminance.zw` 中独立记录，不套用局部源端点。

每条有效射线记录为96字节，仅在 inspection 已开启且所选探针本轮实际更新、命中可着色表面时写入；未记录 ray 不表示零贡献。每帧清理可选记录缓冲，显式越界请求不会留下另一探针的旧记录。端点通过已有 `LitLightSample` 和同一选中 UV 重建，不增加随机抽样或可见性查询；普通路径不增加 pass 或资源。仍未记录完整 RIS 候选、独立 visibility 结果或光源业务身份，源索引只能解释为该完成帧的打包源域。

`probe_history` 的 `live / hold_irradiance / hold_distance` 仅作视口归因对照，不写 Scene/Undo。前者冻结有效运输与呈现 RGB，后者冻结距离矩；几何身份失效始终优先。它们不能作为生产稳定算法。`--scene-lit-stability` 沿已有真实 Renderer 验收入口输出异步 CSV，覆盖通道冻结、运输/显示时钟分离及场景/像素生命周期。

端到端入口：`atelier_renderer_acceptance --scene-lit-stability --output <绝对目录>` 覆盖多体积、共享预算、滚动寿命和运输/增益合同，以及隔墙传播；`--scene-lit` 覆盖空间显示回归，二者都使用真实 GPU。`atelier_editor_control_acceptance <editor.exe> <绝对输出目录> --ddgi-debug` 验证正式编辑器、统一选项发现、幂等 patch、非法 patch 原子拒绝、临时对照及场景/撤销隔离。各入口证明的内容见[验收记录](acceptance.md)。

## 显示菜单与近场策略

World 页统一编辑光照与效果的作者配置，进入同一 World 值和 Session 历史，包括 Shadows、DDGI、GTAO、SSSR、Bloom、Local GI（渲染器不读取，见下）、抗锯齿、曝光和探针命中点的光源候选预算。诊断仅改变视口偏好。Scene View 显示菜单只切换着色与边线预览。Control 临时渲染对照使用独立求值覆盖，不写入场景或撤销历史。

**Window → World Settings** 打开可停靠的 World 配置页，分为 Lighting、DDGI、Effects、Diagnostics、Performance。Lighting 的 `direct_candidates`、覆盖布局与共享传播作者参数随 Scene v8 保存；`spatial_light_sampling`、探针球、接收面指标、体积/重定位叠层以及反馈可见性诊断留在视口。Diagnostics 的 Spatial light sampling 默认开启，关闭后 DDGI 命中点的 fresh RIS 使用完整全局 proposal；此开关由统一 ViewOption/Control 入口读写，不写 World、Scene 或 Session 撤销历史，也不关闭 CPU 网格维护和已有 GPU 缓冲的驻留。本帧 CPU 布局读数仍是瞬时状态。Coverage 提供明确的 Fit Scene 与 Scene + Follow Focus 操作；字段草稿在提交时整体校验，UI 与 Control 不各建一套参数语义。具体页面和交互见[编辑器场景光照](../editor/README.md#场景光照)。

`SceneLitSettings::antialiasing` 为 `Antialiasing::{none,taa,smaa,smaa_t2x}`，菜单显示 Off / TAA / SMAA / SMAA T2x，默认 SMAA。所有模式均使用原生分辨率：

| 模式 | 采样与历史 | 处理位置 |
| --- | --- | --- |
| Off | 无相机 jitter、无最终颜色时间累积；信号自身降噪继续运行 | 当前 HDR 合成后曝光、Bloom 和色调映射 |
| TAA | 八相位 jitter，递归 HDR 颜色历史与局部有效性校验 | HDR resolve，Bloom 和色调映射之前 |
| SMAA | 无相机 jitter，单帧边缘检测、模式面积估计与线性邻域混合 | 色调映射后，UI 之前 |
| SMAA T2x | 两相位四分之一像素 jitter；当前与上一帧的独立 SMAA 空间结果，前帧权重最多 .5 | 与 SMAA 相同，再执行两帧 resolve；最终结果不回灌空间历史 |

SMAA 使用固定版本的上游面积/搜索 LUT；边缘判断读取非线性 sRGB 亮度，颜色混合保持线性。T2x 仅为颜色重投影去除两相位 jitter，复用上游邻域核计算颜色和抗锯齿速度，以原始两帧 point 采样和速度幅值控制最多 .5 的历史权重。GBuffer motion 的 xy 仍含 jitter、z 表示几何覆盖、w 表示对象与着色材质对应有效性；材质编辑不破坏前帧几何矩阵与 FP32 深度。轮廓前景／背景是互补子样本，不能按深度或背景差异一律拒绝。新增、删除或新显露区域可能混合一帧旧空间颜色，下一帧不再包含该颜色；最终结果不递归累积。

T2x 补充亚像素轮廓信息，不替代直接光、反射或 AO 自己的信号降噪，也不承诺恢复单帧完全漏采样的几何细节。原生 SMAA 的 shader、LUT 来源与许可见 [第三方记录](../../../third_party/smaa/README.md)。

Local GI 对应 `ssil`，没有渲染实现，渲染器不读取它；World 与编辑器仍保存它，并保持它与 GTAO 互斥（开启 Local GI 会关闭 GTAO），所以开启它的效果只是没有 AO。

## 身份与历史

World/Runtime 仍是业务对象身份与生命期的唯一权威。Application 将完整组件 ObjectId 映射为快照域内的非零稳定键，并在条目离开快照后移除映射；键不保活对象。场景替换改变 `scene_identity`；Frame 不携带内容修订号，Renderer 逐帧比较快照得知内容变化：网格按稳定键（没有键时按快照索引）对应，比较网格资源、变换和材质捕获（几何、surfaces 指针与常量；Surface、Image、Mesh 都是不可变捕获，内容变化必然换指针）；灯按稳定键比较参数。普通相机移动和连续位姿更新不会每帧清空历史。

Renderer 用前后相机和实例变换生成运动信息，结合深度、法线和局部表面对应关系拒绝错误历史。场景域替换与探针体积重建需要重建相应缓存；尺寸、视口、camera cut 和 AA 采样模式变化清除表面历史，camera cut 保留仍有效的世界空间探针。效果切换经 `lit_history_invalid` 只使依赖变化输入的信号失效，包括受影响的最终颜色历史，不连带清空整个探针场。稳定键为 0 的网格仍可绘制，但不复用该物体的时间对应关系。

基础色、粗糙度、自发光或金属度改变时，只使该对象的着色对应在编辑帧失效，仍保留几何运动；下一帧恢复有效位也纳入实例上传比较。反射的接收面与旧来源都检查这一标记，以响应原位材质编辑。SSSR 分类、历史解析和空间邻点共用粗糙度／视向资格判断，不合资格立即写入环境回退并清除旧来源。反射距离与粗糙度上限、AO 半径和效果开关的修改沿依赖掩码只使受影响的历史失效；探针诊断显示不影响任何历史。

运动纹理表达前帧 UV 减当前 UV 与对应有效性；预期前帧设备深度由独立 R32_FLOAT GBuffer 通道提供，不以 FP16 深度或残差恢复。斜面重投影按接收平面的深度梯度校验各邻点；深度容差来自世界空间投影与相对 FP32 误差，避免在反向深度远处用固定设备深度 epsilon 放宽校验。

灯光/材质编辑以及发光几何的移动、增删缩短有关光照历史的响应，DDGI 辐照度按上述每方向有效观测响应；这些编辑不触发全局历史清场。

直接光没有历史，遮挡物移动和辐射编辑当帧生效。SSSR、GTAO 与最终 AA 各自拥有历史，SMAA 关闭最终颜色时间累积不等于关闭光照降噪历史。探针采样序列属于探针场自身，只在实际更新时推进，随场景域或体积重建重置。

SSSR 不以全局几何变化统一降低历史支持。它比较接收面及反射来源的实际前帧对应与同一世界点的静止投影，排除相机运动和 jitter，再局部缩短运动源的历史。粗糙反射从参与空间估计的样本选择贡献来源见证，按最终新旧贡献权重决定保留或替换；随机 miss 不自动清空见证。旧来源经前帧 R32 深度、法线和投影平面梯度重建，再向当前帧验证几何；确定消失或遮挡时拒绝相应旧历史。连续源锚点不递归吸附像素中心，避免 T2x 相位积累位置漂移。见证不是整个粗糙波瓣的完整身份，离屏信息仍受屏幕空间方法限制。

反射亮度夹取沿当前 RGB 均值收缩，并以同一仿射系数更新一、二阶矩；不对 RGB 三通道加等量亮度偏移，避免纯红旧历史产生互补负色、在最终非负 HDR 合成后形成彩色拖尾。Signed 控制变量估计一直保留。命中 trace 用 RG32_UINT 保存精确 texel 身份和 FP32 距离，两张历史用 RG32_FLOAT 保存连续 UV；三张纹理各为每像素 8 字节，来源深度读取已有的 R32 历史。

普通实例新增、移除、几何替换和快照重排保留探针目标、显示历史及轮转进度。新增或替换几何的对象不复用表面对应，存活稳定对象按自身身份保留前帧矩阵；真实几何变化进入探针响应期。连续成员变化不会在目标进入显示照明之前反复清场。

## 诊断与性能边界

GTAO、最终 TAA 以及 SSSR 接收面/来源见证的表面历史共同检查完整 64 位身份与当前 motion 有效位，再应用各自几何容差；低 32 位相同的不同对象不能共享历史。SMAA T2x 的覆盖样本合成保留自己的轮廓规则，不把这种表面照明身份门槛机械套在互补 AA 样本上。

`FrameStats::scene_lit_gpu_ms` 为八个阶段的原始 GPU 完成样本：GBuffer、AS/上传、直接光（含 HDR 合成）、DDGI、GTAO、反射（SSSR）、HDR resolve/表面历史、Bloom/色调映射/SMAA/显示合成。`scene_lit_ddgi_gpu_ms` 再分为 update/transfer 与 receiver gather（包含半分辨率代表点 gather、全分辨率上采样和回退列表的精确 gather），`scene_lit_ddgi_visibility_rays` 分为 probe-hit shading 与 receiver gather；两个数组均长 2，属于既有 DDGI 时间和 visibility 总计数的子集，不重复加总。只有主阶段、细分 timestamp 与射线读回都对应同一个完成的 RHI 录制序号时，`scene_lit_gpu_timing_valid` 才为 true；`scene_lit_gpu_sample_sequence` 与 `scene_lit_gpu_sample_frame_id` 标识样本。完成结果可能滞后或重复，统计分位数时必须去重；没有用平滑时长计算 p95。

`scene_lit_direct_cluster_gpu_ms`、`scene_lit_shadow_cache_gpu_ms` 与 `scene_lit_direct_shading_gpu_ms` 依次细分直接光父阶段：灯列表构建、阴影 atlas 更新、着色与 HDR 合成。`scene_lit_ddgi_update_gpu_ms[2]` 细分 update/transfer：主射线（含分类/重定位）与命中照明/反馈/卷积；copy/transfer 仍只计入父阶段。细分之和不能替代其父阶段，更不能重复加入八阶段合计。

全部 15 个逻辑时间区间沿既有 timestamp 与异步计数读回共同发布，没有额外 GPU 等待。`scene_lit_gpu_pass_mask` 与完成样本一起保存：bit 0～7 对应主阶段，8～9 对应 DDGI update/gather，10～11 对应 DDGI update 细分，12 对应灯列表构建，13 对应阴影 atlas 更新（本帧有面重绘时才置位），14 对应着色与 HDR 合成。置位表示进入该工作区间，不保证内部每次都有非零工作；跳过的区间仍配对记录空 timestamp，可能测得微小查询开销，不能只靠浮点零判断启用状态。DDGI 关闭时其所有位不置位；DDGI 开启但没有启用体积时仍执行清零输出的 gather。非 Lit 帧没有有效样本。

编辑器的 **World → Performance** 按完成样本统计这些区间，表格口径见[编辑器帧性能](../editor/README.md#帧性能)。八阶段合计不含 UI、Guides、探针诊断绘制、Capture、CPU Present 或显示扫描，不等于完整 GPU 帧时或 FPS。逻辑资源显示属于当前 CPU 资源账目，与异步 GPU 样本的口径分开。

`scene_lit_shadow_cache_*` 发布请求/复用面、静态/动态更新、实际 draw、分辨率降级、整盏放弃的光源数（`dropped_lights`）、近裁剪面投影者、缺失 tap、平面校正回退、因重绘预算延后的 face 数及其最长连续延后帧数、请求 face 占用的 128² 格数，以及因 face 没画齐而不贡献直接光的光源数。所有这些统计对应同一完成帧，不将当前 CPU 请求混入异步耗时。临时 `direct_cluster_inspect` 的 66 档直方图也按同一身份发布；关闭时归零。

阴影和探针射线数来自 GPU 实际执行计数，与上述完成样本关联；屏幕直接光不发射线，阴影射线只来自 DDGI。`scene_lit_light_sources`、`scene_lit_shadow_sources` 与历史重置数描述当前编码帧，分别为解析光源总数和启用 Shadows 时投影的光源数；后者包含本帧因 atlas 放不下而被放弃的光（见 `dropped_lights`）。`scene_lit_resource_bytes` 是资源逻辑字节加 AS 数据量，不包含 GPU 驱动分配开销、AS scratch 和待退休资源，不能称为显卡实际总显存。

空间选灯的当前编码帧统计为 `scene_lit_spatial_sources`（保留源数）、`scene_lit_spatial_cells`（非空 cell 数）、`scene_lit_spatial_bytes`（三个当前 GPU 缓冲的逻辑字节，含空表哨兵）与 `scene_lit_spatial_changed`（本次编码这些表的内容是否变化或首次建立）。Control 将其发布为 `frame_stats.spatial_light_sampling` 的 `retained_sources / nonempty_cells / resource_bytes / uploaded`。这些值不表示裁掉的源数、实际选中数、GPU 完成状态或时间收益；三个缓冲已包含在总资源字节中，不能重复相加。未编码 Scene Lit（例如无几何且不绘制探针诊断）的帧，这四项为零，不代表所有 Scene Lit 缓存均已释放；仍保留的逻辑资源以 `scene_lit_resource_bytes` 总账为准。

Renderer 的端到端验收是 `renderer_acceptance` 目标，运行默认入口与 9 个 `--scene-lit*` 入口；各入口证明的内容、运行方式和变异记录见[验收记录](acceptance.md)。同步图像读回的耗时不作为性能结果。菜单与工程入口由 `editor_scene_lit_acceptance` 验证。

资源账目包含全部逻辑纹理与缓冲：GBuffer 与表面历史、DDGI atlas、GTAO/SSSR/AA 历史、cluster 列表、阴影 atlas（启用时两张 4096² D32，共 128 MiB）与光源表；直接光没有 reservoir、降噪历史或中间纹理。关闭 SSSR 或 Bloom 仍按前述裁剪工作；保留的可复用纹理继续计入统计。逻辑字节、dispatch 数均不是实际外部带宽或帧时测量。

可打开的真实工程见 [Scene Lit Room](../../../assets/examples/Examples/Scene%20Lit%20Room/README.md) 和 [Sponza](../../../assets/examples/Examples/Sponza/README.md)。体积配置来自当前 Scene 的 World 设置，切换场景不继承上一个场景的布局；重新拟合由 World Settings 页的明确操作完成。渲染通过统一材质表消费原有贴图及 Mask。`editor_sponza_acceptance` 在完整建筑上验证 DDGI 开关、移动光源与关灯后的收敛。当前成本见[验收记录](acceptance.md#当前性能)。
