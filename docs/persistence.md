# 持久化格式规则

本页是跨模块持久格式读取与升级规则的唯一权威位置。以下规则已经裁定，不代表现有实现已全部符合。

## 读取与升级

- 引擎只读取当前格式，并按该格式的当前 schema 严格校验。
- 旧格式仅由外部工具升级为当前格式；引擎加载不兼容旧格式，也不执行隐式迁移。本规则不表示已有外部升级工具。
- 唯一宽容例外是缺失节点类型：加载为 null 节点并保留其冻结数据。这不是丢弃未知数据、夹值、套用默认值或以可执行原生基类替代缺失类型的一般许可。

## 现行实现与收敛边界

[Scene 合同](modules/world/project-scenes.md)及[Project 加载说明](modules/editor/projects.md#持久格式与责任)仍记录当前实现中的额外宽容路径，包括原生基类占位、字段保留、夹值及资源替代；这些是待单独审查的产品候选，不是本规则的新例外。其他现存兼容或宽容实现也须另行审查，不能因本页更新而宣称已删除或已满足 null 节点合同。

格式的具体版本号、字段与资源责任继续由对应模块文档维护；[工程指南](engineering.md#验收保留标准)只规定验收保留与删除标准。实现改动和验收删项分别交付，规则同步不修改产品行为。
